我们现在确定的新方向是：**从少量可信样本出发，蒸馏出一个能够可靠替换教师、直接在原有 harness 中完成任务的小模型。**

整个分析可以从下面这条逻辑讲起：现实中为什么需要它，现有研究解决到了哪里，我们自己的结果说明了什么，剩下什么值得研究，以及接下来怎样用实验把问题和方法做实。

**我们的出发点，是一个已经能够工作的大模型 Agent。**

它依靠模型、工具、上下文管理和执行流程完成某类工作。我们希望把其中的大模型换成小模型，降低重复执行的成本，同时保留已经建好的系统。

我们拥有少量经过环境验证的教师示范，可以继续生成数据、调用教师和进行真实交互。因此：

- **K 是初始可信样本数量**，目前通常对应 K 条教师轨迹。
- K 不限制可访问的任务实例，也不限制后续生成新经验。
- 新增教师监督、环境交互和训练曝光要分别报告。
- 最终由学生独立执行，教师和额外训练辅助退出。

这里的 few-shot 描述的是可信数据稀缺的起点。它与“整个训练过程永远只能使用 K 条样本”是不同设置。

**随后，我们发现需要区分两个训练目标：学会教师的输出，以及接替教师在系统中的作用。**

在固定历史上训练和评估，学生当前的回答不会改变下一道评测题。但在 Agent 中，当前输出会影响工具执行、环境状态和下一轮输入。

因此，一个局部错误可能很快被反馈纠正，也可能改变后面整段执行。平均输出拟合得更好，未必意味着所有重要行为都得到了相应改善。

我们需要分别测量：

1. **输出拟合**：独立历史上的教师响应损失。
2. **局部决策**：同样的信息下，学生能否作出有效动作。
3. **自主执行**：学生在原 harness 中一直行动，能否完成任务。

这个区别构成了项目的切入口。但它还不是一个新的研究发现。一般的分布偏移和错误累积早已有研究；HAD 更是直接研究教师和学生共享固定 harness 时，怎样训练学生利用 harness 信息。[arxiv.org](https://arxiv.org/html/2610.02858v1?utm_source=chatgpt.com)

另一方面，Better Harnesses, Smaller Models 表明，小模型直接替换进原有系统可能表现下降，修改 harness 可以改善部分工作流。它支持“模型替换是实际痛点”，但并不能证明这些学生此前已经蒸馏得很好。[arxiv.org](https://arxiv.org/html/2607.08938v1?utm_source=chatgpt.com)

所以，我们选定的路线是：**通过蒸馏训练提高学生在原系统中的执行能力，主要改进放在模型训练阶段。** 修改 harness 可以用于诊断和对照；最终主结果仍然是学生接入原 harness 后的独立表现。

**我们自己的实验，让这个问题进一步收窄了。**

目前最重要的证据来自 ALFWorld dev140：

| 已有结果 | 对研究方向的实际含义 |
|---|---|
| 3–6 万监督 token 附近出现性能低谷，补足剂量后明显恢复 | 优化不足解释了大量失败。必须先保证基线训练充分 |
| K20 平均 107.7/140，K50 平均 114.7/140，教师 114/140 | 当前学生在现有系统中具备达到教师平均表现的可能，不能预设不可跨越的能力障碍 |
| 种子关联实例拟合达到 94–98%，LEAP 无纠错、ETO 只有少量纠错 | 当前探索分布提供的新信号有限，需要开放其他实例和合法执行状态 |
| 加热、冷却等被示范覆盖的类型带来主要增益 | 基本知识与技能覆盖确实重要，不能把这部分失败都归因于 harness |
| 类型覆盖相同的两个样本集得到 86 和 59 | 粗粒度任务类型解释不了全部差异，轨迹内部的具体内容值得研究 |
| 低 K 下，I4 直接给动作比 I3 给建议更有效 | 从信息到动作的转换值得检查，但尚不能据此唯一确定机制 |

这些结果首先告诉我们：**普通 SFT 比之前想象得强，很多“复杂方法失败”其实混入了剂量与采集分布问题。**

它们也留下了一个很有价值的问题：

> 同样很少的样本，为什么有的能让学生在系统里稳定工作，有的效果却差很多？随着 K 增加，究竟补上了什么？

我们现在不能回答“主要就是 harness 不兼容”。你们对 K5 的初步归因中，有相当一部分缺口涉及种子未包含的知识；这说明覆盖解释必须认真控制。

K50 接近教师也必须被尊重。它表明当前分布上的平均差距可以被普通 SFT 消除。下一步应检查具体成功任务、错误位置和反馈响应，而不能为了维持故事预设一定存在一个隐藏障碍。

**据此，我们优先检验的机制是：学生可能学会了正常路线，却没有充分学会在执行偏离后，利用原系统的反馈继续完成任务。**

这里包含一个很具体的过程：

学生先作出一个不够准确的动作。工具或环境返回新的信息。学生如果没有据此更新判断，就可能继续错误路线、重复无效操作，最终把一个局部错误变成整个任务失败。

这条假设能够与现有观察呼应：

- 反复训练原样本，可以把其中的路线学得很好。
- 在已经成功的关联实例上继续执行，可能采不到新的纠错。
- 相同类型的轨迹，可能包含不同的前提、反馈和修正步骤。
- 直接给动作可以替学生跨过一次决策困难，建议则仍需要学生自己完成转换。
- 增加样本可能补上这些情形，使 K50 的表现接近教师。

**这些是相容的解释，还不是已经确认的因果结论。** 类型内部的知识差异、示范质量、对象与布局差异，同样可能解释这些现象。

因此，我们最终选定的是研究方向；“反馈与恢复”是第一条重点机制假设。

**新的研究方向可以完整表述为：研究局部蒸馏质量怎样转化为原 Agent 系统中的执行能力，并据此设计能够保留系统表现的蒸馏方法。**

它有三个连续的问题：

- **现象：** 训练充分以后，局部决策质量与完整执行效果之间，是否仍有稳定的不一致？
- **原因：** 哪些错误会在原 harness 的反馈与控制过程中被纠正，哪些会持续传播？few-shot 是否使某些关键行为更难学到？
- **方法：** 怎样构造和利用蒸馏监督，让学生在原输入、原工具和原执行流程下学会这些行为？

我们希望最终获得的贡献，是一个能够解释实际失败、预测什么监督有用，并指导训练的方法。仅仅强调“考虑 harness”或增加错误恢复数据，还不足以构成强创新。

**方法的第一版，将围绕真实执行分支构造蒸馏监督。**

具体做法是：

1. 让学生在原 harness 中执行，找到真实的决策分歧、状态误判或无效操作。
2. 在可恢复的相同状态上，由教师和学生提出候选行为。
3. 实际执行这些候选，记录工具反馈、系统状态变化和后续完成情况。
4. 用这些证据训练学生：什么情况下可以继续，什么情况下需要检查或修正；存在多条有效路径时允许多解。
5. 部署时撤掉训练辅助，仅保留学生与原 harness。

这里要发展的蒸馏设计，是**如何根据真实执行作用构造目标、分配监督，并训练对反馈的条件化响应**。

但方法还没有定型。FutureBridge 已经考察教师指导后的学生续跑，经典 AggreVaTeD 也已经研究后续代价监督，因此“加一次续跑”或“给重要步骤加权”本身不够新。[arxiv.org](https://arxiv.org/abs/2608.01953?utm_source=chatgpt.com)

我们需要证明，新监督解决的是一个已经定位的剩余问题，并且效果超过相同数据上的普通 SFT，以及同等条件下的 SOPD、HAD 等方法。

**接下来的任务，按下面这个顺序执行。**

| 优先级 | 任务 | 具体产出与要回答的问题 |
|---|---|---|
| P0 | 固定实验口径 | 明确 K、样本、实例、扩展量；记录原 harness 的实际组件；固定发现集与最终评测集 |
| P1 | 重分析现有检查点和日志 | 对齐局部质量、完整成功率、教师/学生成功集合、首次偏离与 I3/I4 续跑，确定失败发生在哪里 |
| P2 | 做同状态交叉续跑 | 区分当前一步的问题与后续恢复的问题 |
| P2 | 补强扩展基线 | 检验新增普通经验、学生状态监督和 HAD 能否直接消除差距 |
| P3 | 训练分支蒸馏原型 | 检验针对机制的监督是否有额外价值，并区分数据收益与训练目标收益 |
| P4 | 在第二工作流验证 | 检查同一机制和方法是否成立，建立超出 ALFWorld 的结论 |

P1 先复用 teacher、base、K5/K20/K50 的足剂量模型，保留三份初始样本集。重点不是重新训练整张表，而是把已有结果解释清楚。

P2 中最关键的是交叉续跑。在完全相同的环境和 harness 快照上，比较：

| 下一步来自 | 后续由谁完成 |
|---|---|
| 教师 | 教师 |
| 学生 | 教师 |
| 教师 | 学生 |
| 学生 | 学生 |

如果教师能从学生那一步继续成功，学生却不能；而给学生教师那一步又能成功，就说明局部偏离和后续策略之间存在值得研究的相互作用。

随后再通过具体反馈或状态处理的干预，检查原 harness 在其中的作用。仅凭这个四格实验，还不能直接归因于 harness。

扩展基线先从 **K5 的三份初始样本集、一个固定新增预算条件**开始，至少包括：

- 足剂量 Seed-SFT；
- Grounded Augmented-SFT；
- 开放新实例的学生状态监督；
- 原 harness 下的 HAD；
- 新方法原型。

**这些方法必须拥有相同的新任务访问权限。** 不能让新方法自由扩展，却继续把所有基线限制在种子关联实例上。已有 ETO、IPR、LEAP 等实验按原计划收尾，作为旧设置的结果保留。

few-shot 的作用则用 K20/K50 对照检查：在技能覆盖与剂量合理的条件下，低 K 是否更容易在关键反馈后继续犯错，针对这些情形的监督是否更有价值。不能只凭低 K 总分低，就宣称机制被放大。

**第一轮实验必须给出一个明确决策。**

如果扩展 SFT 就消除了差距，当前问题主要由覆盖解释；如果学生状态监督就解决了，主要是已有的分布偏移问题；如果 HAD 已经解决，单纯在 few-shot 下复现它不足以支撑我们的目标。

如果强基线之后，仍存在一种**可以定位、可以干预、能够预测训练收益的失败过程**，我们就围绕它定型蒸馏方法，开展第二工作流、训练随机种子和独立评测。

下一轮最先要拿到的成果是：**一张解释现有模型差异的诊断表、一组同状态交叉续跑结果，以及一组公平的扩展基线结果。** 它们将决定新蒸馏方法究竟要学习什么，以及为什么需要这种训练设计。
