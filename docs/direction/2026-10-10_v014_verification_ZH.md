## 0. 结论

1. **压缩包可以原样复现。** 19 个文件的 hash 全部对上；两个原始脚本在锁定依赖下重跑，结果逐字段一致。
2. **21 条命题和定理，我逐条手推了证明，没有发现数学错误。** 独立写的检验套件（不读、不复用原脚本）覆盖全部 23 组检验，结果是 22 PASS、1 FAIL。
3. **唯一的 FAIL 是陈述缺条件，不是推导错误。** Thm 19 的式 (39) 默认训练过程访问到的状态都在已审计的 cell 里，但定理里没写这一条。我们构造了一个精确反例：真实 gap 为 1，证书只给 0.0296。修补办法见 §3。

## 3. 唯一的问题：Thm 19 式 (39) 缺一个覆盖条件

**现象。** (39) 的前提是 certified state 上的 response 能写成 `c + bᵀφ_x + r`，并且离开 certified 集合的概率 ≤ ρ。定理没有要求被访问的 certified state 必须是已审计的 cell，也没有要求 provider 在该状态上的消息律等于某个已审计 cell 的消息律。

**反例**（C15，精确构造）：
- 审计 cell 只有状态 0。在状态 0 上，reference 和 candidate 都确定地发出 0，所以审计得到的 D̂ = 0。
- 训练从状态 1 开始。在状态 1 上，reference 发 0，candidate 发 1。
- 两个状态上 `g(y)=y` 的分解都成立，所以都算 certified，ρ = 0。
- 结果：审计事件以概率 1 发生，真实学习价值 gap 为 1，而 (39) 给出的界只有 0.0296。

**修补。** 在 (39) 前加一条假设："对新训练过程访问到的每个 certified state z，reference 和 candidate 在 z 上的消息律等于某个已审计 cell x(z) 上的消息律。例如 provider 是不依赖状态的 IID block 源，或者 certified 集合就等于已审计状态集合。否则离开已审计集合也算 exit，其概率计入 ρ。" C20 验证了按这个条件把概率计入 ρ 之后，界重新成立（该例中 ρ = 1，界退化为平凡界）。

**对实际的含义。** 我们的 provider 在神经训练里是依赖状态的，比如 teacher 标注学生自己走出的前缀。这时冻结的 cell 几乎覆盖不到新访问的状态，ρ 接近 1，Thm 19 的证书实际上用不上，只能走 Thm 20 的实际状态审计。而 Thm 20 在 M=4、δ=0.05、半径 0.1 时，每个 candidate 每个状态要 1016 对独立训练副本。也就是说，**理论里能真正给证书的路线，在 12B 学生上贵到做不了**，practical 方法只能依靠需要另行验证的 proxy。压缩包本身也承认这一点。

原审计（Independent_Proof_Audit 的 B4 节）其实提到过"映射到最近 checkpoint 需要 cell 内一致逼近界"，但最终版 Thm 19 的陈述里没有写进去。

## 4. 受控小神经网络实验（C23；controlled neural，不是 Gemma，也不是外部 benchmark）

设置：one-hot context → 4 个 tanh 单元 → sigmoid，contexts 共享输出层；loss 是 cross-entropy；优化器为 SGD（η ∈ {0.01, 0.1, 1, 3}）和 Adam（η ∈ {0.01, 0.1}），更新次数 1/4/40 次。数据源有五组：Prop 5 的两个源、Prop 6 的独立和配对两种 packet、(26) 的矩律（N = 2,3,4）、parity 律（N = 2,3），以及同一组标签换一种分组。对比基准是用初始化处的切线（NTK）线性化得到的 affine SGD 预测。训练历史能穷举时精确计算，否则每个数据源跑 2400 次独立训练。

| 区间 | 与 affine 预测一致 | 偏离 | 最大偏差 |
|---|---:|---:|---:|
| SGD，η ≤ 0.1，≤ 4 次更新 | 28 | 0 | 2.5e-4 |
| SGD，η ≥ 1 或 40 次更新 | 19 | 37 | 0.53（实际 gap 普遍小于预测，sigmoid 饱和把差距压缩了） |
| Adam | 10 | 32 | 0.12 |

**主要观察：**

- **lazy 区间里 affine 理论近似成立。** 步长小、更新少时，实际 gap 和 affine 预测几乎重合。
- **Adam 改变了"需要匹配哪些信息"。** 两个数据源的 0 到 N−1 阶矩完全匹配（N=3），SGD-affine 预测 gap 为 0。但 Adam（η=0.1）更新 1 次 gap 就是 0.077，4 次是 0.12。Adam 第一步的 m/√v 等于 sign(g)，更新变成数据的阈值函数，正好对应 Thm 17 的阈值反例：此时低阶矩匹配不再足够，相关信息是 `sign(Z − p)` 的分布。
- **分组方式在序列更新下才有影响。** 单步、共同状态、等权时，重新分组对更新的影响精确为 0（严格 null）。多步序列更新下，分组差异随步长从 1e-5（η=0.01）增长到 0.75（η=3）；Adam 下符号相反。

图：`theory/independent_checks/figs/C23_controlled_neural.png`、`C18_evidence_exposure.png`（独立 block 对比 replay 和合成后代：只有独立 block 按 n^{1−N} 衰减，其余两种不随 exposure 下降）、`C19_response_complexity.png`（同一最高次数下，parity 需要的特征数远多于标量和结构化族）。

## 5. 这次验证确立了什么，没确立什么

**确立了：**
- finite 数学核心在其声明的假设下正确。
- 唯一的陈述缺口有精确反例，也给出了修补。
- Thm 4、Thm 14、Thm 17 的界在部分实例上接近紧或恰好紧。
- 在小网络上，affine 结论成立和失效的边界清楚。

**没有确立：**
- 任何关于 Gemma 或真实 agent 的结论。
- 新颖性。novelty audit 的判断是：各组件大多是经典工具，整合本身是否构成贡献还要看后续定理和方法。
- 神经 proxy 的有效性。

**我们检验套件自身的弱点（如实说明）：**
- C5 里对 d₀ 的检查偏弱。
- C16 的大多数压力配置中 E[ΣB] 很小，只有 n=1000 那组真正有正向 LCB。
- C19 的近似误差是"找到的最好子空间"给出的上界，不是全局最优。
- C23 规模很小。

## 6. 要"完整"这套框架，还缺什么（供下一步决定）

压缩包自己写明还没挣到的部分是：从精确刻画到神经可测 response 的桥。结合这次的结果，我看到的缺口按与我们实际的相关度排序：

1. **优化器相关的信息需求。** C23 显示 Adam 会把学习器变成阈值型，需要匹配的信息从"矩"变成"符号或分位数"。我们实际用 AdamW 训 LoRA，所以这是最贴近实际的一条。可以考虑给出 sign 类或归一化更新下 response class 的刻画及其信息阶，这在现有组件里没有直接对应。
2. **K 在理论中缺席。** 现在 K 只进入 I₀，没有任何结论讲 K 变化时 R_info 或所需信息怎么变。few-shot distillation 论文需要这一环。
3. **lazy 区间的神经 response 近似定理。** 一阶 response 等于梯度对齐，误差随 η² × 更新数增长；C23 给出了经验边界。但这条与 GRACE/LESS 等已有工作重叠，新颖性风险高。
4. **多步 agent 的状态分布偏移。** 把 Thm 4 推广到"在学生访问的状态上查询"的一般 acquisition 下界和上界。这与 DAgger 一类工作接近，需要找出差异点。
5. **证书成本。** 由于 §3 的覆盖问题，practical 方法只能依靠 proxy，必须设计 proxy 的验证协议，也就是 CED 计划里的 G5。
