# 固定接口下的小模型 Agent：面向学生的交互策略蒸馏

2026-10-07｜按最新讨论更新的项目主文档

**核心问题：工具、API 和执行规则既定时，怎样通过蒸馏，让小模型学会适合自身能力的交互策略，并独立完成强模型能够完成的任务？**

工作题目：**Same Tools, Different Policies: Distilling Interaction Strategies for Small Agents**。

这是研究方向、方法原型和执行计划，不是已完成论文的结论。本文取代此前将主线限定为“harness 与学生之间的 gap”或“错误恢复”的叙述。已有实验数字来自用户提供的 10 月 7 日汇总，尚未审计原始日志。本次没有启动新训练或环境实验。

## 1. 已确定的研究边界

### 1.1 固定部署接口，学习怎样使用它

现实中的工具、API、权限与返回语义往往由外部系统决定。论文主实验进一步冻结整个原生 harness H0，确保收益来自学生训练与行为改变。

| 固定部分 | 可学习部分 |
|---|---|
| 工具集合、API schema、参数语义与权限 | 调用哪个已有工具，怎样填写合法参数 |
| 环境状态转移、工具返回内容与真实副作用 | 何时查询、何时操作、何时重新观察 |
| 动作解析、原生上下文组织、已有控制与终止规则 | 如何利用原生历史和反馈，何时选择已有终止动作 |
| 已有记忆机制及其真实读写能力 | 如果原接口支持读写，何时使用；如果不支持，不假设新增记忆 |
| 同条件下的推理与交互预算 | 在预算内怎样分配推理、查询、核验和重试 |

工具不变不等于交互路径固定。同一 API 可以由不同模型在不同时间、不同条件下调用，形成不同的完整策略。

主方法不增加负责替学生决策的运行时教师、规划器、状态整理器或验证器。不修改返回内容使其更容易理解。训练时可使用环境状态进行标签验证，但部署输入只包含原接口合法可得的信息。

正确的模型原生序列化、chat template 与协议适配应对所有方法公平实现，不将实现错误作为研究现象。若系统原本包含其他模型调用或辅助组件，固定并披露，不能将其能力算作学生自己获得的能力。

### 1.2 K 是样本数量

K = |D0| 是初始可信样本数。目前一条样本通常对应一条经过执行验证的教师轨迹，不等于一个任务类型，也不等于允许访问的任务实例数。同一实例可以产生多条轨迹，拆分步骤不会增加初始 K。

允许生成新实例、调用教师和进行真实交互。初始 K、不同实例数、新增轨迹、教师生成 token、真实环境步和监督曝光分别记录。扩大后应称“少样本启动的蒸馏”，不能将全部新经验隐藏在 K-shot 标签下。

已有“只在种子关联实例上探索”的实验作为一种历史设置保留，不再限制新一轮主比较。

### 1.3 延续原项目约束

沿用已指定的黑盒教师 GPT-6-luna 和学生 google/gemma-4-12B-it；不假设可访问教师参数、隐藏状态、梯度或未提供的 logprob。只做 post-training，不做预训练。不使用中国来源的模型 checkpoint，包括辅助生成与奖励模型；可以引用并用允许的模型复现相关方法。

这些是既有项目配置，不表示本次重新验证了服务器部署、模型下载或 API 可用性。新的容量对照需要单独锁定模型与配方。论文一独立开展，世界模型不作为方法的前提。

## 2. 完整的新故事

### 2.1 实际需求

一个强模型已经能够通过现有工具完成某类工作。我们希望以小模型承担重复执行，同时保持工具、权限和执行系统。只有少量可信示范，因此需要利用教师与环境扩展有效训练经验。

### 2.2 蒸馏目标中的潜在错位

成功教师轨迹展示的是“一个具有教师能力的执行者怎样解决问题”。其中可能包含隐含的执行要求：从较长历史恢复状态、同时处理多个约束、推断工具调用后果，或在没有额外检查时持续推进。

学生需要完成相同目标，但最适合它的交互方式未必相同。它可能需要先使用已有查询获得状态，再行动；也可能不需要额外查询，只需要学会更好地利用已经返回的信息。

因此，要检验的是：**某些蒸馏失败究竟因为教师策略还没学好，还是因为教师自然采用的策略并不是这个学生最合适的学习目标？** 两种原因可以共存。

### 2.3 核心机制假设

**一次交互的价值取决于任务状态，也取决于后续由谁执行。** 同一次查询对教师可能冗余，对学生却可能降低记忆、推断或纠错负担。模仿教师的调用路径，可能遗漏对学生有用的行为。

这不意味着学生总应多调用工具。多余交互也可能消耗预算、引入新错误或丢失上下文。研究目标是学习什么时候直接推进，什么时候通过原有接口取得帮助。

### 2.4 方法方向

用真实执行检查候选交互方式对学生的作用，构造能够保持任务目标、又适合学生执行的监督，再训练学生自主选择这些行为。教师提供任务知识与候选策略，环境验证其有效性，学生执行结果用于调整监督目标。

### 2.5 希望改变的小模型 Agent 设计观念

在固定工具生态中，交互策略应成为随执行模型能力而学习的组成部分。设计小模型 Agent 时，需要检验教师的成功方式是否适合学生，以及哪些合法交互能帮助学生完成相同目标。

这是一条需要证据支撑的设计原则，不能仅凭“模型与 harness 都重要”成立。

## 3. 一个不改变接口的例子

假设原系统已经提供“执行操作”和“读取当前状态”两个接口。以下仅为机制示意，并非本项目已经确认的具体失败。

教师可能从历史和操作返回中正确推断当前状态，直接执行下一步。学生可能不能可靠完成同样推断，但可以先调用原有读取接口，依据返回决定下一步。

两者拥有相同的初始信息、工具与权限。学生后来获得了更多观察，这是它主动调用合法工具的结果，需要计入成本，而不是外部直接送来的新提示。

还有一种更细的情况：读取返回的事实在历史中已经出现过，重新读取没有带来新的任务规则，却可能降低学生提取或记忆该事实的负担。应区分这种作用与获得此前未知的事实。

若读取接口不存在、返回不能消除有关不确定性，或其成本超过收益，这种策略便不成立。不能新增“check_state”伪工具，不得将文字自检当作环境验证，也不能把额外验证器的正确答案注入学生。

## 4. 我们已有结果提供什么证据

当前口径：ALFWorld valid_seen dev140，base 62/140，teacher 114/140；多个 K、三份初始样本集和剂量网格。三份样本集不等于三个训练随机种子。

| 已报告结果 | 已支持的判断 | 与新问题的关系及限制 |
|---|---|---|
| 3–6 万监督 token 附近存在低谷，补足剂量后恢复 | 训练过程是重要混杂 | 新方法必须比较足剂量基线；低谷本身尚不能归因于交互策略 |
| K20 平均 107.7，K50 平均 114.7，教师 114 | 当前学生可以达到这一分布上的教师平均水平 | 不预设普遍容量障碍；检查哪些行为随着数据量改变，而不是宣称必有隐藏缺口 |
| K100 平均 111 | 曲线并非严格单调 | 必须保留方差与样本内容分析 |
| 种子关联实例拟合 94–98%；LEAP 无纠错、ETO 仅 3 对 | 原采集分布很难产生新纠错 | 需要开放新实例和同实例的合法不同状态；不能据此断言交互学习无效 |
| 加热、冷却等覆盖带来主要增益 | 基本知识与技能覆盖确实有作用 | 必须与策略适配解释正面对照 |
| K5 的初步归因将约 44% 缺口归于种子没有的知识 | 探针提示覆盖是实质因素 | 小样本归因结果，不升级为普遍比例或互斥因果分解 |
| 粗类型覆盖相同，两个 K2 样本集为 86 与 59 | 类型标签解释不了所有差异 | 检查轨迹的知识、对象、布局、决策步骤与反馈利用；策略差异仍是假设 |
| M1a 未检出，低 K 时 I4 动作干预比 I3 建议更有效 | 局部知识探针与自主行动需要分别考察 | 不能认定全部知识已掌握；动作接管改变了执行，不能唯一归因于能力或信息 |

当前没有证明“学生局部能力已经很好却因 harness 失败”，也没有证明“学生必须采取不同策略”。K20/K50 是同一模型不同数据条件，不能替代模型容量对照。

K50 平均接近教师意味着需要报告配对成功集合与具体交互行为；若二者也相近，应接受该范围内普通蒸馏已足够。教师 114 不是环境理论上限。

## 5. 三个递进、可否证的研究命题

### H1：固定接口下，交互方式的收益随执行模型改变

从相同合法历史出发，比较直接推进与某个原生替代交互，例如先查询再根据返回继续。设 Δ_M 为采用替代交互对执行模型 M 的任务效用增益。

重点寻找 Δ_S > 0，且显著大于 Δ_T 的情形。若成本调整后的策略排序在教师和学生之间反转，证据更强；不要求每个案例都反转。

需要排除：教师处于成绩上限、学生仅缺新规则、额外特权信息、不匹配预算、重复尝试次数增加、接口实现错误。教师的平均增益较小，可能仅因为天花板，不能直接当作能力依赖证据。

### H2：改变蒸馏目标中的交互方式，比只增加教师自然轨迹更有效

控制训练剂量、任务访问权限和合理资源预算后，经过验证的替代策略监督，能让学生在独立实例中改善自主成功率，并学会在合适条件下采用有关交互。

需要比较普通扩展 SFT、SmartAD、学生状态监督和 HAD。若已有方法已解决该现象，不声称发现特殊障碍。

### H3：策略选择的变化能够被学生能力与执行条件预测

改变学生模型能力、历史负担或操作前后的不确定性后，哪些查询或核验有用应出现可解释变化。需要同时测试“不该增加交互”的情况。

目标是能预测新实例上哪种监督有益，而非只给已有失败贴标签。低 K 表现差或弱模型收益大都不是充分证据；K、容量和训练剂量应分开控制。

| AggreVaTeD [8] | 后续代价指导模仿学习 | 单纯给重要动作加权不是新机制 |

不能预先断言这些方法学不到替代交互。实际比较决定我们是否存在新增贡献。只有改变问题名称、加入 few-shot 标签或更换一个 loss，不能建立新颖性。

## 7. 蒸馏方法原型：让监督目标适应学生的执行

方法的核心是可迭代的策略目标构造与学习，不预设一个复杂的运行时模块。

### 7.1 建立足剂量学生起点

从 K 条可信种子训练学生。保留普通 SFT 强基线及其正常成功轨迹。后续任务与真实交互允许扩展；不能只访问学生已经熟悉的种子关联实例。

### 7.2 在原生执行中定位候选决策

关注学生不确定状态、忽略返回、重复无效操作、提前结束或持续沿用过时计划等位置。正常成功位置同样采样。分歧和不确定性只用于提出候选，不能直接当作错误真值。

### 7.3 产生合法的替代交互

黑盒教师结合合法历史与观察到的学生困难提出少量候选；学生自己的有效分支也可保留。候选可以改变既有工具的调用时机、参数、顺序和对反馈的应对方式。

改写不能新增 API、宏动作、权限、外部状态字段或执行规则。若接口一轮只允许一个动作，每个候选仍逐轮调用。所谓“调整粒度”仅指原接口允许范围内重新安排操作和检查，不改变工具的原子语义。

若原协议保留模型生成的推理文本，可以学习更有用的简短状态记录；若原协议不保留，不依赖它提供记忆。没有真实调用或可验证依据的“我检查过了”不是检查。

### 7.4 验证对学生是否有用

从同一快照实际执行候选，然后让冻结版本的当前学生独立续跑。记录最终成功、失败类型、模型 token、工具调用、延迟及预算消耗。必要时教师续跑用于区别候选本身无效与学生后续暂时不会。

标签依据真实执行结果。教师偏好、似然或预测可用于提案，但不能替代环境验证。对关键候选进行配对重复，避免一次随机成功决定标签。

当前学生续跑失败不等于经过训练后仍无法学会。验证信号用于构造优先级和课程，不永久删掉所有当前较难的正确教师经验，防止训练锁在学生现有能力内。

### 7.5 学习条件化的交互策略

训练需要同时包含：

- 直接推进已经足够的情况；
- 采用额外交互确实有益的情况；
- 同一查询得到不同返回后，需要采取不同下一步的情况。

这样才能检验学生是否学会了何时查询、如何使用反馈，而不是机械地每步多调用一次工具。

训练目标的候选实现包括：验证后的多步原生交互监督，以及在同一历史上依据学生续跑效用构造的候选偏好。所有梯度来自学生的输出概率；不依赖教师 logits。工具返回作为真实上下文，监督模型生成的部分，不让学生伪造环境观察。

核心比较是“直接教师目标”与“经学生执行验证后调整的目标”。结果加权 CE 或偏好学习只是可能的实现，不是单独的新颖性来源。后续若设计新目标，必须与同数据普通 CE 比较。

### 7.6 部署与迭代

部署只加载训练后的学生，运行原 H0。学生自行决定是否查询、检查、重试或结束。不能持续给出正确下一动作或逐任务正确策略。

训练中更新学生后，再采集新的状态与候选收益。策略随学生能力改善可能变得更直接，不能强制永久保留所有训练时增加的交互。

## 8. 第一批实验及交付物

### E0：原生接口与数据口径清单

目的：先确认哪些策略真的可实现。

交付一份接口清单：已有工具及读写/副作用语义、返回中可验证的事实、原生历史与记忆、动作/重试/终止限制、资源预算、可快照或重放能力。明确同一实例多样本与后续扩展统计。

额外检查训练数据与部署格式、截断和解析一致。已有实现错误立即修复，不作为方法收益。

### E1：重用现有检查点解释已有差异

对象：teacher、base、K5/K20/K50 足剂量学生，三份初始样本集；K2 两个差异明显的样本集用于案例发现，少量低谷检查点用于剂量分析。

交付：

1. 独立共同历史库上的输出损失、局部动作质量与完整成功率。
2. 教师/学生配对成功集合，不只报告平均总分。
3. 首次实质偏离、已有反馈是否足够、是否存在合法的替代交互。
4. I3/I4 干预后的续跑，以及不同样本集包含的具体知识和交互行为。

历史库包含教师与学生真实访问历史，对所有模型使用同一固定集合。训练拟合不能代替独立局部能力。任务内多个步骤不是独立统计样本。

### E2：执行模型 × 原生交互方式的交叉实验

这是新主线最关键的机制实验。

从相同环境与完整 H0 状态恢复，比较两种真实可执行的下一步或短交互前缀：A 为直接推进候选，B 为合法替代候选，例如先查询。每种前缀后，分别由教师和学生自主完成。

| 初始交互方式 | 后续教师执行 | 后续学生执行 |
|---|---|---|
| A：直接推进 | J_T(A) | J_S(A) |
| B：原生替代交互 | J_T(B) | J_S(B) |

关注 J_S(B)-J_S(A) 与 J_T(B)-J_T(A) 的差异，并同时报告完整成本。剩余预算扣除已执行前缀；整步输出和原生历史一并恢复，不能只换动作却保留另一个候选的推理历史。

这是训练侧机制干预，不是部署阶段替学生选择动作。最终主结果必须由学生从任务开始自主决定。

控制条件：

- 相同初始信息与访问权限；后续观察可以因合法行为不同而不同。
- 区分获取新事实、重新取得已有事实、仅增加无关调用或更长思考。
- 如果存在适当且安全的原生操作，加入相近成本的无关交互对照；不存在就披露而不制造伪工具。
- 同一上限下评测，同时报告成本曲线；额外工具步不是免费资源。
- 对教师天花板和不可恢复状态单独分析，不只挑选有利案例。

此前教师/学生“下一步来源 × 后续执行者”的四格续跑仍有用，作为 E2 的局部诊断。新 E2 更关注原生替代交互本身对不同执行者的价值。

### E3：强扩展基线与方法首轮训练

先做 K5 三份初始样本集和一个预先固定的新增预算条件：

A. 已有足剂量 Seed-SFT。
B. Grounded Augmented-SFT：新实例上的环境验证教师轨迹。
C. SOPD 或明确的黑盒 DAgger 适配：新实例中的学生状态监督。
D. 原 H0 下 HAD 适配。
E. 新交互策略目标与普通 CE。
F. 相同数据下的新蒸馏目标完整原型。

SmartAD 是正式主表必要近邻；如果多候选数据已经具备，应尽早纳入。FutureBridge 应按真实教师信息接口决定忠实实现或明确标注适配，不能把缺少教师概率访问的替代版当作原法。

所有方法拥有相同的新任务访问权限。相同数据对照必须保证教师输出、执行验证和额外知识完全一致。相同资源对照分别报告教师 token、环境步、训练曝光与 GPU 时间。此前约 40 万监督 token 可作为起点，不是所有新配方通用的最佳剂量。

若新方法只比受限在旧实例的基线好，不能说明新的蒸馏机制有效。

### E4：确认自主性、选择性与泛化

主指标是独立任务成功率，辅以教师成功任务的保留、任务成本与失败类型。机制指标包括：该查询时是否查询、不必查询时是否直接推进、是否根据不同真实返回作出恰当后续动作。

不以调用次数增多、教师动作一致率提高或训练损失降低代替成功。额外检查会有成本，既比较相同预算，也呈现成功率与成本的关系。

保留当前 dev140 作为开发证据；封存评测不能用于生成策略、选检查点或失败驱动训练。需要新对象、实例、布局或条件组合上的确认。

### E5：能力和 few-shot 的独立作用

K 是数据轴。另增加至少一种学生能力条件，优先使用来源允许、配置可控的模型对照。检查交互方式的相对价值是否随模型能力、历史负担和任务不确定性改变。

K5/K20/K50 用来观察初始化经验如何影响策略学习，不能当作模型容量对照。高 K 接近天花板时，不能仅凭低 K 增益更大认定 few-shot 特有机制。

最终主结果补训练随机种子，并在第二个具有原生可观测操作、可验证结果和可重放状态的工作流中复现。每个环境都保持各自 H0 固定，不要求单一学生泛化到任意 harness。选择第二环境是为了验证机制，不是为了保证出现某个分数缺口。

## 9. 资源优先级与原计划的衔接

1. **先做 E0/E1。** 主要利用已有代码、轨迹、检查点和干预记录，拿到明确候选。
2. **E2 与普通扩展基线并行推进。** 从 K5 三份样本集开始，不立即展开所有 K × 预算 × 方法组合。
3. **有候选信号后实施 E3。** 新策略目标与同数据 CE 对照同时准备，直接面对强近邻。
4. **E4/E5 用于确认。** 初步信号出来后再扩容量、训练随机种子和第二工作流。
5. **已有 ETO/IPR/LEAP 等按原计划收尾。** 这些提供历史设置下的比较，不再独占新增实验预算。额外剂量对照只为解决具体质疑而补。

本计划不预估未经测量的 GPU 小时或保证完成日期。第一轮决策依据是是否得到有解释力的机制证据与公平基线，而非跑完固定数量的格子。

## 10. 什么结果支持或推翻主线

| 结果 | 应作的判断 |
|---|---|
| 普通扩展 SFT 就解决剩余失败 | 当前设置主要受剂量和覆盖约束，不主张特殊策略障碍 |
| 学生状态监督已解决 | 状态分布覆盖解释充分，需要进一步证据才提出新机制 |
| HAD 或 SmartAD 已解决 | 现有学生适配监督足够，few-shot 复现本身不足以作为主要创新 |
| 额外交互对教师和学生等量有效 | 可能只是通用的更好策略，不能直接称学生能力相关 |
| 收益完全由新增事实或额外预算解释 | 应按实际信息/成本机制表述，不声称能力补偿规律 |
| 只有持续提示策略或教师接管才有效 | 已证明辅助有用，尚未完成蒸馏后的自主策略迁移 |
| 只在单个既有实例出现收益 | 是案例线索，需要独立实例与随机性验证 |
| 同预算下出现可重复的执行者差异，且训练后学生能自主选择有益交互 | 支持主线，进入预测规律、完整方法与第二工作流验证 |

高潜力贡献应包含三件事：新的、经控制的现象；能预测策略收益的解释；在固定接口内把解释转化为自主能力的蒸馏方法。工作标题、一个偏好 loss 或“更多核验更好”的经验法则都不能替代这条证据链。

## 11. 可直接用于项目介绍的故事段落

小模型 Agent 通常需要接入既有工具和 API，而部署者未必能够修改这些接口。轨迹蒸馏能够有效迁移教师行为，但成功教师展示的是适合其自身推理、记忆和纠错能力的交互方式，这种方式是否也是学生最合适的学习目标仍需检验。我们的已有实验表明，训练剂量与基本覆盖能够解释大量 few-shot 失败，普通 SFT 在当前分布上可以接近教师；因此，新研究将从这些强基线出发，考察同一次合法交互的作用是否随执行模型改变，以及普通模仿是否遗漏了对学生有价值的查询、核验和后续应对。我们计划通过同状态交叉执行构造和验证学生适用的策略目标，并将其蒸馏进模型，使学生在保持原有工具、API 和执行规则的条件下，自主选择合适的交互方式。研究希望形成关于小模型 Agent 如何使用固定外部能力的可检验设计原则。
