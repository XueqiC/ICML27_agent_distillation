## 1. 要回答的问题

一句话：harness+teacher 诊断出的错误，能否不经过"生成数据再训练"，而是直接在 D-param 定位的层里编辑权重来纠正，并由 harness 验收？

- 对照一：同一学生不做编辑。
- 对照二：同一学生按 v0 方式训练（D-param 版）。

## 2. 步骤

**S1 错误方向（只用训练侧数据）**
- 来源：第一轮修复记录中 teacher 标出的走不通步骤，以及修复后在同一步执行的正确决策。只用 R 桶对应的训练题，不用留出题和 dev140。
- 对每个配对（同一题、同一步：原失败决策 vs 修复后决策），在学生上前向，取决策 token 前最后一个位置的残差流状态 h_l，l 取 D-param 选出的层。
- 方向 d_l = 归一化的均值差 mean(h_fail) − mean(h_fix)。
- 按 teacher 的失败类别分别估计：refused_action、search_incomplete_or_loop、missing_precondition、goal_misread、wrong_object_or_target。另外估计一个合并方向。
- 配对数少于 20 的类别不单独估计。

**S2 编辑**
- E1 方向消除：对选中层的 MLP 输出投影 W，做 W ← W − α d_l d_lᵀ W，α ∈ {0.25, 0.5, 1.0}。效果是减少该层向错误方向写入的分量。
- E2 只在一个类别方向上做 E1：先做循环 / 重复被拒（search_incomplete_or_loop 与 refused_action 合并），这和 blog 的例子对应。
- 编辑对象是 LoRA 合并后的权重，其余参数不动。记录改动参数所占比例。

**S3 harness 验收**
- 验收集：v0 第一轮的 71 道合成留出题（1 次 greedy 加 3 次采样），以及 K20 原题。
- 接受条件（全部满足）：
  - 留出题的任务级成功率比未编辑学生高至少 5 个百分点；
  - 任何一档的失败率都不上升超过 5 个百分点；
  - K20 原题保持 100%。
- 在满足条件的候选中取留出题成功率最高的，平局取 α 较小的。
- 注意：这样使用后，这 71 道留出题就成了 S 部件的选择集，不能再作为 v0 停止规则的无偏测量。第二轮需要重新合成一批留出题。

**S4 最终评测**
- 被接受的编辑在 dev140 上评测（hpg B200，与 baseline 相同流程）。
- 与未编辑学生配对比较（McNemar 检验）。

## 3. 应用对象

两个时间点各做一次：
- θ₀：回答"仅靠编辑能补多少"；
- v0 D-param 训练后的学生：回答"编辑与局部训练能否叠加"。

## 4. 成本与风险

- 不调用 teacher。GPU：方向估计约 1 小时，每个候选编辑在 71 道题上评测约 30 分钟，共 3 个 α × 2 种方向集合。
- 风险：
  - 方向由均值差估计，噪声可能较大；
  - 编辑可能伤害未覆盖的能力，所以要求 K20 原题保持 100%，并检查各档留出题。
