# P1：teacher 直接"开胸手术"改权重，是否真的好（预注册）

日期：2026-11-05 CST。状态：**定稿**（15:4x CST，任何 P1 运行之前）。用户 15:19 CST 提出、15:22 CST 同意本方案。
前置：P0 预注册与结果 `docs/direction/2026-11-04_P0_whitebox_diagnosis_prereg_ZH.md`（§7：teacher 秩一编辑 28.9%，不编辑 22.2%，固定规则 31.1%，未达标）。

## 1. 问题

只用已有数据（K20 第一轮的修复记录），让 teacher（gpt-6-luna）读取学生内部状态、自己定位"病灶"并直接修改权重。与以下做法相比，它是否更好：不改、随机改、简单规则改、不经 teacher 的自动定位改、以及用同样的修复数据直接做 SFT？

P0 可能低估了 teacher，因为它有四个限制。P1 逐一放开：

| P0 的限制 | P1 |
|---|---|
| 只有一种编辑：在一个投影上去掉一个方向（秩一） | 多层、秩 k、加性秩一、神经元缩放、teacher 自选位置的局部微调，可以组合 |
| 没有梯度；每类 60 次工具调用、10 次 rollout、5 个候选编辑 | 增加梯度归因工具；预算放大 5 倍 |
| 诊断集 23 对（每类 4–5 对） | 诊断集约占一半（约 56 对） |
| 只测从分叉点开始的 rollout | 另测整题 rollout 和 dev140 |

## 2. 数据与划分

- 学生：θ₀ = K20 轨迹 SFT seed 0（e4b-tsft-k20-e32-lr5e-5），LoRA 合并进 base 后的稠密权重。
- 配对：沿用 P0 冻结的 113 个配对（`reports/p0_tooling/extraction_v3/pairs.json`，文件 sha256 432fd178…，配对摘要 cb4e1699…），定义不变：原失败轨迹与验证通过的修复执行的第一个分叉步 t*，状态 s，失败动作 a_f，修复动作 a_r。
- **新划分（P1）**：按任务实例（group_id）分组，每个类别内用 Random(0) 打乱分组后贪心分配，使每个类别的诊断集配对数为该类别总数的一半（向下取整，至少 6 个）。诊断集与测试集不共享任务实例。
  - 各类别总数：goal_misread 27、missing_precondition 37、refused_action 19、search_incomplete_or_loop 12、wrong_object_or_target 18；
  - 实际划分写入冻结文件后记录在 §8，teacher 永远看不到测试集。
- 不使用 dev140、合成留出题或 K20 原题做任何选择；它们只用于 §5 的评测。

## 3. teacher 的工具与编辑（只作用于诊断集）

沿用 P0 的工具 1–7（动作打分、logit lens、注意力汇总、上下文反事实、激活修补、方向工具、harness rollout），新增：

8. **梯度归因**：在 teacher 选定的诊断配对上，计算 log p(a_r) − log p(a_f) 对每层、每个模块（q/k/v/o、gate/up/down）权重的梯度范数，返回排序。
9. **神经元归因**：在选定的层和配对上，MLP 中间神经元的激活 × 梯度，返回前 N 个。

编辑类型（可以在一个提交中组合多个，按顺序作用）：
- **去方向**：W ← W − α U Uᵀ W，U 为 1–8 个正交化方向（来自方向工具），可作用于多层的 down_proj / o_proj（P0 的推广）；
- **加性秩一**：W ← W + α a bᵀ，a、b 来自方向工具或神经元归因；
- **神经元缩放**：把选定 MLP 中间神经元在 down_proj 中的对应列乘以系数 c；
- **局部微调**：teacher 选定模块（层 × 类型）、诊断配对、目标动作、学习率、步数（≤ 200 步），在这些模块上训练 LoRA（秩 ≤ 16），损失为 −log p(a_r | s)；训练得到的权重增量保存为文件并记录 sha256，测试时直接加载该增量，不重新训练。

预算（每个类别的会话）：300 次工具调用、50 次 rollout、25 个不同的候选编辑（含局部微调和提交）、2,000 个真实环境步。
teacher token 只设失控上限：每个会话输入 60M、输出 3M；较早的工具结果在对话中压缩为摘要，最近 20 条保留全文。用量照实记录。

会话安排：
- 五个类别各一个会话，并行；
- 一个**整合会话**：看到五份提交，可以调整各编辑的系数、删去某些编辑或改用组合，在全部诊断配对上验证，产出最终的**部署编辑**。预算：100 次工具调用、30 次 rollout、10 个候选编辑、1,000 个环境步。

## 4. 条件

所有条件都作用在同一个合并后的 θ₀ 上，只用诊断集的信息。

| 条件 | 内容 | 超参如何定 |
|---|---|---|
| E0 | 不改 | — |
| E1 | teacher 手术：整合会话的部署编辑 | teacher 自定 |
| E2 | 随机对照：与 E1 结构相同（同样的层、模块、秩、系数），方向随机；局部微调部分换成逐张量 Frobenius 范数相同的随机增量；5 个种子 | 与 E1 相同 |
| E3 | 固定规则方向：每个类别取诊断集上 h(s, a_f) − h(s, a_r) 的均值（original_thought 前缀，teacher-forcing 动作 token 位置），在第 20–41 层的 down_proj 上去方向，五个类别依次作用 | α ∈ {0.25, 0.5, 1.0}，按诊断配对 rollout 成功率选 |
| E5 | 不经 teacher 的自动定位微调：对诊断配对的 −log p(a_r \| s) 求梯度，按跨配对的信噪比取前 25% 的张量，在其上训练 LoRA（秩 16） | 学习率 ∈ {1e-5, 3e-5, 1e-4} × 步数 ∈ {50, 200}，按诊断配对 rollout 成功率选 |
| E4 | 用同样的修复数据做 SFT：从 θ₀ 继续训练（v0 训练配方），数据只含诊断集配对所在的修复 episode（R 桶）和 K20 种子轨迹（D 桶），桶概率按 v0 的 .50 : .10 归一化为 5/6 : 1/6，更新步数 = ⌈4 × 行数 / 16⌉，全部 LoRA 张量，然后合并 | 固定配方，不调 |

参照（不参与判定）：v0 第一轮训练后的模型（D-data 69.3%、对照 A 71.4%、对照 B 69.3%），它们用的数据多得多。

## 5. 评测（由我们执行，teacher 不参与）

- **M1 留出失败状态**：测试集（约 57 对）每个配对从 s 起 greedy rollout，成功率；同时报告决策翻转率（分母为 θ₀ 能复现 a_f 的配对）。
- **M2 整题**：K20 第一轮的 71 个合成留出题和 20 个 K20 原题，从初始状态 greedy rollout，成功率。
- **M3 附带伤害**：从 S 桶学生成功轨迹中抽 200 个决策，greedy 动作被改变的比例。
- **M4 dev140**：每个条件的最终权重导出为完整模型，用 vLLM 直接加载（不走 LoRA 路径），hpg B200，greedy，BATCH_INVARIANT=1，其余与 baseline 评测一致。E0（合并后的 θ₀）在同一路径上评测，作为 E 系列的参照；与 LoRA 路径的 θ₀（78/140）对比，作为路径一致性检查。
- E2 的 5 个种子在 M1–M4 上都评测，报告均值和逐种子结果。
- M1、M2、M3 用 HF bf16 前向（与 P0 相同的工具），全部在 hpg B200 上运行。

## 6. 判定（按点估计；显著性只在附录报告）

用户 11-05 要求现阶段不以显著性作门槛。噪声参照：dev140 两次评测 θ₀ 相差 3 个百分点（78 vs 81）。

- **teacher 手术"真的好"**，需同时满足：
  1. dev140 上 E1 比 E0、E2（种子均值）、E3、E5 都高至少 3 个百分点；
  2. M1 上 E1 比 E0、E2、E3、E5 都高至少 5 个百分点；
  3. dev140 上 E1 不低于 E4；
  4. M3 附带伤害 ≤ 5%，K20 原题成功率不下降。
- 只满足 1、2、4，不满足 3：手术优于其他编辑方式，但不如直接用同样数据训练。
- 1 或 2 不满足：在现有数据上，teacher 定位改权重没有优于简单做法；与 P0、D-param 的结论一致。
- 不论结果如何，全部条件与指标照实报告。
