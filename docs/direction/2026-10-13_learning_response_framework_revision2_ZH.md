# 面向持续学习的经验充分性：响应谱、预测状态与信息获取的统一框架

**版本：2026-10-14，第二次修订。** 修订基础为 2026-10-13 稿、针对该稿的评审及作者关于“经典理论的原创组合”的意见。项目证据仍固定于 [86586984a4121514fc2e38e20ee772f52245a7bf](https://github.com/XueqiC/ICML27_agent_distillation/tree/86586984a4121514fc2e38e20ee772f52245a7bf/theoretical_framework)，没有把后续未知结果补写为事实。本稿是完整的独立修订提案，尚未合并进仓库。原稿公式 (1)–(43) 保留，新增结果使用 (R1)–(R20)，便于对照。附录提供两组实际运行过的合成数学核验代码与结果。

## 0. 修订结论：以持续学习充分性为问题，以响应算子为统一对象

**核心问题是：world model / 经验生成器必须保留哪些环境差异，才能让指定学生继续学习，并在真实任务上保持结果？这些差异能否在有限获取和计算预算下识别、持续维护并编译成合法反馈？**

这里的“持续”指多步训练过程中仍然充分，不特指某一种 continual learning 基准。学习响应算子仍贯穿全文；其谱衡量反馈差异对后续任务的增益，预测状态约束这种信息在未来更新中的闭合，信息理论与合法反馈集合共同约束它能否被获取和实现。

### 0.1 正确的新颖性标准

经典定理的组合、问题转化和应用方式本身可以构成原创贡献，**不需要每条引理都是新数学**。应检查的是：组合是否提出了已有框架未充分处理的问题，连接是否推导出新的可用结论，以及这些结论能否改变方法与实验判断。“组件都有经典来源”不足以判定框架不新；仅将几个经典名词放在一起也不足以证明独创。

本稿以一个连接而非定理数量组织贡献：在后续学习测试封闭时，

\[
\boxed{\text{反馈响应}=\text{未来任务可观测性}\circ\text{下一步学习预测状态变化}.}
\]

其精确版本是第 4.4 节 \(\mathcal R_z=C\mathcal T_z\) 与零空间等价。它使压缩目标、动态状态和查询目标拥有同一含义：保留那些合法反馈能够改变、未来任务能够看见、现有证据尚未充分识别的学习差异。

**可以主张的组合贡献候选**是“可获取、可更新、可实现的学习充分接口”。这个整体是否足够独创，仍需与 machine teaching、value-directed compression、PSR、datamodels 和学习算法压缩逐项比较；本稿不把针对性文献检索当作不存在先例的证明。

### 0.3 论文主张应如何收紧

建议主张：**相对于学习过程的充分性应在未来学习操作下保持闭合；响应算子给出该接口的任务几何，完整优化器记忆决定其结构，信息与可实现性决定其可获得性，成本与漂移条件决定其可用性。**

这比“对响应矩阵做 SVD”多了明确的结构与决策后果。与此同时，一般理论不保证实际系统低秩、不保证长程可预测、不保证便宜估计，也不保证优于现有数据选择方法。论文强度应由这些条件在真实学习系统中是否成立、组合方法是否在总成本下带来收益来支撑，而不是凭完整性认定 ICML best paper 级别。

建议主文优先呈现第 4.4、5.3、3.4–3.5、8.5 节，并由第 6.4 节的综合保证连接；其余经典推导、范围证书和假设审计支撑主线，可移至论文附录。本文件保留完整推导以便评审。

## 1. 从第一性原理确定系统边界

固定环境与评价机制 \(E\)、训练预算 \(R<\infty\)、任务结果 \(F_E\in[0,1]\)。结果可以是多任务得分的预先固定加权平均。若原始收益无界，需要先另行处理尾部或归一化，不能直接沿用本文的范围型证书。

完整状态记为

\[
Z_t=(\theta_t,m_t,v_t,t,\text{buffer}_t,\text{sampler}_t,\text{必要交互历史}).
\]

这不是假设原始观察满足 Markov 性。必要时使用完整历史，使条件分布有定义；这个数学状态可能很大，实际算法是否能压缩它是后面要解决的问题。隐藏环境状态不要求被算法直接读取。

反馈消息 \(Y_t\) 可以是一条轨迹、标签、批次或其他实际允许的训练输入。完整更新

\[
Z_{t+1}=U_t(Z_t,Y_t,\Xi_t)
\]

只要求可测。允许非线性、裁剪、离散操作、冷启动 Adam、非平稳学习率以及状态依赖随机性。随机种子状态若影响未来，须纳入状态；以下的条件更新核已包含这些相关性。

反馈协议 \(P\) 通过 \(P_t(dy\mid z)\) 产生消息，诱导核

\[
K_t^P f(z)=\mathbb E[f(U_t(z,Y_t,\Xi_t))\mid Z_t=z;P].
\]

若随机性与消息耦合，使用真实条件核 \(\Xi_t\mid z,y\)，不强行假设独立。目标为

\[
L(P)=\mathbb E_P F_E(Z_R).
\]

比较协议时，环境、起点分布、评价器以及已声明的训练机制相同。若它们不同，差异必须显式加入输入或核。比较模型预训练知识时，同样必须固定双方可用的先验信息 \(I_0\)；“后处理不增加环境信息”是条件于 \(I_0\) 的陈述，不表示预训练模型没有外部知识。

**主线最低条件仅为：有限预算、可测的真实条件核、有界任务结果、明确的比较范围。** 文本 token 独立、梯度平稳、小步长、低秩、全局收缩、Fisher 非退化和已知隐藏状态均不在其中。

### 定理 1：精确学习后果恒等式〔精确；原 §3 的保留核心〕

设参考协议为 \(P^0\)，替代协议为 \(P^S\)。定义

\[
V_R^0=F_E,\qquad V_t^0=K_t^0V_{t+1}^0,
\]

以及固定检查点 \((t,z)\) 的精确消息响应

\[
g_{t,z}(y)=\mathbb E[V_{t+1}^0(U_t(z,y,\Xi_t))\mid z,y].
\tag{1}
\]

则

\[
\boxed{L(P^0)-L(P^S)
=\sum_{t=0}^{R-1}\mathbb E_{Z_t\sim d_t^S}
\int g_{t,Z_t}(y)\,[P_t^0-P_t^S](dy\mid Z_t).}
\tag{2}
\]

**证明。** 在替代协议轨迹上对 \(V_t^0(Z_t)\) 作望远镜求和，再使用 \(V_t^0=K_t^0V_{t+1}^0\)。条件期望将每一项化为 \((K_t^0-K_t^S)V_{t+1}^0\)。没有 Taylor 展开。□

若仅在认证状态集 \(\mathcal C_t\) 中有局部误差界 \(\beta_t(z)\)，令 \(\tau\) 为替代轨迹首次离开这些集合的时刻，未离开则 \(\tau=R\)。停止上述求和可得

\[
|L(P^0)-L(P^S)|\le
\mathbb E_S\sum_{t<\tau}\beta_t(Z_t)+\Pr_S(\tau<R).
\tag{3}
\]

定理 1 是精确的后果核算恒等式。它本身不预测误差很小；若估计其全部项比直接比较两个协议还贵，就没有独立的计算优势。其价值在于为可复用接口、机制分析与获取设计提供统一目标。

停止点后的两个条件价值都在 \([0,1]\)，所以退出代价只支付一次。原协议的访问分布不能直接替代式 (2) 中的 \(d_t^S\)。这正是反馈改变训练轨迹后会出现的覆盖问题。

## 2. 学习响应算子及其谱

### 2.1 为什么先固定检查点

在一个固定 \((t,z)\) 上，令 \(a\in\mathcal A\) 索引事先声明的“任务结果＋后续训练协议”测试。记

\[
g_a(y)=\mathbb E[\text{测试 }a\text{ 的最终真实得分}\mid z,\text{本轮输入 }y].
\]

这里可改变后续训练时长、任务和合法训练计划。若只放一个标量测试，则算子秩至多为 1；这个低秩几乎没有科学内容。想讨论一般性，需要预先声明有意义的多测试集合。

选择消息参考概率测度 \(\rho\) 和测试权重概率测度 \(\omega\)。在标准可测空间上定义

\[
\mathcal H=L_0^2(\rho)=\{h:\mathbb E_\rho h=0,\ \mathbb E_\rho h^2<\infty\},
\quad \widetilde g_a=g_a-\mathbb E_\rho g_a,
\]

\[
\boxed{(\mathcal R h)(a)=\langle \widetilde g_a,h\rangle_\rho.}
\tag{4}
\]

当反馈分布 \(P,Q\) 对 \(\rho\) 的密度属于 \(L^2\)，取 \(h=dP/d\rho-dQ/d\rho\)，式 (4) 就是两种反馈在所有测试上的精确得分差。

**线性来自概率混合的期望运算，不来自学习器的线性化。** \(U\) 可以完全非线性。不同状态的条件反馈差异通常不同；不能把多个检查点的响应行堆在一起，再偷偷假设它们共享一个与状态无关的 \(h\)。跨状态分析应逐状态应用式 (4)，或者显式使用 \(h(z,y)\) 的条件算子。第 3.4 节给出允许堆叠响应行、学习共享特征而不偷换输入的正确版本。

由于 \(0\le g_a\le1\)，有

\[
\|\mathcal R\|_{\mathrm{HS}}^2
=\mathbb E_{a\sim\omega}\operatorname{Var}_{y\sim\rho}g_a(y)
\le\frac14.
\tag{5}
\]

因此 \(\mathcal R\) 是 Hilbert–Schmidt 算子，存在奇异分解

\[
\mathcal R h=\sum_{j\ge1}\sigma_j\langle v_j,h\rangle_\rho u_j,
\qquad \sigma_1\ge\sigma_2\ge\cdots\ge0.
\tag{6}
\]

这里的紧性由有界得分和概率测度推出；没有假设有限秩。但谱衰减是否足够快、是否允许有用的压缩，仍是待测的结构事实。

### 定理 2：谱充分性与线性接口复杂度〔精确；经典逼近理论的实例化〕

令模式差异 \(\alpha_j=\mathbb E_Pv_j-\mathbb E_Qv_j\)。则

\[
\|\mathcal R h\|_{L^2(\omega)}^2
=\sum_j\sigma_j^2\alpha_j^2.
\tag{7}
\]

若前 \(r\) 个模式均匹配，且 \(\|h\|_\rho\le B\)，则

\[
\|\mathcal R h\|_{L^2(\omega)}\le B\sigma_{r+1}.
\tag{8}
\]

若只满足 \(|\alpha_j|\le\delta_j\)，则

\[
\|\mathcal R h\|_{L^2(\omega)}^2
\le\sum_{j\le r}\sigma_j^2\delta_j^2+B^2\sigma_{r+1}^2.
\tag{9}
\]

在放宽的有符号输入球 \(\{h\in\mathcal H:\|h\|\le B\}\) 上，最优秩 \(r\) 线性预测接口的最坏重建误差恰为 \(B\sigma_{r+1}\)。因此可定义相对于 \((\rho,\omega,B)\) 的线性接口复杂度

\[
r_\varepsilon=\min\{r:B\sigma_{r+1}\le\varepsilon\}.
\tag{10}
\]

**证明。** 式 (7) 是输出奇异向量的正交性；式 (8)–(9) 是尾部特征值上界。上界由截断 SVD 实现。任意秩不超过 \(r\) 的线性预测算子，在 \(\operatorname{span}(v_1,\ldots,v_{r+1})\) 上都有非零零空间向量；对其归一化，真实输出范数至少为 \(\sigma_{r+1}\)。即使允许非线性解码器，只要编码端是 \(r\) 个线性统计量，利用对称的两个零空间输入也得到相同最坏情形下界。□

这个最优性不能直接变成“任何概率分布、任何压缩算法都至少需要 \(r\) 个数字”。概率密度必须非负；一般非线性编码、无限精度实数编码与有限位复杂度不在上述结论内。

一个无需额外谱衰减假设的推论是：由式 (5)，

\[
(r+1)\sigma_{r+1}^2\le\sum_j\sigma_j^2\le\tfrac14,
\qquad B\sigma_{r+1}\le\frac{B}{2\sqrt{r+1}}.
\]

因此，在固定密度差预算 \(B\) 与加权均方后果度量下，\(r+1\ge B^2/(4\varepsilon^2)\) 是误差不超过 \(\varepsilon\) 的一个**充分维数上界**，不是必要维数，也不保证非平凡压缩。

尤其是对式 (12) 的 \(J\) 个候选混合测度，只知道最坏界 \(B^2\le2J\)。代入保守选择 \(B^2=2J\) 后需要 \(r+1\ge J/(2\varepsilon^2)\)；若 \(\varepsilon<1/\sqrt2\)，所需维数已超过候选混合差异至多 \(J-1\) 维的有效输入空间。因此，**这一通用界在该口径下通常没有压缩内容**，不能作为“无需结构即可有效压缩”的主张。实际 \(B\) 可以小于 \(\sqrt{2J}\)，实际谱也可能更快衰减；有用压缩须依赖这些可验证事实、明确受限的候选类，或其他逼近结构。它也不保证逐任务保真、低成本特征学习、合法编译和跨状态复用。

### 命题 2.1：概率可行的局部下界

若消息集合有 \(m\) 个元素，\(\rho_y>0\)，且 \(0\le r<m-1\)，则对任意 \(r\) 个线性消息特征，存在单位 \(v\in\operatorname{span}(v_1,\ldots,v_{r+1})\)，使其与这些特征及常数正交。对

\[
P_y=\rho_y(1+av_y/2),\quad Q_y=\rho_y(1-av_y/2),
\quad 0<a\le 2/\|v\|_\infty,
\tag{11}
\]

\(P,Q\) 是概率分布、特征均值相同，而

\[
\|\mathcal R(dP/d\rho-dQ/d\rho)\|\ge a\sigma_{r+1}.
\]

统一选择 \(a\le2\sqrt{\rho_{\min}}\) 足以确保非负。这个比例常数揭示了支持覆盖的成本，不能省掉后宣称全局概率最优性。

### 2.2 不应隐藏的测度选择

对有限候选反馈分布 \(P^1,\ldots,P^J\)，可取

\[
\rho=J^{-1}\sum_{j=1}^J P^j.
\tag{12}
\]

于是每个候选及其凸混合的密度不超过 \(J\)，任意两者的差满足 \(\|h\|_\rho^2\le2J\)。这是由有限候选集构造出来的条件，不必假设现实世界有全局有界密度比。对只有两个分布的等权混合，有 \(\|h\|^2\le4\)。新消息、新候选或新的支持出现时，须重建覆盖或另付误差。

谱依赖 \(\rho\)、\(\omega\)、任务、优化器状态和未来协议；它不是模型的一组永恒常数。改变权重后比较谱，需要报告权重变化。参数坐标的可逆重参数化若保留相同实际过程和测试，不改变这个以可观察后果定义的算子；改变输入或输出的度量则会改变奇异值。

### 2.3 平均小误差与逐任务保证

令

\[
b_j(a)=\langle\widetilde g_a,v_j\rangle_\rho,\quad
e_r(a)=\left\|\widetilde g_a-\sum_{j\le r}b_j(a)v_j\right\|_\rho.
\]

逐测试有

\[
\boxed{|\mathbb E_P g_a-\mathbb E_Qg_a|
\le\left|\sum_{j\le r}b_j(a)\alpha_j\right|+B e_r(a).}
\tag{13}
\]

这是后续训练保证应使用的版本。有限测试集若 \(\omega_a>0\)，也可以把平均误差除以 \(\sqrt{\omega_a}\) 得到该测试的界；稀有测试会付出大代价。连续测试集的平均界不能直接控制任意单点。一个权重为 \(10^{-6}\)、误差为 1 的任务，只贡献 \(10^{-3}\) 的均方根误差。

原 §4 的统一范数结论因此仍有价值：若每个响应可由特征统一逼近到 \(\epsilon\)，匹配特征的任意两概率分布，其得分差不超过 \(2\epsilon\)，无需 \(L^2\) 密度条件。SVD 是一个有明确度量的可计算选择，不取代所有其他逼近范数。

### 2.4 它与“频率”的准确关系

响应核

\[
k(y,y')=\mathbb E_{a\sim\omega}[\widetilde g_a(y)\widetilde g_a(y')]
\]

定义 \(\mathcal R^*\mathcal R\)，其特征值是 \(\sigma_j^2\)。两个消息在许多后续测试中产生相近后果，就会在该核中相近。这提供内生的“后果几何”。但核的非对角项可以为负，它不自动是图邻接矩阵；\(\sigma_j\) 也不自动是图 Laplacian 频率。

| 经典谱概念 | 排序的含义 | 在本框架中的地位 |
|---|---|---|
| 图 Laplacian 特征值 | 相邻节点间的振荡能量 | 只有先有合理图结构时才可额外引入 |
| \(\mathcal R\) 的奇异值 | 单位反馈差异造成的任务后果增益 | 贯穿全文的主对象 |
| 控制系统 Hankel 奇异值 | 既能被输入激发、又能被未来输出看见的方向 | 第 4–5 节中的动态对应物 |
| 信息白化后的响应奇异值 | 后果重要性相对于可识别信息的大小 | 第 8 节中的查询难度；不等于原始 \(\sigma_j\) |

因此应保留“大响应增益模式”，而不能不加论证地说“保留低频”。原 §4.6 中的 Chebyshev 多项式和 Boolean Fourier 度数可以作为具有额外代数结构的例子；多项式次数高也不等于需要很多任意特征，例如 parity 本身就可以作为一个特征。

若任务确实提供了有操作含义的消息扰动核 \(N\)，且它以 \(\rho\) 为平稳测度并满足详细平衡，可以定义 \(L=I-N\)。此时

\[
\langle\phi,L\phi\rangle_\rho
=\tfrac12\mathbb E_{Y\sim\rho,Y'\sim N(Y)}(\phi(Y)-\phi(Y'))^2
\]

是真正的扰动粗糙度，\(L\) 的特征值可解释为相对于该扰动的“频率”。在有限消息空间，只有当 \(L\) 与 \(\mathcal R^*\mathcal R\) 对易时，才能选到同时描述频率与后果增益的共同特征基；一般情况下两种排序不同。扰动核的选择须来自实际问题，不能仅为借用低频直觉而任意添加。Boolean Fourier/noise stability 对 datamodels 的应用已有 [R22]；本稿不主张首次把频率用于训练数据影响。

## 3. 如何估计谱，以及统计代价在哪里

### 3.1 冻结有限测试与反馈目录的证书

固定 \(p\) 个测试、\(m\) 个合法反馈输入，权重 \(w_i,q_j>0\) 且各自和为 1。令 \(G_{ij}\) 是完整运行后的期望得分。一次反馈列也可以是一种可执行反馈提供者；此时是对提供者的混合权重做压缩，不能同时声称识别了其内部所有消息模式。

使用每格 \(n\) 个独立复现实验估计 \(G_{ij}\)。同一复现内允许不同列共享随机数；独立性要求是跨复现，而非假设 token 独立。对 \(\Pi_q=I-\sqrt q\sqrt q^\top\)，加权中心化矩阵为

\[
M=D_{\sqrt w}G D_{\sqrt q}\Pi_q.
\tag{14}
\]

以至少 \(1-\delta\) 的概率，所有元素同时满足

\[
|\widehat G_{ij}-G_{ij}|\le
\epsilon_n=\sqrt{\frac{\log(2pm/\delta)}{2n}}.
\tag{15}
\]

因为权重归一化，加权 Frobenius 误差不超过 \(\epsilon_n\)，中心化投影不扩张范数，所以

\[
\|\widehat M-M\|_{\mathrm{op}}\le\epsilon_n,
\quad |\widehat\sigma_j-\sigma_j|\le\epsilon_n.
\tag{16}
\]

令 \(\widehat\Pi_r\) 投影到估计的前 \(r\) 个右奇异向量，则

\[
\|M(I-\widehat\Pi_r)\|_{\mathrm{op}}
\le\widehat\sigma_{r+1}+\epsilon_n
\le\sigma_{r+1}+2\epsilon_n.
\tag{17}
\]

**证明。** 第一项用逐格 Hoeffding 与并合界；矩阵不等式用 Frobenius 范数和三角不等式；末式再用奇异值扰动界。□

这不需要谱间隙。只有把某个估计方向解释成唯一稳定的“第 \(j\) 个机制”，才需要间隙或对子空间整体做解释。

若从 \(\widehat G\) 构造逐行系数和残差，则真实响应差还须加 \(2\epsilon_n\)：两概率分布对逐点估计误差的积分差不超过该数。因此有限目录中的可检查式为

\[
\beta_i\le\left|\sum_{j\le r}\widehat b_j(i)\alpha_j\right|
+B\widehat e_r(i)+2\epsilon_n.
\tag{18}
\]

式 (18) 中的 \(\alpha_j\) 是真实特征均值差。若只知道估计值 \(\widehat\alpha_j\) 与同时有效的误差界 \(\eta_j\)，右侧还需加上 \(\sum_{j\le r}|\widehat b_j(i)|\eta_j\)，并将第一项中的 \(\alpha_j\) 换成 \(\widehat\alpha_j\)。匹配样本均值不等于已经匹配真实均值。

未观测的新列、新任务、新状态不受式 (15) 自动保护。低秩也不自动保证少量随机格子即可完成矩阵：某个重要方向可能只出现于一个极少采样的格子。任何矩阵补全、泛化或离策略外推都需要另外的覆盖条件。

### 3.2 有限样本下的谱截断选择

若算子和特征已知或已用独立样本冻结，从 \(P,Q\) 各抽取 \(n\) 个独立消息估计 \(\alpha_j\)，定义

\[
\widehat f_r=\sum_{j\le r}\sigma_j\widehat\alpha_j u_j.
\]

则

\[
\mathbb E\|\widehat f_r-\mathcal Rh\|^2
=\sum_{j\le r}\frac{\sigma_j^2}{n}
\left(\operatorname{Var}_P v_j+\operatorname{Var}_Q v_j\right)
+\sum_{j>r}\sigma_j^2\alpha_j^2.
\tag{19}
\]

证明只用均值估计的无偏性与输出方向的正交性，不要求不同模式的噪声独立。式 (19) 给出截断偏差与采样方差的实际权衡。若谱和模式从同一数据中选择，不能原样套用固定特征公式，须样本分割、交叉拟合或另做统一控制。

这个表达式不包含学习 \(g_a\) 自身的成本。获得响应矩阵可能需要大量真实后续训练；“接口维数低”不能被宣传成“端到端样本成本必然低”。特别是只需评估单个已知测试时，直接估计其得分可能更便宜。

### 3.3 CRN、选择与 surrogate 的位置

共享随机数通常有助于比较，但方差下降不是无条件定理：配对差方差取决于协方差。每一侧的边缘分布必须仍然对应真实实验；强行让状态依赖过程消费相同数据、从而改变边缘分布，会改变估计目标。

先冻结候选与审计设计，再使用同时置信界选择，可避免在同一批有限候选中择优造成的遗漏。若不断根据审计数据生成新候选，要么使用新的确认样本，要么采用适合自适应过程的置信序列/统一复杂度分析；原先的固定候选并合界不足。只对旧候选建立置信序列，也不能自动覆盖事后生成的新候选；其条件有效性或全候选类控制仍需证明。

短尾或 log-likelihood surrogate 只能估计相应的 surrogate 响应。到真实任务的转移需要独立成立的校准误差界。把校准集上的最大残差当作所有未来状态的确定性上界，或用观测样本极差代替总体支持范围，均不能产生原声称的严格证书。

### 3.4 跨检查点共享接口：可以堆叠，但必须保留条件输入

选择共同的合法消息空间、参考测度 \(\rho\) 和具有相同语义的测试集合。不同剩余预算必须作为测试标签说明，不能把不同含义的行误当同一个测试。记各检查点的响应为 \(\mathcal R_z\)，实际反馈差异为 \(h_z=dP_z/d\rho-dQ_z/d\rho\)。共享的是消息特征 \(\phi(y)\)，不是反馈分布，也不是 \(h_z\)。若消息合法性随状态变化，可使用共同合法池或事先声明的拒绝机制；改变支持后不能沿用原覆盖保证。

**命题 3.2：共享特征的条件响应界〔精确；算子逼近的组合应用〕。** 给定状态权重 \(\nu\)，定义堆叠算子

\[
(\mathcal S h)(z,a)=(\mathcal R_z h)(a).
\tag{R1}
\]

其前 \(r\) 个右奇异向量张成投影 \(\Pi_r\)。若 \(\|h_z\|_\rho\le B\) 对 \(\nu\)-几乎处处状态成立，则

\[
\mathbb E_{z\sim\nu}\|\mathcal R_z(I-\Pi_r)h_z\|_\omega^2
\le B^2\sum_{j>r}\sigma_j(\mathcal S)^2.
\tag{R2}
\]

而 \(\Pi_r\) 在所有 \(r\) 维共享线性消息接口中，最小化
\(\mathbb E_\nu\|\mathcal R_z(I-\Pi)\|_{\rm HS}^2\)。

**证明。** 逐状态使用 \(\|Ah\|\le\|A\|_{\rm HS}\|h\|\)，再积分；堆叠后的 Hilbert–Schmidt 截断残差恰为奇异值平方尾和。最优性是对这个平均残差目标的 Eckart–Young 最优性，不是对任意状态访问分布的 minimax 最优性。□

这里必须使用尾和，不能未经证明换成 \(B^2\sigma_{r+1}(\mathcal S)^2\)。例如两个等权状态的响应分别为行向量 \((1,0)\)、\((0,1)\)，各自输入取对应单位向量，不压缩时实际 RMS 为 1，而堆叠算子的最大奇异值只有 \(1/\sqrt2\)。两者可同比缩放以满足有界响应范围，反例不变。这修正的是跨状态范数，**不是禁止用多状态数据学习共享特征**。

\(\nu\) 上平均小误差仍然不保证实际训练访问的每个状态准确。若不能控制访问分布相对于 \(\nu\) 的覆盖，就应使用下一项逐检查点保证或第 6.2 节的退出代价。

**命题 3.3：锚点接口复用〔条件性；不要求谱间隙〕。** 在锚点 \(z_0\) 上已有 \(\|\widehat{\mathcal R}_{z_0}-\mathcal R_{z_0}\|_{\rm op}\le\epsilon_0\)，令 \(\widehat\Pi_r\) 是估计算子的前 \(r\) 个输入模式。若
\(\|\mathcal R_z-\mathcal R_{z_0}\|_{\rm op}\le\Delta_z\)，则

\[
\|\mathcal R_z(I-\widehat\Pi_r)\|_{\rm op}
\le\widehat\sigma_{r+1}(z_0)+\epsilon_0+\Delta_z.
\tag{R3}
\]

**证明。** 将 \(\mathcal R_z\) 分成锚点估计、锚点估计误差与跨检查点差异，使用三角不等式和投影算子范数不超过 1。□

这允许在模式本身发生旋转、甚至奇异值重合时复用预测接口；解释某一根奇异向量的身份才另需间隙。多个锚点时可选认证上界最小者；若选择使用同一审计数据，须让所有候选锚点的置信事件同时成立。

**如何获得可检查的 \(\Delta_z\)，而非另加全局 Lipschitz 假设。** 冻结两个检查点，独立抽取 \(y_i\sim\rho\)，在每个点按正确边缘协议运行同一组测试，得到配对有界输出向量 \(X_z^{(i)},X_0^{(i)}\in[0,1]^p\)。同一复现允许 CRN，跨复现独立。令

\[
W_i=\|X_z^{(i)}-X_0^{(i)}\|_\omega^2\in[0,1].
\]

条件 Jensen 不等式与中心化不扩张范数给出

\[
\|\mathcal R_z-\mathcal R_{z_0}\|_{\rm op}^2
\le\mathbb E_\rho\|g_z(y)-g_0(y)\|_\omega^2
\le\mathbb E W_i.
\]

因此，对 \(M\) 个事先冻结的检查点配对同时以至少 \(1-\delta\) 的概率，可取

\[
\boxed{\widehat\Delta_z=
\sqrt{\min\!\left\{1,\ \overline W_z+
\sqrt{\frac{\log(M/\delta)}{2n}}\right\}}.}
\tag{R4}
\]

在该置信事件上，\(\|\mathcal R_z-\mathcal R_{z_0}\|_{\rm op}\le\widehat\Delta_z\)，可将它作为式 (R3) 的 \(\Delta_z\)。式 (R4) 是有限范围内的严格转移证书；它使用 \(n\) 个随机消息配对，而不要求重新填写整个消息目录。代价仍是每个独立续训分支约 \(2n\) 次训练，CRN 失效时过程噪声会使上界很松；在零漂移附近，简单 Hoeffding 版本的半径可能只有 \(n^{-1/4}\) 量级。它**没有无条件解决廉价迁移认证**，但把迁移条件落实成了可执行、可拒绝的实验。

模式均值匹配时，式 (R3) 乘 \(B_z\) 给出新状态的加权 RMS 误差；不完全匹配时另加保留模式的响应误差。若最终保证针对某个有限测试 \(a\)，可除以 \(\sqrt{\omega_a}\) 转成逐测试界，或直接审计该行；不能把 RMS 界直接当作该任务的界。

### 3.5 可负担估计：短续训用于校正，而不自动替代真实目标

短续训是否保留完整训练的排序是实质问题。我们采用多保真控制变量的经典思想 [R24–R25]，把它与响应估计结合：允许便宜预测有偏，但用少量完整续训估计其偏差。收益来自配对相关性，不来自“短训练必然足够”的假设。

**命题 3.4：无偏响应估计及成本条件〔精确；经典多保真估计的任务化应用〕。** 固定检查点、候选、目标测试与一个已冻结的便宜估计器。设完整续训输出 \(X\in[0,1]^p\)，便宜输出 \(Y\in[0,1]^p\)，目标 \(f=\mathbb E X\)。便宜估计器可以是短续训、经过裁剪的代理、或带学习器状态的预测器。用两组相互独立的样本定义

\[
\widehat f=
\frac1{n_0}\sum_{i=1}^{n_0}Y_i
+\frac1{n_1}\sum_{i=1}^{n_1}(X_i'-Y_i').
\tag{R5}
\]

第二组内部将完整与便宜输出耦合，且 \(Y_i'\) 与第一组的 \(Y_i\) 边缘分布相同。条件于已冻结的设计，

\[
\mathbb E\widehat f=f,\qquad
\mathbb E\|\widehat f-f\|_\omega^2
=\frac{v_0}{n_0}+\frac{v_1}{n_1},
\quad
v_0=\mathbb E\|Y-\mathbb EY\|_\omega^2,
\quad v_1=\mathbb E\|(X-Y)-\mathbb E(X-Y)\|_\omega^2.
\tag{R6}
\]

**证明。** \(\mathbb EX=\mathbb EY+\mathbb E(X-Y)\)。两个样本均值独立，交叉项期望为零；向量坐标间可以相关。□

设每次便宜样本的总成本为 \(c_0\)，每次配对完整样本的总成本为 \(c_1\)，后者包含对应的便宜计算。若中间计算可复用，则使用实际复用后的成本。给定方差、忽略整数取整，达到 MSE 不超过 \(\varepsilon^2\) 的最小采样成本及分配为

\[
S=\sqrt{v_0c_0}+\sqrt{v_1c_1},\qquad
n_\ell=\frac{S}{\varepsilon^2}\sqrt{\frac{v_\ell}{c_\ell}},
\qquad
\boxed{C_{\rm MF}=\frac{S^2}{\varepsilon^2}.}
\tag{R7}
\]

证明由 Cauchy–Schwarz：
\((\sum c_\ell n_\ell)(\sum v_\ell/n_\ell)\ge(\sum\sqrt{v_\ell c_\ell})^2\)，上述分配取等。取 \(\max\{1,\lceil n_\ell\rceil\}\) 增加的成本至多为 \(c_0+c_1\)；方差为零但常数均值未知时仍至少取一个样本。

若完整采样方差为 \(v_H\)、单位成本为 \(c_H\)，在相同 MSE 和相同连续分配口径下，省计算的充要条件为

\[
\boxed{\sqrt{v_0c_0}+\sqrt{v_1c_1}<\sqrt{v_Hc_H}.}
\tag{R8}
\]

这只是估计器之间的成本结论，不是对 LESS、TRAK 或整个蒸馏算法的优势定理。低秩只描述均值响应；若便宜预测在固定消息下是常数，它不会降低完整训练的条件随机方差。要省完整复现，必须有可利用的配对相关性，或对随机消息的综合目标减少消息间的变化。代理训练、方差试验和最终认证都必须计入总成本。

**未知方差与严格证书。** 式 (R7) 的 oracle 分配不是免费可用的。可用独立 pilot 估计方差、冻结样本量，再用新样本确认。对总体范围宽度为 \(L\) 的标量 \(Z\)，pilot 中 \(k\) 个独立样本对给出

\[
\widehat v=\frac1k\sum_{i=1}^k\frac{(Z_{2i}-Z_{2i-1})^2}{2},\qquad
v\le\widehat v+\frac{L^2}{2}\sqrt{\frac{\log(1/\delta_v)}{2k}}
\tag{R9}
\]

的 \(1-\delta_v\) 上界，因为被平均的量在 \([0,L^2/2]\) 且期望为方差。对向量使用加权平方范数也得到加权总方差的同类界。用估计方差得到的是估计分配；若要认证式 (R8) 成立，需对其左侧用有效上界、右侧用有效下界，并控制联合覆盖，不能只比较点估计。pilot 开销可能抵消省下的计算，不能省略。

不使用任何方差估计时，对预先冻结的共 \(N\) 个标量响应，同时有效的保守误差半径为

\[
\eta=\sqrt{\frac{\log(4N/\delta)}{2n_0}}
+2\sqrt{\frac{\log(4N/\delta)}{2n_1}},
\tag{R10}
\]

因为 \(Y\in[0,1]\)、\(X-Y\in[-1,1]\)。可将有效的方差上界代入 Bernstein 界以求更紧认证，但 MSE 的成本优势不会自动变成严格证书优势。若直接估计两个协议的得分差，各变量范围相应扩大，必须重新设置半径。用同一批样本选择代理或系数，再把它当作已冻结，不能直接套用式 (R5)–(R10)。

**与谱学习和重复使用如何组合。** 对冻结目录获得各响应的有效误差后，第 3.1 节的谱扰动界继续成立；只需将原单保真误差换成新的同时误差。先支付锚点接口学习成本 \(C_{\rm fit}\)，然后用于 \(M_{\rm use}\) 个实际决策，才有平均开销 \(C_{\rm fit}/M_{\rm use}\)；必须按真实复用次数报告，不能假定无限摊销。跨检查点复用再支付式 (R4) 的校验或其他有效转移认证成本。

**纠正目录成本的计数单位。** 若 \(p\) 个测试只是同一训练模型上的 \(p\) 个部署指标，一次续训可以输出整个向量，不需要训练 \(p\) 次。设需要 \(p_{\rm train}\) 条不同的后续训练分支，\(m\) 个反馈候选、\(n\) 个复现，则完整目录需要约 \(mnp_{\rm train}\) 次续训，另计多任务评估。只有测试确实需要不同续训时，才是 \(pmn\)。按评审提供的“每次约 5 B200 GPU 小时”估算，20 个候选、4 次复现：10 个共享训练的评估指标约为 400 GPU 小时加评估；10 条不同训练分支才约为 4,000 GPU 小时。本稿未重新测量该单次成本，两种口径都不等于已经可负担。

## 4. 控制理论与预测状态：压缩必须能更新自己

### 4.1 控制输入应是什么

把学习过程本身看作受控系统。控制 \(b\in\mathcal B\) 是可执行的反馈提供者、查询方式或训练干预，状态是完整学习/交互状态，输出是预先声明的部署结果。改变学习率、优化器或任务时，应当明确它们是控制的一部分、测试的一部分，还是另一个系统；不能事后随意混用。

令 \(K_b\) 为相应真实状态转移核。将时钟放入状态，达到预算后吸收，即可处理有限时域、非平稳系统。以下不存在无限时间训练的稳定性假设。

对合法控制词 \(w=b_1\cdots b_\ell\)，定义 \(K_w=K_{b_1}\cdots K_{b_\ell}\)。任务输出为 \(F_1,\ldots,F_k\)。最小预测测试空间是

\[
\mathcal V=\operatorname{span}\{1,K_wF_j:\ w\text{ 为所声明的合法后续测试}\}.
\tag{20}
\]

测试集合需在合法前置一步后封闭；有限时域可用按剩余时长分层的空间表达。如果额外允许任意长控制词，必须通过吸收状态维持原训练预算，而不是偷偷放宽任务。

若 \(\mathcal V\) 有有限维基底 \(\psi=(1,\psi_2,\ldots,\psi_d)^\top\)，则存在矩阵 \(A_b\) 与向量 \(c_j\)，使

\[
K_b\psi=A_b\psi,\qquad F_j=c_j^\top\psi.
\tag{21}
\]

对当前状态分布 \(\mu\)，令 \(q(\mu)=\mathbb E_\mu\psi\)。则

\[
q'=A_bq,\qquad \mathbb E_\mu F_j=c_j^\top q.
\tag{22}
\]

**闭合的含义是这些预测统计量足以继续预测下一步的同类统计量。** 状态转移可以非线性；线性的是函数空间中的期望更新。有限维闭合存在时给出精确表示，但一般系统未必有低维闭合。不能把“存在小 \(d\)”列为适用于所有 agent 的默认前提。

这个不变子空间/Krylov 构造与 Poupart–Boutilier 的价值导向 POMDP 压缩有直接先例 [R2]。把输出改成“训练后的真实任务结果”、把状态扩展到完整优化器，形成本文的问题实例；不能据此宣称首次发现价值充分的动态状态。

### 定理 3：学习过程 Hankel 秩与线性预测实现〔精确；经典实现理论的实例化〕

固定初始分布 \(\mu_0\)，定义任务 Hankel 矩阵

\[
H(p,(w,j))=\mu_0 K_pK_wF_j,
\tag{23}
\]

行是控制前缀 \(p\)，列是后续测试 \((w,j)\)，并加入常数输出。测试和前缀都包括合法一步延伸；时钟与吸收机制处理预算。

实现定理要求核在所用控制目录上定义一致，并且所讨论的矩阵包含所需延伸。状态依赖的合法性须通过显式拒绝/吸收机制或分层空间处理；若只有零散合法实验形成的部分矩阵，其秩通常只提供下界，不能直接使用下面的完整实现结论。

若这整个矩阵的代数秩为有限数 \(d\)，则存在 \(d\) 维线性受控预测实现

\[
q(pb)=A_bq(p),\quad H(p,(w,j))=c_j^\top A_wq(p),
\tag{24}
\]

其中 \(A_w=A_{b_\ell}\cdots A_{b_1}\)。任何实现全部这些输入输出期望的线性表示，其维数至少为 \(d\)。

**证明。** 任意 \(d'\) 维表示将 \(H\) 分解成“前缀状态坐标”乘“未来测试系数”，所以 \(\operatorname{rank}H\le d'\)。反向取 \(H\) 的行空间为预测状态空间。前缀延伸 \(p\mapsto pb\) 诱导线性映射：若 \(\sum_i a_iH(p_i,\cdot)=0\)，则对每个 \((w,j)\)，延伸后的和为 \(\sum_i a_iH(p_i,(bw,j))=0\)。因 \((bw,j)\) 仍是合法列，该映射定义良好。选一组基底即得式 (24)，输出由空后缀列读取。□

四个边界非常重要：

1. 这是对给定初始分布和合法实验所张成的**可达预测空间**的最小性，不是对所有隐藏状态或任意非线性表示的最小性。对所有单点状态建立式 (21) 的空间可能更大。
2. 少数已观测行列组成的低秩子矩阵，不证明完整 \(H\) 低秩。需要后缀延伸检验与保留集预测；缺少激励时还会把未观测方向误判成零模式。
3. 当时间已知，应报告每个时间层的预测维数或说明时钟开销。不要把跨时间拼接造成的秩增加全解释成环境复杂度。
4. 上述开环控制词预测的是干预后的期望。要根据新观察在线更新状态，需要下一节的条件化闭合。

固定检查点的 \(g_a(y)\) 可以视为此类 Hankel 对象中的一个局部输入—后缀块：先执行当前消息，再执行未来测试。第 2 节对这个块中心化并选定权重。**局部响应谱与动态 Hankel 谱有结构联系，但一般并不是同一组奇异值。**

### 4.2 真正的 PSR：观察后也能更新

设执行控制 \(b\) 后观察到 \(o\)。离散观察情形定义次概率算子

\[
T_{b,o}f(z)=\mathbb E[\mathbf1\{O=o\}f(Z')\mid z,b].
\]

如果测试空间在所有 \(T_{b,o}\) 下闭合，且包含常数函数，则有 \(T_{b,o}\psi=M_{b,o}\psi\)。设第一坐标对应常数，\(e_1=(1,0,\ldots)^\top\)，则

\[
\boxed{q'=\frac{M_{b,o}q}{e_1^\top M_{b,o}q},\qquad
\Pr(o\mid q,b)=e_1^\top M_{b,o}q.}
\tag{25}
\]

**证明。** 分子是观察事件与下一步特征的联合未归一化期望，分母是该事件概率；按条件期望归一化即可。□

这正是预测状态表示的经典结构 [R3–R4]。对历史—未来的联合观察测试可构造对应 Hankel 矩阵；对正概率历史进行行归一化不改变其秩。若只保留开环奖励测试，可能失去式 (25) 的闭合，不能因此宣称支持任意观察自适应策略。有限观察、有限时域下，可以把策略的所有观察分支纳入测试类；一般观察空间需要相应可测积分版本与另外的估计分析。

式 (25) 的概率解释针对真实可达的预测状态 \(q\)，不表示任意 \(q\in\mathbb R^d\) 都定义合法概率分布。

不把 \(\Pr(o\mid q,b)\ge p_{\min}>0\) 列为全局基本假设。罕见观察确实可能放大条件化误差，应显式支付相关代价，或使用未归一化量进行整体期望分析。随意除以很小的估计概率再声称稳定，是不可接受的步骤。

精确表示的输出来自真实概率过程，因而概率合法；一般的截断 SVD 或任意估计矩阵不自动保正、不自动归一化，也不保证可生成真实反馈。PSR 的预测实现和消息生成器的实现是不同问题，第 7 节单独处理。

### 4.3 静态充分但动态不充分：一个必要反例

令状态 \(z=(s,b)\in\{0,1\}^2\)，当前部署得分 \(F(z)=s\)，下一次更新为 \(U(s,b)=(b,b)\)。两个状态 \((0,0)\)、\((0,1)\) 当前得分相同，但更新后得分分别为 0、1。

只保留 \(\psi=(1,s)\) 能准确预测当前结果，却不能预测下一步的同一特征，因为 \(K s=b\notin\operatorname{span}(1,s)\)。加入 \(b\) 后空间闭合。该例不依赖近似、优化器异常或分布尾部，说明动态闭合检查无法被当前低秩替代。

### 命题 3.1：近似闭合的有限时域误差〔条件性；不要求收缩〕

若对某个固定合法控制序列，有

\[
K_{b_t}\psi=A_t\psi+r_t,\qquad F=c^\top\psi+e_F,
\]

定义 \(q_t=\mathbb E\psi(Z_t)\)，模型预测 \(\widehat q_{t+1}=A_t\widehat q_t\)。则精确地

\[
q_H-\widehat q_H=A_{H-1:0}(q_0-\widehat q_0)
+\sum_{t=0}^{H-1}A_{H-1:t+1}\mathbb E r_t(Z_t),
\]

其中空矩阵乘积为单位阵。因此

\[
|\mathbb EF(Z_H)-c^\top\widehat q_H|
\le\mathbb E|e_F(Z_H)|
+\|c^\top A_{H-1:0}\|\,\|q_0-\widehat q_0\|
+\sum_t\|c^\top A_{H-1:t+1}\|\,\mathbb E\|r_t(Z_t)\|.
\tag{26}
\]

这直接来自线性递推展开。不假设所有增益小于 1；若增益巨大，界就可能无用，须如实报告。矩阵拟合误差也应算进 \(r_t\)。观察自适应情况下，应按分支/条件状态处理，或使用第 6 节适用于一般协议的 Bellman 残差式，不能无解释地搬用固定开环序列公式。

### 4.4 贯穿框架的连接：响应等价就是下一步预测状态等价

至此的谱和 PSR 不应成为两套并列术语。连接它们的是**对后续学习测试封闭的充分性**。对所声明的测试类，定义两个状态等价，当且仅当它们对所有这些后续测试的期望都相同。若测试类含合法一步前置，这个等价关系可以继续预测；若只含“现在部署”，则第 4.3 节已给出反例。

这里说的是相对于受限测试类的部署充分性与学习充分性不同。若两个环境对所有允许的交互历史与学习协议本来就完全同分布，任何同一学习器当然也无法区分；本文不主张违反这种全行为等价性。

**定理 3.5：响应—预测状态桥接〔精确；组合命题〕。** 固定 \((t,z)\)。假设所声明的未来价值测试空间在下一时刻具有有限基底 \((1,\psi_1,\ldots,\psi_d)\)。这仅用于有限维版本，不是全框架的默认低秩假设。写

\[
V_a(z')=k_a+c_a^\top\psi(z'),\qquad
\Gamma_z(y)=\mathbb E[\psi(U_t(z,y,\Xi))\mid z,y].
\]

把 \(c_a^\top\) 组成矩阵 \(C\)；有限测试权重均为正，并假设这些测试连同常数张成所述基底，因而 \(C\) 满列秩。定义

\[
\mathcal T_z h=\mathbb E_\rho[\Gamma_z(Y)h(Y)].
\]

则

\[
\boxed{\mathcal R_z=C\mathcal T_z,\qquad
\ker\mathcal R_z=\ker\mathcal T_z.}
\tag{R11}
\]

所以对 \(P,Q\) 的密度差 \(h\)，以下两件事等价：

1. 当前反馈在全部声明的后续学习测试中有相同响应；
2. 执行当前反馈后，下一步预测状态的期望相同。

**证明。** 条件期望给出 \(g_a(y)=k_a+c_a^\top\Gamma_z(y)\)。由于 \(\mathbb E_\rho h=0\)，常数项消失，故有算子分解。满列秩使 \(Cx=0\Rightarrow x=0\)，得到核相等。□

若测试空间按第 4.1 节对合法未来更新闭合，这些期望随后足以预测同类未来结果。观察自适应协议还须采用第 4.2 节的分支闭合；仅有开环测试时不保证任意自适应协议。多轮中若逐状态、逐时刻满足桥接匹配，并覆盖实际访问的状态，则对该类参考后续协议可用式 (2) 得到最终结果相等。**一次检查点上的匹配不能代替后续所有访问状态上的匹配。**

这个结论把三个角色分清：\(\mathcal T_z\) 描述反馈能改变哪些学习记忆，\(C\) 描述哪些记忆会被未来任务看见，\(\mathcal R_z\) 是二者的复合。谱截断选择这个复合中的重要方向；闭合约束决定它能否在下一轮继续使用；查询再针对尚未识别的重要方向补证据。它是本稿的**组合层面贡献候选**，其线性代数与预测状态思想来自经典理论，不将等式本身宣称为首次发现。

**近似版本不隐藏误差。** 若 \(V_a=k_a+c_a^\top\psi+e_a\)，则

\[
\mathcal R_z=C\mathcal T_z+\mathcal E_z,
\qquad
(\mathcal E_z h)(a)=\mathbb E_\rho h(Y)
\mathbb E[e_a(U_t(z,Y,\Xi))\mid z,Y].
\tag{R12}
\]

若条件残差函数的 \(L^2(\omega\times\rho)\) 范数不超过 \(\epsilon_{\rm pred}(z)\)，则
\(\|\mathcal E_z h\|_\omega\le B_z\epsilon_{\rm pred}(z)\)。再结合近似特征匹配、式 (R3) 或逐任务投影残差，即得到当前反馈误差；沿轨迹使用第 6 节的恒等式，另外支付闭合、终点与覆盖误差。

满列秩仅给出精确零空间等价；要从“小响应误差”反推“小坐标误差”，还需要 \(C\) 的最小奇异值，可能很差。预测状态坐标可以任意缩放，因此真正的输出保证使用任务范数，而不人为声称所有记忆坐标都稳定。

## 5. 控制理论究竟增加了什么

### 5.1 可控而不可观、可观而不可控

可选地，在确有局部可微性的路径附近写完整状态扰动

\[
\delta z_{t+1}=A_t\delta z_t+B_t\delta u_t+\epsilon_t,
\quad\delta o_t=C_t\delta z_t+\zeta_t.
\tag{27}
\]

\(\epsilon_t,\zeta_t\) 是未被忽略的非线性余项。把训练序列切分为过去与未来，在零初始扰动且先忽略余项的线性系统中，有

\[
\delta z_\tau=\mathscr C_\tau\delta u_{\mathrm{past}},\quad
\delta o_{\mathrm{future}}=\mathscr O_\tau\delta z_\tau,
\quad H_\tau=\mathscr O_\tau\mathscr C_\tau.
\]

过去输入使用声明的能量范数，未来输出使用声明的加权范数。定义有限时域 Gramians

\[
W_c=\mathscr C_\tau\mathscr C_\tau^\top,
\qquad W_o=\mathscr O_\tau^\top\mathscr O_\tau.
\]

则非零 Hankel 奇异值满足

\[
\sigma_j(H_\tau)^2
=\lambda_j\!\left(W_c^{1/2}W_oW_c^{1/2}\right).
\tag{28}
\]

**证明。** \(H_\tau^\top H_\tau=\mathscr C_\tau^\top W_o\mathscr C_\tau\)；使用 \(AB\) 与 \(BA\) 的非零特征值一致性即可。□

这解释了为什么环境里很复杂的一个方向仍可能对蒸馏不重要：合法反馈激发不了它，或者未来任务看不见它；两者必须同时满足才产生大的输入—输出增益。相反，\(m,v\) 中的一个变化可能对当前参数影响很小，却强烈影响未来输出。这是完整状态的重要性，而不局限于 Adam 的某个平稳公式。

### 5.2 哪些控制理论结论不能直接搬过来

有限时域式 (28) 不需要渐近稳定。经典平衡截断的 \(H_\infty\) 误差界 \(2\sum_{j>r}\sigma_j\) 属于相应稳定线性时不变系统及其实现条件 [R5]；不能把它写成一般非线性 Adam 训练的现成保证。

对一个 Hankel 块做最优低秩逼近，也不一定得到具有相同时间移位结构的因果动态模型。必须同时检查第 4 节的闭合残差。式 (27) 对真实训练是否准确，要测余项或限制为明确的局部分析；本稿的基础恒等式始终使用精确核，不依赖这个分支。

R3 中的振幅律失败不能由“我们换了一个谱解释”自动修复。新框架容纳这个失败：响应可以非二次、非平稳、受到后续梯度变化和数值扰动影响。究竟哪个机制导致失败，仍需分离实验，不能直接认定唯一原因是 Hessian。

### 5.3 恢复学习器特有的机制：精确记忆反例与完整伴随通道

一般性的精确核与学习器特有的解释可以共存。应撤回的是未获支持的平稳振幅外推，不能把完整优化器的机制也一并删去。

**命题 5.1：相同即时参数更新不保证相同学习后果〔精确构造〕。** 对没有额外记忆、且未来核只依赖当前参数和已知时钟的 SGD，两次干预若得到相同参数，之后使用相同的条件训练协议就产生同分布的未来结果。对 Adam，存在标准可达检查点和两条合法反馈，使即时参数完全相同，但下一步结果不同。

**证明与可复现构造。** 使用一维 Adam，\(\beta_1=0.9,\beta_2=0.999,\eta=1\)，保留 bias correction，无 weight decay，先取 \(\epsilon=0\) 以便给出有理数构造。从 \((\theta,m,v)=(0,0,0)\) 用梯度 1 更新一次，得到

\[
z_1=(-1,0.1,0.001).
\]

第二次反馈梯度分别为

\[
g_A=\tfrac12,\qquad g_B=\tfrac{2103}{790}\approx2.662025316.
\tag{R13}
\]

此时未校正矩满足 \(m_2=0.09+0.1g\)、\(v_2=0.000999+0.001g^2\)。这两个梯度使
\((0.9+g)/\sqrt{0.999+g^2}\) 完全相同，且 bias correction 因子相同，故两侧
\(\theta_2\approx-1.932179639\)，但 \((m_2,v_2)\) 不同。下一步在相同参数上使用共同梯度 1，得到

\[
\theta_3^A\approx-2.895140182,\qquad
\theta_3^B\approx-2.823937478.
\tag{R14}
\]

选有界终点结果 \(F(\theta)=(1+e^{-\theta})^{-1}\)，两侧结果相差约 \(-0.00364994\)。全部梯度都可由适当标签的一维平方损失在相应参数处产生；第三步是两侧相同的平方损失，因此不要求后续 Hessian 为零。两条分支均来自同一个标准 Adam 历史。这里 \(\eta=1\) 只用于数值展示；保持这些梯度值并相应选择平方损失标签时，任意 \(\eta>0\) 都有相同即时更新与非零后续差异，参数差随 \(\eta\) 缩放。

在 \(g_B\) 处，第二步更新对梯度的导数不为零，隐函数定理保证小正 \(\epsilon\) 下可连续调整 \(g_B\) 保持即时参数相等，而第三步差异保持非零。脚本另验证 \(\epsilon=10^{-8}\) 的对应根约为 \(2.662025475\)。SGD 的陈述则直接来自其指定的无记忆条件核。□

**严格的分离对象。** 这个例子分离的是“只看干预后的参数/即时参数位移”的接口与保留未来响应的接口。它也使一维梯度方向代理打平。但完整梯度保留了幅值，TRAK、LESS 或 datamodels 的具体实现可能读取其他信息；因此不能将该例写成对这些方法的全面分离。加入 momentum、采样器记忆或数据缓冲后，SGD 也必须扩充状态。

**完整一阶通道仍然有价值。** 对可微的实际 AdamW 轨迹，在不穿过裁剪/离散分支边界且分母可微的局部区域，记

\[
m'=\beta_1m+(1-\beta_1)g(\theta),\quad
v'=\beta_2v+(1-\beta_2)g(\theta)^2,
\quad
\theta'=(1-\eta\lambda)\theta-
\eta\frac{a m'}{\sqrt{b v'}+\epsilon},
\]

其中 \(a=(1-\beta_1^{t+1})^{-1}\)、\(b=(1-\beta_2^{t+1})^{-1}\)，所有平方与除法逐坐标进行。定义

\[
D=\operatorname{diag}\frac{a}{\sqrt{bv'}+\epsilon},\qquad
E=\operatorname{diag}\frac{abm'}{2\sqrt{bv'}(\sqrt{bv'}+\epsilon)^2},
\quad H=\frac{\partial g}{\partial\theta}.
\]

若下一状态的续训价值梯度为 \((s_\theta,s_m,s_v)\)，令

\[
u=(1-\beta_1)(s_m-\eta Ds_\theta)
+2(1-\beta_2)\operatorname{diag}(g)(s_v+\eta Es_\theta).
\]

链式法则精确给出该点的伴随导数

\[
\boxed{\chi_\theta=(1-\eta\lambda)s_\theta+H^\top u,\quad
\chi_m=\beta_1(s_m-\eta Ds_\theta),\quad
\chi_v=\beta_2(s_v+\eta Es_\theta).}
\tag{R15}
\]

上述导数条件于本步输入；若进一步对状态依赖的采样分布求期望导数，还需包含该分布的导数或证明交换条件，不能把固定样本反向传播自动等同于全部随机训练目标的导数。

这与原 §7.1 的完整状态通道相容，属于反向微分/控制伴随的经典实例化。它明确保留 \(H\)、bias correction、weight decay 和 \(\epsilon\)。局部反馈梯度扰动的价值导数为 \(u^\top\delta g\)；有限幅度替换仍需余项或直接响应测量，不能因式 (R15) 正确而恢复失败的平稳振幅律。

SGD 的该导数没有 \(m,v\) 通道；Adam 有经未来可观测性加权的记忆通道。对 LoRA 等参数化 \(\theta=f(q)\)，局部可改变的参数方向由 \(J_f(q)\) 限制，响应导数使用相应复合 Jacobian；这只是局部可达性结论，有限多步后子空间可改变，不能宣称整个训练的响应秩被当前切空间永久封顶。

原来的 SGD 状态权重 \(d(s)^2\)、warm Adam 权重 \(d(s)\) 仍可列为**受限模型推论**：它们需要原证明中的独立访问、独立坐标、梯度与参数无关、仿射终点，以及 warm Adam 的充分频繁访问、均值场和可忽略 \(\epsilon\) 等条件。低访问率的 isolated Adam 又有不同规律。正文用这些分支提出机制假说，实验检验实际条件；不把它们当作任意神经网络优化器的普遍权重律。

## 6. 联合误差工具：从响应压缩到真实训练收益

本节保留联合误差表达式作为后续保证的基础工具。它属于 performance-difference / simulation-lemma 与近似价值 Bellman 残差的经典组合；相关源头包括 Kakade–Langford (2002) [R16]。式 (30) 是在本文符号下的直接推导，不作为主要原创定理。恒等式与各项可测性本身不保证数值信息量，单次比较时估计全部项可能比直接运行两协议更贵。第 3.4–3.5 节说明复用和估计省计算所需的额外条件。

设 \(\widehat V_t\) 是任意固定的近似参考续训价值函数，可以由预测状态模型给出，也可以由其他方法给出。定义参考 Bellman 残差、终点误差及近似消息响应：

\[
r_t^0(z)=K_t^0\widehat V_{t+1}(z)-\widehat V_t(z),\quad
e_R(z)=F_E(z)-\widehat V_R(z),
\]

\[
\overline g_{t,z}(y)=\mathbb E[\widehat V_{t+1}(U_t(z,y,\Xi_t))\mid z,y],
\quad d_t(z)=\int\overline g_{t,z}\,d(P_t^0-P_t^S).
\tag{29}
\]

注意：\(\overline g\) 中本轮更新仍是实际更新。若连更新核也由模型近似，相关误差必须纳入响应估计或 Bellman 残差，不能视为零。

使用第 2–3 节的 \([0,1]\) 范围常数时，应使 \(\widehat V_t\in[0,1]\)，例如明确裁剪；若采用其他已知范围则相应缩放常数。下面的代数恒等式本身只要求相关期望存在。

### 定理 4：精确联合分解与认证界〔精确；经典恒等式的实例化〕

两协议起点相同，且相关期望存在时，

\[
\boxed{
L(P^0)-L(P^S)
=\mathbb E_S\sum_{t=0}^{R-1}d_t(Z_t)
+\mathbb E_0\sum_t r_t^0(Z_t)
-\mathbb E_S\sum_t r_t^0(Z_t)
+\mathbb E_0 e_R(Z_R)-\mathbb E_S e_R(Z_R).
}
\tag{30}
\]

若局部响应差由谱/特征/统计误差界 \(|d_t(z)|\le\beta_t(z)\) 控制，则

\[
\boxed{
|L(P^0)-L(P^S)|
\le\underbrace{\sum_t\mathbb E_S\beta_t(Z_t)}_{\text{反馈响应压缩与估计}}
+\underbrace{\sum_t(\mathbb E_0|r_t^0|+\mathbb E_S|r_t^0|)}_{\text{动态预测与闭合}}
+\underbrace{\mathbb E_0|e_R|+\mathbb E_S|e_R|}_{\text{真实终点评价}}.
}
\tag{31}
\]

例如 \(\beta_t\) 可取式 (13)，或在冻结有限目录、同时置信事件上取式 (18)。谱必须针对式 (29) 的响应或有误差控制的估计，而不能用一个无校准关系的梯度矩阵替换。

**证明。** 对任意协议 \(j\in\{0,S\}\)，

\[
L(P^j)-\mathbb E\widehat V_0(Z_0)
=\mathbb E_j e_R(Z_R)
+\sum_t\mathbb E_j[K_t^j\widehat V_{t+1}-\widehat V_t](Z_t).
\]

对 \(j=S\)，中括号为 \(r_t^0-d_t\)；对 \(j=0\)，中括号为 \(r_t^0\)。相减得到式 (30)，再取绝对值得到式 (31)。□

这个分解比逐轮先把 \(\widehat V\) 换成精确 \(V\)、再为每轮重复累计全部未来误差更直接，避免了那种证明方式可能产生的多余重复计数。它仍可能因误差项大而失去实用性，没有无条件非空证书的承诺。

### 6.1 闭合残差如何进入联合界

若 \(\widehat V_t=c_t^\top\psi_t\)，且真实参考核满足

\[
K_t^0\psi_{t+1}=A_t\psi_t+\epsilon_t,
\]

则

\[
r_t^0=(c_{t+1}^\top A_t-c_t^\top)\psi_t+c_{t+1}^\top\epsilon_t.
\tag{32}
\]

第一项是模型内部的值递推误差，第二项是动态特征闭合误差。即使训练出低维特征，若 \(\|c_{t+1}\|\) 很大，小的特征残差仍可能成为大的值误差；不能把它藏进一个未检查的常数。

### 6.2 有限覆盖的版本

令 \(\tau^0,\tau^S\) 分别是两协议首次离开认证状态集的时刻。若 \(\widehat V_t\in[0,1]\)，停止式 (30) 的两个望远镜和可得

\[
\begin{aligned}
|L(P^0)-L(P^S)|\le{}&
\mathbb E_S\sum_{t<\tau^S}\beta_t
+\mathbb E_0\sum_{t<\tau^0}|r_t^0|
+\mathbb E_S\sum_{t<\tau^S}|r_t^0|\\
&+\mathbb E_0[|e_R|\mathbf1\{\tau^0=R\}]
+\mathbb E_S[|e_R|\mathbf1\{\tau^S=R\}]\\
&+\Pr_0(\tau^0<R)+\Pr_S(\tau^S<R).
\end{aligned}
\tag{33}
\]

每条轨迹在退出时的真实剩余价值和近似值均处于 \([0,1]\)，故每个退出概率只付一次。相较式 (3)，这里因参考值也在近似，需要控制两个访问分布；不能默默只保留替代协议的一项。若使用精确 \(V^0\)，应直接回到更紧的式 (3)。对预测值裁剪到 \([0,1]\) 后，要以裁剪后的函数重新计算残差，不能假装裁剪仍保持原线性递推。

若残差只在审计分布 \(\nu_t\) 上测得平均值，必须另外控制实际占用与 \(\nu_t\) 的运输/密度比或退出概率。有限审计点上的最大误差，不自动等于整个认证区域的最大误差。

### 6.3 为什么这比引入更强假设更一般

式 (30) 不需要全局 Lipschitz、收缩、平稳梯度、优化器线性、低维真实环境、可逆观察或可微策略。困难被保留为可明确量化的误差项，而没有通过强假设删除。

代价是：一般系统可能无法以小成本估计这些项，或者界可能很松。这是理论诚实的边界。它提供“什么时候压缩有效”的判据，不提供“所有 agent 必然能被便宜压缩”的定理。

### 6.4 综合推论：把接口、获取、复用与持续训练接成一条保证

为了让组合产生一个可用结果，下面明确各模块如何进入同一保证。它由前述结论推得，不把新的组合公式误称为新的 simulation lemma。

**推论 4.1〔条件性；组合保证〕。** 对式 (29) 的有界响应测试类，在每个认证状态 \((t,z)\) 选择一个接口锚点 \(j=j(t,z)\)。其估计响应算子为 \(\widehat{\mathcal R}_j\)，前 \(r_j\) 个模式给出消息特征 \(\phi_j\)；\(C_j\) 是保留模式到测试输出的系数矩阵。假设在一个同时有效的置信事件上：

1. 锚点算子误差不超过 \(\epsilon_j\)，新状态到锚点的算子差不超过 \(\Delta_{t,z}\)；
2. 参考反馈的模式均值属于有效集合 \(\mathcal M_{t,z}\)；合法编译按 \(C_j\) 求式 (R16) 的半径 \(\mathfrak r_{t,z}\)，求解误差不超过 \(\eta_{\rm opt}\)；
3. 实际参考/替代反馈的密度差不超过 \(B_{t,z}\)，其消息支持在共同参考测度覆盖内；
4. 测试类包含式 (29) 对应的测试 \(a_t\)，其权重 \(\omega_{a_t}>0\)。

则局部标量响应差满足

\[
\boxed{|d_t(z)|\le\beta_t(z):=
\frac{\mathfrak r_{t,z}+\eta_{\rm opt}
+B_{t,z}\big(\widehat\sigma_{r_j+1}(j)+\epsilon_j+\Delta_{t,z}\big)}
{\sqrt{\omega_{a_t}}}.}
\tag{R19}
\]

把它代入式 (33)，得到

\[
\boxed{|L(P^0)-L(P^S)|\le
\mathbb E_S\sum_{t<\tau^S}\beta_t(Z_t)
+\mathcal E_{\rm dyn}+\mathcal E_{\rm terminal}+\mathcal E_{\rm exit},}
\tag{R20}
\]

其中后三项恰为式 (33) 的两侧 Bellman 残差、两侧终点误差与两侧退出概率，没有将任何一项默认为零。

**证明。** 对实际密度差 \(h\)，将局部响应写成

\[
\mathcal R_{t,z}h
=C_j(\mu_{P^0}-\mu_{P^S})
+\widehat{\mathcal R}_j(I-\widehat\Pi_{r_j})h
+(\mathcal R_{t,z}-\widehat{\mathcal R}_j)h.
\]

三项在输出加权范数中分别不超过
\(\mathfrak r_{t,z}+\eta_{\rm opt}\)、
\(B_{t,z}\widehat\sigma_{r_j+1}(j)\)、
\(B_{t,z}(\epsilon_j+\Delta_{t,z})\)。由指定测试的权重转成逐测试界，再用式 (33)。□

该推论使用的是**完整响应漂移**，因此连复用的保留模式系数变化也被支付；仅控制丢弃子空间的漂移并不足够。若直接审计指定测试，可用其逐行界替代 \(1/\sqrt{\omega_{a_t}}\) 的代价。第 3.5 节提供估计 \(\epsilon_j\) 的一种条件性省成本方法，第 3.4 节提供 \(\Delta_{t,z}\) 的一种可执行认证方式，第 8.5 节定义 \(\mathfrak r_{t,z}\) 如何区分获取与编译缺口。

同时置信事件必须对所认证的状态和自适应选择有效。有限已审计状态之外不能直接沿用，须证明统一控制、使用访问时条件有效的新审计，或计入退出项。获得这个完整证书仍可能比直接比较两协议更贵；其研究价值在于多决策复用以及明确告诉方法应减少哪类误差，而不是自动保证廉价认证。

## 7. 从预测特征编译回合法反馈

找到 \(r\) 个模式不等于已经找到可执行的合成消息，更不等于已经拥有完整 world model。

给定经核验的有限消息池 \(\{y_1,\ldots,y_m\}\)，记保留特征为 \(\phi(y)=(v_1(y),\ldots,v_r(y))\)，期望目标为 \(\mu_*\)。一个合法混合反馈必须满足

\[
q_i\ge0,\quad\sum_iq_i=1,\quad\sum_iq_i\phi(y_i)=\mu_*.
\tag{34}
\]

它存在当且仅当 \(\mu_*\in\operatorname{conv}\{\phi(y_i)\}\)。由 Carathéodory 定理，若存在，则有支持不超过 \(r+1\) 的解。该结论是经典凸几何；它保证的是特征均值匹配，不是文本意义正确或整个学习过程无损。

稀疏混合可能在 \(\rho\) 很小的消息上放置很大质量，使第 2 节的 \(B\) 变大。因此不能同时无条件声称“只需 \(r+1\) 条消息”和“原先的谱误差界保持不变”。可行的处理是：

- 在优化中增加密度比上界或 \(\chi^2\) 约束，并允许更多支持；
- 使用第 2.3 节的逐点统一逼近界；
- 显式报告所选混合的实际 \(B\) 和逐测试残差。

若目标落在凸包外，应报告不可实现或把投影误差计入模式不匹配；要改善它，需要扩充合法消息池、查询新证据或改变训练接口。不能靠负权重或未经核验的生成消息证明“achievability”。

这个处理替代原 §6.5 中直接发出 \(P^*_{\widehat\theta}\) 的一般性叙述。原叙述可以保留为**当 oracle 分布确实可生成时**的条件性定理，但不能成为现实 agent 蒸馏的默认上界。

## 8. 查询与信息：哪些后果方向值得补数据

### 8.1 精确、非参数的信息障碍

本节使用经典 Le Cam 两点法 [R26] 及自适应 transcript 的 KL 链式分解。

让环境 \(E\) 未知，算法只能看到允许的 transcript \(T\)，其中包括共同先验信息、演示、查询结果和私有随机性。对两个环境 \(E_0,E_1\)，设 transcript 分布为 \(\mathbb P_0^T,\mathbb P_1^T\)，需要估计的后果向量为 \(f_0,f_1\)。任意估计器满足

\[
\inf_{\widehat f}\max_{i=0,1}\mathbb E_i\|\widehat f-f_i\|
\ge\frac{\|f_1-f_0\|}{2}
\left(1-\operatorname{TV}(\mathbb P_0^T,\mathbb P_1^T)\right).
\tag{35}
\]

**证明。** 在两分布的公共部分上，三角不等式给出两种误差之和至少为 \(\|f_1-f_0\|\)。公共部分的质量是 \(1-\mathrm{TV}\)，最大风险至少为两风险和的一半。□

若问题是从两个候选反馈中选择，两个环境的最优候选相反，且选错的真实训练收益损失均至少为 \(\Delta\)，相同二点检验论证给出

\[
\inf_{\widehat b}\max_i\mathbb E_i[\operatorname{regret}(\widehat b)]
\ge\frac\Delta2(1-\operatorname{TV}).
\tag{36}
\]

必须明确这种决策结构；一个目标估计误差下界不能自动当成任意策略类的任务 regret 下界，因为可能有第三种行动在两个环境中都好。

对自适应查询，KL 链式法则沿算法实际观察到的历史分解：

\[
\operatorname{KL}(\mathbb P_0^T\|\mathbb P_1^T)
=\operatorname{KL}(\text{初始信息}_0\|\text{初始信息}_1)
+\sum_\ell\mathbb E_0\operatorname{KL}
\left(Q_0(\cdot\mid H_\ell,X_\ell)\|Q_1(\cdot\mid H_\ell,X_\ell)\right).
\tag{37}
\]

查询策略在两环境下使用同一算法，故策略自身不另贡献信息。配合 Pinsker 可得到具体预算下界。在 iid 演示、状态无关查询模型中才可进一步简写成 \(K\,\mathrm{KL}_D+n\sup_x\mathrm{KL}_{Q_x}\)；一般情形需保留历史条件或对历史和查询共同取上确界。

式 (35)–(37) 不要求参数化、Fisher 信息、梯度平稳或高效估计器。对 transcript 的环境无关随机后处理不会减小不可区分性障碍。生成内容仍可能让有限能力学生更容易学习，但那是表示/算法收益，不是新环境证据。

### 8.2 可完整证明的查询设计特例：线性高斯目标

为了得到可计算设计规则，单独声明模型

\[
y=D\vartheta+\epsilon,\quad\epsilon\sim N(0,\Sigma),\qquad
f(\vartheta)=C\vartheta,
\]

其中 \(D,\Sigma,C\) 已知，\(\Sigma\succ0\)，\(\vartheta\in\mathbb R^d\)。\(f\) 是学习后果目标，不要求恢复所有环境参数。给定输出损失权重 \(W\succeq0\)，令

\[
I=D^\top\Sigma^{-1}D,\qquad B=C^\top WC.
\tag{38}
\]

若 \(I\succ0\)，广义最小二乘给出精确恒定风险

\[
\mathbb E\|\widehat f-f\|_W^2
=\operatorname{tr}(BI^{-1})
=\sum_j\lambda_j,
\quad Bv_j=\lambda_jIv_j.
\tag{39}
\]

而且这是无界参数空间上的 minimax 平方风险。

**证明。** \(\widehat\vartheta=I^{-1}D^\top\Sigma^{-1}y\) 的误差协方差为 \(I^{-1}\)，所以风险为迹。取先验 \(\vartheta\sim N(0,\tau^2I_d)\)，Bayes 风险为 \(\operatorname{tr}[B(I+\tau^{-2}I_d)^{-1}]\)，当 \(\tau\to\infty\) 时逼近该迹；任何 minimax 风险都不小于这些 Bayes 风险。谱等式来自 \(I^{-1/2}BI^{-1/2}\) 的特征分解。□

如果 \(I\) 奇异，只需识别影响目标的方向：当 \(C\ker I=0\) 时可在可识别商空间上用伪逆；若存在 \(v\in\ker I\) 而 \(Cv\ne0\)，在这里的无界参数空间上 minimax 风险为无穷。若参数有界，则是不可消除的误差底，不应继续写成无穷。

定义信息白化后的后果算子

\[
\mathcal R_I=W^{1/2}CI^{-1/2}.
\tag{40}
\]

它的奇异值平方就是式 (39) 的 \(\lambda_j\)。这给出清晰区分：原响应谱表示“会造成多大后果”，白化谱表示“这个后果方向相对于已有证据有多难识别”。高增益但已有大量信息的方向，未必值得继续查询。

若一次单位噪声查询的向量为 \(a\)，新增精度 \(aa^\top\)，则由 Sherman–Morrison 恒等式，目标风险下降量精确为

\[
\boxed{\Delta(a)=
\frac{a^\top I^{-1}BI^{-1}a}{1+a^\top I^{-1}a}.}
\tag{41}
\]

有成本时可以比较 \(\Delta(a)/\operatorname{cost}(a)\)，但这种逐步贪心选择不自动是整体预算下的最优策略。标量目标 \(C=c^\top\) 时，\(B=cc^\top\)，退化为原 §6 的目标定向信息几何；多目标对应加权 A/L-optimal design，而非直接把标量 c-optimal 结论扩展成任意非线性任务的最优性。

### 8.3 从特例回到真实学习系统时不能跳过的步骤

在一般正则参数模型中，可用局部信息近似 \(I\)、用**完整精确后果函数**的导数 \(C=\partial f/\partial\vartheta\) 获得局部版本，但必须单独证明局部近似、可识别性和估计器性质。这不是主定理的前提。

如果 \(f(\vartheta)=\int g_\vartheta(y)P_\vartheta(dy)\)，则在可交换微分时

\[
\partial f=\int g_\vartheta\,\partial P_\vartheta
+\int(\partial g_\vartheta)\,dP_\vartheta.
\tag{42}
\]

环境变化还可能改变后续训练、占用分布和测试结果，均须进入 \(\partial g\)。只有响应机制固定时，才可把导数简单写成 \(\mathcal RJ\)。冻结 continuation 梯度后推导的原一阶目标是一个有效的局部目标，但不能自动等同于真实完整训练收益的导数。

这也说明“贯穿同一个响应对象”不意味着强行把所有谱合并成同一组数字：压缩、更长的动态测试和观测信息白化改变了问题的输入输出空间或度量，应分别报告。

### 8.4 对原设计引理的一项直接放宽：允许奇异设计

原 Lemma 6.4 要求每个设计的 \(A(\xi)\succ0\)。对一个固定线性目标，这比必要条件强。保留查询空间紧、\(I_Q(x)\) 连续且半正定，令

\[
A(\xi)=KI_D+n\int I_Q(x)\,\xi(dx),
\quad
\Phi_c(A)=
\begin{cases}
c^\top A^+c,&c\in\operatorname{range}A,\\
+\infty,&c\notin\operatorname{range}A.
\end{cases}
\]

则不要求每个 \(A(\xi)\) 可逆，仍有

\[
\boxed{\inf_\xi\Phi_c(A(\xi))
=\sup_{h\ne0}\frac{(c^\top h)^2}
{K h^\top I_Dh+n\sup_x h^\top I_Q(x)h}.}
\tag{43}
\]

使用 \(0/0=0\)、正数除以 0 为无穷的约定；若右侧有限，存在达到最优值的设计。

**证明。** 对任意半正定 \(A\)，谱分解直接给出
\(\Phi_c(A)=\sup_h(2c^\top h-h^\top Ah)\)。设计空间紧凸，括号内对设计仿射、对 \(h\) 凹，因此 Sion 极小极大交换 [R15] 给出

\[
\inf_\xi\Phi_c(A(\xi))
=\sup_h\{2c^\top h-Kh^\top I_Dh-n\sup_xh^\top I_Q(x)h\}.
\]

沿每个方向对尺度最大化即得到比值式 (43)。也可先加入 \(\varepsilon I\) 使用原正定引理，再令 \(\varepsilon\downarrow0\)：紧性保证最优设计有聚点，而变分表达式保证下半连续，从而给出相同极限。\(\Phi_c\) 是连续函数族的上确界，故在紧设计空间上下半连续，有限最优值可以达到。□

这个放宽是经典最优设计对偶性的直接延伸，不声称为新的设计理论。它允许不识别对线性目标无用的方向。但原 Theorem 6.5 还要控制非线性 \(\Psi(\widehat\theta)\) 的二阶误差；不能因为式 (43) 成立，就把它所需的估计条件一并删除。

### 8.5 将获取、压缩与合法编译变成同一个决策问题

信息论不能只作为结尾处的“还需要数据”。固定一个已经校准的响应接口 \(\phi(y)\in\mathbb R^r\)，令

\[
g_a(y)=k_a+c_a^\top\phi(y)+e_a(y),\quad
C=(c_a^\top)_a,\quad \mu_P=\mathbb E_P\phi(Y).
\]

以下有限测试的权重均为正，零权重测试先从目标空间删除。暂将 \(C\) 视为已知/冻结，未知环境部分体现为目标反馈 \(P\) 的特征均值。由现有 transcript 构建非空紧置信集合 \(\mathcal M\)，使真实 \(\mu_P\in\mathcal M\) 的概率至少为 \(1-\delta\)。令 \(\mathcal Q_{\rm legal}\) 是第 7 节的有限合法池混合以及所需的密度约束，并假设它非空、紧。定义

\[
\mathcal K=\{C\mu_Q:Q\in\mathcal Q_{\rm legal}\},\qquad
\boxed{r(\mathcal M,\mathcal K)=
\min_{q\in\mathcal K}\sup_{\mu\in\mathcal M}\|C\mu-q\|_\omega.}
\tag{R16}
\]

这同时问：重要后果还不确定多少，以及已知的目标后果能否用合法反馈达到。半径存在最小值，因目标连续、可行集合紧。

**命题 8.1：不确定性与可实现性必须同时消失〔精确；鲁棒逼近的组合应用〕。**

\[
r(\mathcal M,\mathcal K)\ge
\max\left\{\tfrac12\operatorname{diam}_\omega(C\mathcal M),
\ \sup_{\mu\in\mathcal M}\operatorname{dist}_\omega(C\mu,\mathcal K)\right\}.
\tag{R17}
\]

且 \(r=0\) 当且仅当 \(C\mathcal M\) 为单点且该点属于 \(\mathcal K\)。若界 \(\|h\|_\rho\le B\) 对所比较分布成立，残差算子范数至多为 \(\epsilon_{\rm tail}\)，则半径最优编译 \(Q^*\) 满足

\[
\|\mathcal R(dP/d\rho-dQ^*/d\rho)\|_\omega
\le r(\mathcal M,\mathcal K)+B\epsilon_{\rm tail}
\tag{R18}
\]

的 \(1-\delta\) 条件保证。保留空间内数值优化未达到最优时另加优化误差。

**证明。** 对任何固定 \(q\)，任意两目标的距离不超过它们到 \(q\) 的距离之和，得到直径的一半下界；到可行集的距离给出另一项。紧性给出零半径的充要条件。最后分解真实响应为 \(C(\mu_P-\mu_{Q^*})\) 与残差，用三角不等式。□

它产生三项操作上不同的结论：

- 若未知性仅在 \(\ker C\) 中，再多辨认这些方向也不会缩小当前接口的任务误差；无需为重建整个环境付费。
- 若 \(C\mathcal M\) 很大而已有合法池足够丰富，应获取能区分这些后果方向的证据；线性高斯情形由式 (39)–(41) 提供可算特例。
- 若目标已经明确却位于 \(\mathcal K\) 外，继续减少相同信息的不确定性不能解决编译问题；需要扩充合法反馈池或接受可实现性误差。

例如 \(C=(1,0)\)，未知特征均值为 \((0.2,u),u\in[-100,100]\)，则响应目标没有不确定性。若合法响应只能落在 \([0,0.1]\)，仍至少有 0.1 的误差。这是信息已够、编译不足的情形，不能误诊为需要更多环境数据。

**条件边界。** 在一般未知环境中，\(C\)、终点评价和访问分布也可能随环境变化；不能只为 \(\mu_P\) 建集合。此时应对联合不确定对象 \((C_E,\mu_E,e_E)\) 做鲁棒优化，或先给出响应校准误差并将其另计；式 (R17) 的固定 \(C\) 商空间解释只用于上述明确的条件模型。置信集合不是未经校准的后验置信感，核外未覆盖的消息也不由它保证。

把查询选择写为“使未来有效集合的预期/最坏半径下降最多，扣除查询成本”是一项具体方法提案；对一般非线性学习系统，本稿没有证明它能高效求解或全局最优。式 (R18) 与第 6 节联用时必须先转成相应逐任务误差，并支付动态与覆盖项。这样信息获取、压缩、编译、持续训练才是在同一任务目标下组合，而不是四个互不相干的模块。

## 9. 具体研究方法与可否证实验

保留 CED 的获取—编译—审计过程，以第 4.4 节的持续学习接口组织。以下是一项已给出理论约束的方法提案，尚无新的真实基准结果。

1. **冻结操作范围与预算。** 列出学习器完整状态、任务、允许的反馈与查询、后续训练策略及观察分支。明确哪些测试共享一次训练，哪些必须分叉。预算包含 teacher、环境、GPU 续训、检查点恢复、代理训练和最终任务评估。
2. **建立少数锚点接口。** 从完整状态运行冻结反馈目录。一次模型尽可能复用多任务评估；若独立 pilot 支持式 (R8)，使用无偏多保真校正。基于同时有效的响应误差选择谱维数，报告逐任务残差；只评估两个固定协议时先与直接 CRN 比较成本。
3. **补足未来测试与记忆通道。** 用合法后续操作扩展测试，学习预测状态递推；用保留后缀检查闭合。对 Adam 比较包含与去除 \(m,v\) 通道的模型，对其他优化器使用其实际状态，不强迫所有学习器共享同一套统计量。
4. **复用与刷新。** 在新检查点沿用共享消息特征、重新估计条件特征均值；用式 (R3)–(R4) 或其他有效转移证书检查残差。只有当包含复用校验后的成本低于重拟合时，才称为有效复用。若达不到指定容差，建立新锚点、扩充特征或缩短认证范围；诊断性漂移指标须明确标注。
5. **按缺口选择获取或编译。** 在声明的响应模型中构造目标均值不确定集合与合法输出集合，求解式 (R16)。信息缺口触发有针对性的查询，凸包缺口触发合法池扩充，闭合缺口触发测试/状态扩充。一般查询策略按方法提案评价；只有符合线性高斯条件时直接使用式 (41) 的精确风险减少。
6. **编译与确认。** 用正概率混合匹配后果方向，支付密度与编译残差。候选自适应生成后使用新确认样本，或证明适当的同时/序贯有效性。最终真实任务收益、严格认证覆盖率和诊断排序分列报告。

### 9.1 本版的实验优先级

| 实验 | 预先冻结的比较与量 | 可能支持的结论 | 阴性结果的含义 |
|---|---|---|---|
| E1：优化器记忆与后续响应 | 先复现命题 5.1；真实模型中比较可达的近似匹配即时更新，记录 \(m,v\)、未来得分与配对区间 | 记忆通道在目标训练中有可观测作用 | 合成反例仍成立，但真实场景中的效应可能太小，不支撑其作为主要机制 |

真实模型对照至少包括原 CED、直接 CRN、适用于该任务的 LESS/TRAK/datamodels 基线及“只有响应谱、没有动态闭合/复用/校正”的消融。适配差异必须公开；不能把不适用的 baseline 配置故意作为弱对照。

R2 的 A3 与 A1 按原计划完成并同时报告正负结果。它检验的是已实施的查询分配与理论建模在该任务上的适用性；若正则性、目标或成本模型不匹配，结果不会直接证伪一个条件性信息下界，也不会单独验证整个新框架。

### 9.2 测试丰富度、谱与论文叙述的边界

若实际只关心固定后续训练下的 6 个部署指标，那么固定检查点响应秩本来就至多为 6。此时重点应是能否可靠估计和复用这些任务相关统计量，而不是把这个秩上界宣传为深层谱结构。只有不同后续协议、训练时长、观察分支或检查点确实是实际决策需要，扩展测试才有意义。

扩大测试类时，精确充分空间的维数不会下降；保留旧测试绝对权重并新增测试时，\(\mathcal R^*\mathcal R\) 增加半正定项。但重新归一化权重、或用一个长尾测试替换短尾测试，都不保证奇异值单调。谱衰减、闭合、漂移和估计收益必须分别报告。

## 10. 假设审计：哪些保留，哪些退出主线

本次核查覆盖原 README 全部主线、A/B/C 关键陈述与证明、充分性对偶、最优设计、Adam 振幅律和配对替换证据，并对新增推导逐项检查。它不是对仓库每一页证明、全部训练代码的形式化验证。因此结论是“修订主线不再依赖下列过强条件”，而不是保证所有历史版本已无任何漏洞。

| 条件或隐含跳步 | 判断 | 修订后的处理 |
|---|---|---|
| 有限预算、结果有界、真实核可测 | 常规且与问题直接对应 | 主线保留；范围与归一化公开 |
| 只用参数 \(\theta\) 就是完整学习状态 | 对带记忆优化器一般不成立 | 纳入 \(m,v\)、时钟、缓冲区与必要历史 |
| 原始观察必须 Markov | 不必要 | 使用完整历史或预测状态；不要求观察本身 Markov |
| 梯度/token/重复数据彼此独立 | 在实际训练中通常过强 | 主线不需要；只在明确的独立实验复现处使用独立性 |
| 仿射平均学习器、独立经验块、有限决策次数 | 原 §4 的受限模型条件 | 保留为说明阶数与 cumulant 的例子；不推广到任意优化器 |
| 小学习率就保证完整状态 Taylor 余项为 \(O(\eta^2)\) | 一般不成立；优化器状态改变可有不同尺度 | 主线使用精确核；局部近似单独量化完整状态余项 |
| 冻结 continuation 梯度且与环境参数无关 | 对原一阶目标合法，对真实收益导数可能不足 | 明确目标定义；需要完整导数时使用式 (42) |
| DQM 与对所有查询统一的 KL 二次展开 | 正则局部模型常用，但不是任意黑盒环境事实 | 留在 Fisher 分支；DQM 本身不自动替代额外的统一 KL 条件 |
| 每种设计 \(A(\xi)\succ0\) | 对线性目标过强 | 用式 (43) 的伪逆及目标可识别性替换 |
| 所有参数方向信息都按 \(N\) 增长 | 对全参数估计方便，对线性后果可能多余 | 主下界不用；非线性 achievability 需要什么则单独证明 |
| 高效两阶段估计器存在 | 本身是实质条件，不是由 c-optimal 设计自动推出 | 高斯特例完整证明；一般情形不宣称自动达到下界 |
| 可生成任意 \(P^*_{\widehat\theta}\) | 对真实蒸馏明显强 | 改为有限合法池的凸可实现性与显式编译误差 |
| Adam 恰好处于 \(m=\mathbb Eg,v=\mathbb Eg^2\) | 严格的平稳理想化 | 退出主定理，保留为解释性特例 |
| 后续梯度不依赖 \(\theta\)，终点得分仿射 | 对长程神经网络训练过强 | 不用于谱、动态或收益主定理 |
| \(\mathbb E[m/\sqrt v]=\mathbb Em/\sqrt{\mathbb Ev}\) | 一般错误 | 原均值场定义应明确为替代模型；实际误差另测 |
| 无 bias correction、无 weight decay、\(\epsilon=0\) | 特例优化器设定 | 原振幅公式适用范围写明；真实响应核包含实际实现 |
| 冷/暖状态由少数 warmth 分位数决定 | 不足以控制任务加权误差 | 使用任务加权误差或实际响应审计 |
| 低秩、快速谱衰减、有限维 PSR | 不是普遍事实 | 作为测量结果或条件性压缩性质；保留不能压缩的可能 |
| 全局有界密度比 | 可能过强 | 对有限目录用混合参考测度构造；目录外重新付覆盖代价 |
| 低平均谱误差意味着所有任务/状态都准确 | 错误 | 逐测试残差、权重代价及实际占用覆盖 |
| 所有动态矩阵都稳定/收缩 | 不必要且可能不真实 | 有限时域显式增益或 Bellman 残差；不导入 LTI 的无限时域界 |
| 每个观察概率有统一正下界 | 对丰富观察空间过强 | 条件化仅在正概率事件定义；稀有分支另计误差 |
| 全环境可由稀疏因果图/可分 DBN 表示 | 可选建模结构，不是当前任务必需 | 不加入主线；使用时单独比较结构失配 |
| SVD/PSR 预测可以直接生成合法消息 | 不成立 | 第 7 节的正概率编译与可实现性检查 |
| 冻结候选、独立复现、已知总体范围 | 有限样本证书的真实条件 | 保留并按实验协议落实；自适应选择须另处理 |
| 样本极差就是总体范围 | 错误 | 只能作为诊断，不用于声称原严格置信保证 |
| surrogate 校准在所有新状态都成立 | 强且不可从有限校准残差直接推出 | 显式转移误差、保留集验证；无依据则只报告 surrogate 排序 |
| 可随意恢复检查点、分叉未来、查询任意状态且免费 | 对真实系统不成立 | 限定可执行干预集合，把分叉和评估成本全部计入预算 |

### 10.1 无法同时满足的更强愿望

以下障碍不能通过换一套术语消除：

- **任意反馈分布的精确/逐任务保真不能普遍强压缩。** 取 \(m\) 条消息、\(m\) 个指示函数响应，中心化响应秩为 \(m-1\)。任意反馈差异都可能影响某个任务。这不否定第 2 节在固定 \(B\) 和平均度量下的近似接口上界。
- **当前充分性与任意未来充分性不可等同。** 第 4.3 节给出最大得分差为 1 的反例。
- **没有信息的方向不能靠生成自动辨认。** 两环境 transcript 完全相同时，式 (35) 给出不可消除的误差。
- **完全一般的 surrogate 不保证真实结果排序。** 令真实结果为 \(F\)、surrogate 为 \(1-F\)，排序直接相反。有限校准集没有覆盖的区域可存在同样现象。
- **没有激励与覆盖，就不能判断某个谱方向不存在。** 观测到的零响应可能只是没有测到相关干预。

因此应主动放弃“无需任何结构就能得到统一低维、低成本、全任务最优蒸馏”的表述。更可靠的主张是：给出结构可被测量、失配代价可被计算、失败可被识别的理论。

### 10.2 新增结论的实质条件与失败处理

不能把“总论对一般可测核成立”写成“整套方法不需要结构”。低维、稳定迁移和低成本是需要证据的性质。

| 新增结果 | 所需条件 | 是否属于全框架基本前提 | 不满足时如何处理 |
|---|---|---|---|
| 有限维桥接与线性 PSR | 声明的未来测试空间有限维；所选测试张成它 | 否，是精确有限表示条件，可能很强 | 使用残差版本，扩大测试/状态；不声称普遍低维 |
| 自适应未来学习充分性 | 观察分支/条件算子闭合 | 否，只在支持相应自适应协议时要求 | 缩小协议范围或支付遗漏分支误差 |
| 多检查点共享特征 | 共同消息测度、测试语义一致；各状态的密度差受控 | 不是所有环境天然具备 | 在共同合法池分析，或分簇建立不同接口 |
| 锚点迁移 | 可控制响应差异；式 (R4) 需可恢复分叉、独立配对复现 | 是该转移证书的操作条件 | 新锚点或未认证；不默认全局平滑 |
| Adam 反例 | 指定可达历史、合法梯度与非零分母 | 构造实例条件 | 说明存在性与机制；真实效应须另测 |
| 完整一阶伴随 | 本步条件更新及续训价值局部可微 | 否，仅解释性导数分支 | 不可微处用精确响应；有限变化保留余项 |
| 多保真估计无偏 | 两组独立；便宜分量边缘一致；代理/分配已冻结 | 是此估计器条件，常规但必须落实 | 独立确认或另外证明自适应估计性质 |
| 多保真更便宜 | 式 (R8)、足够复用，并计入 pilot/拟合开销 | 否，是待测的收益条件 | 使用直接完整续训，不宣称便宜估计 |
| 信息—编译半径 | 有效置信集合、合法紧可行集；固定/已校准响应 | 是该条件性决策模型的范围 | 响应也未知时扩大联合不确定集，支付校准误差 |
| 泛化到新任务、新候选或新检查点 | 相应覆盖或有效转移控制 | 不能从旧目录的通过自动获得 | 增加确认数据或收缩保证范围 |

本版没有新增全局梯度平稳、Hessian 为零、所有动态收缩、默认低秩、免费精确响应、普遍校准迁移或任意 oracle 反馈可生成的假设。原稿中较强条件保留为明确受限的分支，没有通过改名使其成为一般事实。

## 12. 近邻工作、组合贡献与论文定位

本版按原始论文和官方论文页补充文献，检索截至 2026-10-14。以下是针对性的新颖性核对，不是穷尽性结论。

| 近邻工作 | 必须承认的已有内容 | 本稿需要在其基础上证明的增量 |
|---|---|---|
| Machine teaching：Zhu 2015；Liu 等 2017；Lessard–Zhang–Zhu 2019 [R19–R21] | 教学依赖学习器；迭代选样；已有将顺序教学写成最优控制问题的工作 | 贡献不能写成“首次按学习器选反馈/用控制理论描述教学”；需体现未知环境证据、持续充分接口、合法编译与计成本维护的组合 |
| Datamodels，Ilyas 等 2022；TRAK，Park 等 2023 [R17–R18] | 训练数据变化到模型输出的反事实预测；TRAK 明确处理计算可行性 | “反事实响应矩阵”不是新的大类；需区分一次数据归因与状态条件的多轮合法反馈接口，并实测成本 |

| Value equivalence 2020；MIST-WM 2026 [R7–R8] | 相对于任务/函数类的模型充分性；MIST-WM 已讨论主动探索与任务充分 world model | 需证明学习更新与优化器记忆使目标接口及获取选择发生实质变化，不能只改名为 learner-relative |

特别地，datamodels 本身已经是反事实建模，不应把本稿描述成“为 datamodels 首次加入反事实”。已有顺序 machine teaching 已采用控制论，所以“把训练看作受控系统”也不是足够的差异。

Gunn 的稳定条件涉及高阶 Taylor 系数张量的 Frobenius 范数随阶数快速衰减，并且其保证依赖相应稳定量。本稿没有证明该条件适用于我们的 agent，也没有把它引入一般主线。它是一条需要认真比较的算法压缩路线，而不是可以忽略的无关工作。

### 12.1 可以作为论文贡献的三条陈述

1. **问题与表示的组合贡献。** 以受限但对未来学习操作封闭的测试类定义经验充分性，并通过响应—预测状态分解统一消息压缩与学习记忆；完整状态反例说明仅匹配即时行为/参数可能丢失后续可见信息。
2. **实现与成本的组合贡献。** 在允许状态条件反馈差异的共同接口中给出复用界，结合可执行漂移校验与无偏多保真响应估计，明确何时可摊销、何时应放弃；其真实优势等待实验。
3. **获取与编译的组合贡献。** 将尚未识别的任务后果与合法反馈凸包放入同一不确定性半径，并在逐任务校准、闭合和覆盖条件下连接最终训练误差；高斯设计只是可算特例。

这三条不是“每条都有全新数学”的宣称，也不是“整体原创性已经确认”的宣称。它们给出审稿人可以具体比较、推翻或验证的贡献单位。若实验证实这些组合带来已有方法难以得到的预测和成本收益，就具备有力论文主线；当前仍不能据此保证任何录用或 best paper 判断。

### 12.2 建议的论文摘要草案

> 用于训练学生的经验模型需要保留的环境信息，取决于学生的更新机制及其未来任务。我们研究对后续学习操作保持充分的经验接口，以反馈干预的完整续训响应定义任务几何，并建立响应等价与下一步预测状态等价的联系。完整优化器记忆的构造表明，相同即时参数更新仍可产生不同的后续结果。为使该表示可用，我们推导跨检查点共享与复用的误差条件，并采用无偏多保真校正给出响应估计的方差—成本判据。进一步，将任务相关信息的不确定性与合法反馈可实现性组合，区分应通过查询、状态扩充或反馈池扩充解决的缺口。理论保留动态闭合、校准与覆盖误差，不要求全局平稳、收缩或默认低秩。真实系统中的压缩、复用及成本收益需由相应实验验证。

这是一版**理论稿摘要**，未写入尚不存在的真实模型优越性。最终论文应以实际实验替换最后一句，而不是提前填入正结果。

"""Deterministic checks of the revised framework; synthetic, not LLM evidence.
Run with Python >=3.10 and NumPy. No network, model downloads, or GPU required.
"""
from __future__ import annotations
import json
from functools import lru_cache
from pathlib import Path
import numpy as np


def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))


def check_close(a, b, tol=2e-11):
    error = float(np.max(np.abs(np.asarray(a) - np.asarray(b))))
    assert error < tol, (error, a, b)
    return error


def main():
    rng = np.random.default_rng(20261013)
    out = {"seed": 20261013, "numpy": np.__version__,
           "scope": "synthetic mathematical checks only"}

    # Weighted, centered response operator. Euclidean x = sqrt(q) * h.
    p, m, r = 7, 11, 3
    w = rng.uniform(.3, 1.3, p); w /= w.sum()
    q = rng.uniform(.3, 1.3, m); q /= q.sum()
    G = sigmoid(rng.normal(size=(p, m)))
    Pi = np.eye(m) - np.outer(np.sqrt(q), np.sqrt(q))
    R = np.sqrt(w)[:, None] * G * np.sqrt(q)[None, :] @ Pi
    U, s, Vt = np.linalg.svd(R, full_matrices=False)
    x = Pi @ rng.normal(size=m); x /= np.linalg.norm(x)
    spectral_error = check_close(np.linalg.norm(R @ x)**2,
                                np.sum(s**2 * (Vt @ x)**2))
    Rr = (U[:, :r] * s[:r]) @ Vt[:r]
    truncation_error = check_close(np.linalg.norm(R - Rr, 2), s[r])
    hs = float(np.linalg.norm(R, 'fro')**2)
    assert hs <= .25 + 1e-14
    out["weighted_spectrum"] = {
        "spectral_identity_error": spectral_error,
        "best_rank_residual_error": truncation_error,
        "hilbert_schmidt_squared": hs,
        "singular_values": s.tolist()}

    # Arbitrary r features: construct two positive laws with matching features.
    features = rng.normal(size=(r, m))
    top = Vt[:r+1].T
    B = (features * np.sqrt(q)[None, :]) @ top
    _, _, Bt = np.linalg.svd(B, full_matrices=True)
    v = top @ Bt[-1]
    h = v / np.sqrt(q)
    alpha = 1.8 / np.max(np.abs(h))
    P = q * (1 + alpha*h/2)
    Q = q * (1 - alpha*h/2)
    assert min(P.min(), Q.min()) > 0
    check_close([P.sum(), Q.sum()], [1, 1])
    feature_error = check_close(features @ P, features @ Q)
    gap = float(np.linalg.norm(np.sqrt(w) * (G @ (P-Q))))
    lower = float(alpha * s[r])
    assert gap >= lower - 1e-13
    out["positive_law_lower_bound"] = {
        "feature_match_error": feature_error, "actual_response_gap": gap,
        "guaranteed_gap": lower, "smallest_probability": float(min(P.min(), Q.min()))}

    # Estimated singular subspaces: an eigengap is unnecessary for error control.
    eps = .004
    Ghat = np.clip(G + rng.uniform(-eps, eps, G.shape), 0, 1)
    Rhat = np.sqrt(w)[:, None] * Ghat * np.sqrt(q)[None, :] @ Pi
    Uh, sh, Vht = np.linalg.svd(Rhat, full_matrices=False)
    Phat = Vht[:r].T @ Vht[:r]
    noise = float(np.linalg.norm(R-Rhat, 2))
    residual = float(np.linalg.norm(R @ (np.eye(m)-Phat), 2))
    assert noise <= eps + 1e-13
    assert residual <= s[r] + 2*eps + 1e-13
    out["estimated_spectrum"] = {"operator_noise": noise,
        "entrywise_bound": eps, "projection_residual": residual,
        "guaranteed_residual": float(s[r] + 2*eps)}

    # Exact nonlinear Adam-like learning dynamics, including m, v, counter.
    # Gradients depend nonlinearly on theta; no zero-Hessian or stationarity premise.
    horizon = 4
    z0 = (.2, .03, .08, 2)

    def update(z, y):
        theta, mom, vel, count = z
        grad = theta + .2*theta**3 - y
        mom = .7*mom + .3*grad
        vel = .85*vel + .15*grad**2
        count += 1
        mh = mom / (1-.7**count)
        vh = vel / (1-.85**count)
        theta = theta - .17*mh/(np.sqrt(vh)+.01)
        return tuple(map(float, (theta, mom, vel))) + (count,)

    def prob(z, kind):
        return float(sigmoid((.6 if kind == 0 else -.4) + .5*z[0]-.2*z[1]))

    def terminal(z):
        return float(sigmoid(1.3*z[0]-.25*z[0]**2))

    @lru_cache(None)
    def V(t, z, kind):
        if t == horizon:
            return terminal(z)
        py = prob(z, kind)
        return ((1-py)*V(t+1, update(z, -1), kind)
                + py*V(t+1, update(z, 1), kind))

    def expectation(t, z, kind, fun):
        py = prob(z, kind)
        return (1-py)*fun(t+1, update(z, -1)) + py*fun(t+1, update(z, 1))

    def occupancies(kind):
        levels = [[(z0, 1.)]]
        for t in range(horizon):
            nxt = []
            for z, mass in levels[-1]:
                py = prob(z, kind)
                nxt.extend([(update(z, -1), mass*(1-py)), (update(z, 1), mass*py)])
            levels.append(nxt)
        return levels

    d0, d1 = occupancies(0), occupancies(1)
    gap = V(0, z0, 0)-V(0, z0, 1)
    telescope = sum(mass * (expectation(t,z,0,lambda tt,zz: V(tt,zz,0))
                            - expectation(t,z,1,lambda tt,zz: V(tt,zz,0)))
                    for t in range(horizon) for z,mass in d1[t])

    def Vhat(t,z):
        return terminal(z) if t == horizon else float(sigmoid(.15+t*.03+z[0]*.4))

    def residual0(t,z):
        return expectation(t,z,0,Vhat)-Vhat(t,z)

    response_term = sum(mass*(expectation(t,z,0,Vhat)-expectation(t,z,1,Vhat))
                        for t in range(horizon) for z,mass in d1[t])
    r0 = sum(mass*residual0(t,z) for t in range(horizon) for z,mass in d0[t])
    r1 = sum(mass*residual0(t,z) for t in range(horizon) for z,mass in d1[t])
    joint = response_term + r0-r1
    absolute_bound = sum(mass*abs(expectation(t,z,0,Vhat)-expectation(t,z,1,Vhat))
                         for t in range(horizon) for z,mass in d1[t])
    absolute_bound += sum(mass*abs(residual0(t,z)) for d in (d0,d1)
                          for t in range(horizon) for z,mass in d[t])
    assert abs(gap) <= absolute_bound + 1e-13
    state_a, state_b = (.2,.1,.04,3), (.2,.1,1.,3)
    same_theta_gap = abs(terminal(update(state_a,1))-terminal(update(state_b,1)))
    assert same_theta_gap > 1e-3
    out["nonlinear_full_state_learning"] = {
        "return_gap": float(gap), "telescope_error": check_close(gap,telescope),
        "joint_decomposition_error": check_close(gap,joint),
        "joint_absolute_bound": float(absolute_bound),
        "same_parameter_different_optimizer_response": float(same_theta_gap)}

    # Immediate value cannot reveal a hidden channel that becomes relevant later.
    states = [(s0,b) for s0 in (0,1) for b in (0,1)]
    K = np.zeros((4,4))
    for i,(s0,b) in enumerate(states):
        K[i,states.index((b,b))] = 1
    F = np.array([s0 for s0,b in states], dtype=float)
    psi = np.column_stack([np.ones(4),F])
    coeff = np.linalg.lstsq(psi,K@psi,rcond=None)[0]
    defect = float(np.max(np.abs(K@psi-psi@coeff)))
    immediate_rank = int(np.linalg.matrix_rank(psi))
    closed_rank = int(np.linalg.matrix_rank(np.column_stack([psi,K@F])))
    assert immediate_rank == 2 and closed_rank == 3
    check_close(F[0],F[1]); check_close((K@F)[1]-(K@F)[0],1.)
    out["dynamic_closure_counterexample"] = {
        "immediate_feature_rank": immediate_rank, "closed_test_rank": closed_rank,
        "closure_defect": defect, "future_gap_for_identical_immediate_value": 1.0}

    # Noncontractive finite-horizon control: past reachability and future observation.
    N, split = 5, 2
    A = [np.array([[1.15+.03*t,.12],[.04,.75]]) for t in range(N)]
    B = [np.array([[1.],[(-1)**t*.4]]) for t in range(N)]
    C = [np.array([[1.,.25+.06*t]]) for t in range(N+1)]
    columns = []
    for j in range(split):
        col = B[j]
        for k in range(j+1,split): col = A[k] @ col
        columns.append(col)
    reach = np.hstack(columns)
    rows, transition = [], np.eye(2)
    for t in range(split,N+1):
        rows.append(C[t]@transition)
        if t < N: transition = A[t]@transition
    observe = np.vstack(rows)
    H = observe@reach
    Wc, Wo = reach@reach.T, observe.T@observe
    ev, vec = np.linalg.eigh(Wc)
    root = (vec*np.sqrt(np.maximum(ev,0)))@vec.T
    gram_sv = np.sqrt(np.maximum(np.linalg.eigvalsh(root@Wo@root),0))[::-1]
    hsv = np.linalg.svd(H,compute_uv=False)
    assert max(np.linalg.norm(a,2) for a in A) > 1
    out["finite_horizon_control"] = {
        "hankel_gramian_identity_error": check_close(hsv,gram_sv),
        "hankel_singular_values": hsv.tolist(),
        "max_one_step_gain": float(max(np.linalg.norm(a,2) for a in A))}

    # Exact Gaussian target-information geometry and one-query reduction.
    design = rng.normal(size=(9,4))
    I = design.T@design+.4*np.eye(4)
    target = rng.normal(size=(3,4))
    W = np.diag([.2,.3,.5]); T = target.T@W@target
    inv = np.linalg.inv(I)
    e,v = np.linalg.eigh(I)
    invroot = (v*(1/np.sqrt(e)))@v.T
    lambdas = np.linalg.eigvalsh(invroot@T@invroot)
    risk = float(np.trace(T@inv))
    a = rng.normal(size=4)
    reduction = float((a@inv@T@inv@a)/(1+a@inv@a))
    actual = risk-float(np.trace(T@np.linalg.inv(I+np.outer(a,a))))
    out["gaussian_target_information"] = {
        "risk_spectral_identity_error": check_close(risk,lambdas.sum()),
        "query_reduction_error": check_close(reduction,actual),
        "risk_before": risk, "risk_reduction": reduction}

    # Semidefinite c-optimal design: every design misses a nuisance direction.
    # I(p)=diag(p,4(1-p),0), c=(1,1,0), optimum p=2/3.
    c = np.array([1.,1.,0.])
    design_weight = 2/3
    singular_I = np.diag([design_weight,4*(1-design_weight),0.])
    optimum = float(c@np.linalg.pinv(singular_I)@c)
    direction = np.array([2.,1.,7.])
    dual = float((c@direction)**2/max(direction[0]**2,4*direction[1]**2))
    grid = np.linspace(.001,.999,10001)
    grid_min = float(np.min(1/grid + 1/(4*(1-grid))))
    assert grid_min >= optimum-1e-12
    assert np.linalg.matrix_rank(singular_I) == 2
    out["singular_design_duality"] = {
        "primal_dual_error": check_close(optimum,dual),
        "exact_optimum": optimum, "grid_minimum": grid_min,
        "unidentified_nuisance_dimensions": 1}

    # Uniform guarantee does not follow from an average over rare tasks.
    rare_probability = 1e-6
    averaged = float(np.sqrt(rare_probability))
    assert averaged == .001
    out["rare_task_counterexample"] = {
        "weighted_rms_error": averaged, "rare_task_error": 1.0}
    # No finite rank bound follows from measurability and boundedness alone.
    universal_G = np.eye(8)
    universal_R = universal_G@(np.eye(8)-np.ones((8,8))/8)
    assert np.linalg.matrix_rank(universal_R) == 7
    out["no_universal_compression"] = {"messages": 8, "centered_rank": 7}
    out["status"] = "PASS"
    destination = Path(__file__).with_name("verification_results.json")
    destination.write_text(json.dumps(out,indent=2,ensure_ascii=False)+'\n')
    print(json.dumps(out,indent=2,ensure_ascii=False))


if __name__ == '__main__':
    main()

rng = np.random.default_rng(20261014)
out = {}

# 1. Response = observation of next predictive-state change, with centering.
m, d, p = 9, 3, 6
rho = rng.dirichlet(np.ones(m))
Gamma = rng.normal(size=(d, m))
C = rng.normal(size=(p, d))
T = (Gamma - (Gamma @ rho)[:, None]) * np.sqrt(rho)
R = C @ T
assert np.linalg.matrix_rank(C) == d
assert np.linalg.matrix_rank(R) == np.linalg.matrix_rank(T)
null_T = np.linalg.svd(T, full_matrices=True)[2][d:].T
bridge_error = np.linalg.norm(R @ null_T)
assert bridge_error < 1e-12
out['predictive_state_bridge'] = {'rank': d, 'nullspace_error': float(bridge_error)}

# 2. A shared feature space permits state-conditional inputs. A stacked
# operator norm bound for ONE common input is not valid for such inputs.
R1, R2 = np.array([[1., 0.]]), np.array([[0., 1.]])
stack = np.vstack([R1, R2]) / np.sqrt(2.)
actual = math.sqrt((np.linalg.norm(R1 @ np.array([1., 0.]))**2
                    + np.linalg.norm(R2 @ np.array([0., 1.]))**2) / 2)
wrong_bound = np.linalg.norm(stack, 2)
correct_bound = np.linalg.norm(stack, 'fro')
assert actual > wrong_bound + .2
assert actual <= correct_bound + 1e-12
matrices = [rng.normal(size=(5, 8)) for _ in range(4)]
stack = np.vstack(matrices) / 2
_, s, vt = np.linalg.svd(stack, full_matrices=False)
r = 3
P = vt[:r].T @ vt[:r]
hs_residual = sum(np.linalg.norm(M @ (np.eye(8)-P), 'fro')**2 for M in matrices)/4
assert abs(hs_residual - sum(s[r:]**2)) < 1e-10
out['conditional_checkpoint_inputs'] = {
    'actual_rms': actual, 'invalid_common_input_bound': float(wrong_bound),
    'valid_hilbert_schmidt_bound': float(correct_bound),
    'shared_basis_tail_identity_error': float(abs(hs_residual-sum(s[r:]**2)))}

# 3. Anchor interface: residual <= anchor tail + measured operator drift.
A = rng.normal(size=(7, 10))
E = .02*rng.normal(size=A.shape)
_, s, vt = np.linalg.svd(A, full_matrices=False)
P = vt[:3].T @ vt[:3]
residual = np.linalg.norm((A+E) @ (np.eye(10)-P), 2)
bound = s[3] + np.linalg.norm(E, 2)
assert residual <= bound + 1e-12
# A common-U coupling preserves Bernoulli marginals. For this coupling,
# E[(X-X0)^2]=|g-g0| >= (E[X-X0])^2 pointwise.
g0, gz = rng.uniform(size=(6, 8)), rng.uniform(size=(6, 8))
rho, omega = rng.dirichlet(np.ones(8)), rng.dirichlet(np.ones(6))
delta = gz-g0
centered_delta = delta - (delta @ rho)[:, None]
weighted_operator = np.sqrt(omega)[:, None]*centered_delta*np.sqrt(rho)[None, :]
coupled_second_moment = float(omega @ np.abs(delta) @ rho)
assert np.linalg.norm(weighted_operator, 2)**2 <= coupled_second_moment + 1e-12
out['anchor_transfer'] = {'actual_residual': float(residual), 'bound': float(bound),
    'coupling_operator_squared': float(np.linalg.norm(weighted_operator, 2)**2),
    'coupled_second_moment_upper_bound': coupled_second_moment}

# 4. Exact reachable Adam counterexample. Standard beta values and bias
# corrections, no weight decay, epsilon=0 for rational closed-form roots.
b1, b2, eta = .9, .999, 1.
def step(state, grad, t, eps=0.):
    theta, m, v = state
    m = b1*m+(1-b1)*grad
    v = b2*v+(1-b2)*grad**2
    theta -= eta*(m/(1-b1**t))/(math.sqrt(v/(1-b2**t))+eps)
    return np.array([theta, m, v])
z = step(np.zeros(3), 1., 1)
g_a, g_b = .5, 2103/790
za, zb = step(z, g_a, 2), step(z, g_b, 2)
assert abs(za[0]-zb[0]) < 1e-12
assert np.linalg.norm(za[1:]-zb[1:]) > .1
za3, zb3 = step(za, 1., 3), step(zb, 1., 3)
score = lambda theta: 1/(1+math.exp(-theta))
gap = score(za3[0])-score(zb3[0])
assert abs(gap) > .003
# Positive epsilon: adjust the second gradient to the exact equal-step root.
eps = 1e-8
zep = step(np.zeros(3), 1., 1, eps)
target = step(zep, .5, 2, eps)[0]
lo, hi = 2., 4.
for _ in range(80):
    mid = (lo+hi)/2
    if step(zep, mid, 2, eps)[0] < target:
        lo = mid
    else:
        hi = mid
gb_eps = (lo+hi)/2
zae, zbe = step(zep, .5, 2, eps), step(zep, gb_eps, 2, eps)
assert abs(zae[0]-zbe[0]) < 1e-12
assert abs(step(zae, 1., 3, eps)[0]-step(zbe, 1., 3, eps)[0]) > .07
out['adam_memory_separation'] = {'checkpoint': z.tolist(),
    'feedback_gradients': [g_a, g_b], 'equal_current_theta_error': float(abs(za[0]-zb[0])),
    'next_theta_gap': float(za3[0]-zb3[0]), 'bounded_score_gap': gap,
    'positive_epsilon_root': gb_eps, 'positive_epsilon_equal_theta_error': float(abs(zae[0]-zbe[0]))}

# 5. Differentiate the complete Adam update including Hessian=1, correction,
# epsilon and weight decay; compare to a central finite difference.
state = np.array([.7, .2, .8]); t=5; eps=.03; wd=.1; lr=.07
g = state[0]-.3
mnew = b1*state[1]+(1-b1)*g
vnew = b2*state[2]+(1-b2)*g*g
aa, bb = 1/(1-b1**t), 1/(1-b2**t)
D = aa/(math.sqrt(bb*vnew)+eps)
E = aa*bb*mnew/(2*math.sqrt(bb*vnew)*(math.sqrt(bb*vnew)+eps)**2)
next_costate = np.array([.4, -.2, .6])
q = (1-b1)*(next_costate[1]-lr*D*next_costate[0])+2*(1-b2)*g*(next_costate[2]+lr*E*next_costate[0])
adj = np.array([(1-lr*wd)*next_costate[0]+q,
    b1*(next_costate[1]-lr*D*next_costate[0]),
    b2*(next_costate[2]+lr*E*next_costate[0])])
def objective(z):
    grad = z[0]-.3
    mn = b1*z[1]+(1-b1)*grad
    vn = b2*z[2]+(1-b2)*grad*grad
    th = (1-lr*wd)*z[0]-lr*aa*mn/(math.sqrt(bb*vn)+eps)
    return next_costate @ np.array([th, mn, vn])
h = 1e-6
numeric = np.array([(objective(state+h*e)-objective(state-h*e))/(2*h) for e in np.eye(3)])
err = np.linalg.norm(adj-numeric)
assert err < 1e-8
out['full_adam_adjoint'] = {'finite_difference_error': float(err)}

# 6. Independent two-level control variate, checked by finite probability
# enumeration; no assertion that short training is always correlated.
flip = .0025
prob = np.array([.5*(1-flip), .5*flip, .5*flip, .5*(1-flip)])
X = np.array([0.,0.,1.,1.]); Y = np.array([0.,1.,0.,1.]); D = X-Y
var = lambda a: float(prob @ ((a-prob @ a)**2))
vh,v0,v1 = var(X),var(Y),var(D)
assert abs(prob@X - (prob@Y+prob@D)) < 1e-15
c0,c1,ch = .01,1.01,1.
target_mse = 1e-4
S = math.sqrt(v0*c0)+math.sqrt(v1*c1)
n = np.array([math.sqrt(v0/c0)*S/target_mse, math.sqrt(v1/c1)*S/target_mse])
assert abs(v0/n[0]+v1/n[1]-target_mse) < 1e-14
cost = n @ np.array([c0,c1])
assert abs(cost-S*S/target_mse) < 1e-10
out['multifidelity_cost'] = {'full_variance': vh, 'cheap_variance': v0,
    'residual_variance': v1, 'continuous_sample_counts': n.tolist(),
    'full_cost_at_same_mse': vh*ch/target_mse, 'multifidelity_cost': float(cost),
    'cost_ratio_before_pilot_overhead': float(cost/(vh*ch/target_mse))}

# 7. The joint robust acquisition/compilation radius: invisible uncertainty
# contributes no target diameter, while infeasibility still creates an error.
C = np.array([[1.,0.]])
M = np.array([[.2,-100.],[.2,100.]])
image = (C @ M.T).ravel()
assert np.ptp(image)==0
# If legal response outputs are [0,.1], optimal error remains .1.
legal = np.linspace(0,.1,101)
radius = min(max(abs(image-q)) for q in legal)
assert abs(radius-.1) < 1e-12
M2 = np.array([0.,1.]); legal2 = np.linspace(0,1,101)
radius2 = min(max(abs(M2-q)) for q in legal2)
assert abs(radius2-.5) < 1e-12
out['information_and_feasibility'] = {'invisible_uncertainty_diameter': float(np.ptp(image)),
    'remaining_feasibility_error': float(radius), 'two_target_optimal_radius': float(radius2)}

out['status']='PASS'
dest = Path(__file__).with_name('verification_results_v2.json')
dest.write_text(json.dumps(out,ensure_ascii=False,indent=2)+'\n')
print(json.dumps(out,ensure_ascii=False,indent=2))
