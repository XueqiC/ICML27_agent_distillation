## 0. 名词

- **θ_raw**：原始 Gemma-4-E4B-it（snapshot ee0ef60…），不带 adapter。
- **D_K**：K20 seed 0 的 20 条 teacher 轨迹（`data/verified/seeds_full_train_r2/subsets/k20`），共 315 个决策步。第 t 步是（历史 h_t，teacher 的输出 y_t，其中的动作 a_t）。这是轨迹 SFT 用的全部数据，本文所有实验也只用它。
- **Δ**：权重改动。学生 = θ_raw + Δ。SFT 和 WSP 的区别只在 Δ 是怎么来的。
- **SFT**：Δ 由优化器在 L(θ) = −Σ_t log p_θ(y_t | h_t) 上迭代得到。现有配方（`e4b-tsft-k20-e32-lr5e-5`）：LoRA 秩 64、α = 128、dropout 0.05，作用在语言模型全部 42 层的 q/k/v/o/gate/up/down 上（258 个模块），32 个 epoch，lr 5e-5，线性衰减，共 320 次更新，每个 epoch 8,552 个监督 token。
- **WSP**：Δ 不靠优化器迭代，而是由"程序员"（teacher LLM，或一条固定规则）根据对学生的读取（激活、logit、注意力，可选一次梯度）直接写出来；形式是闭式的低秩改写（去方向、加性秩一、神经元缩放、最小二乘改写），只用前向计算和 rollout 验证。
  - 参照 blog *Sparks of Weight-Space Programming*（11-04 读的原文，记在 P0 prereg）：LLM 没有 GPU、不能训练、不能用梯度，只有 10/25/50 批前向的预算；它在第 15、19 层 MLP 各 64 个输出列上减掉一个"循环"方向，共改 131,072 个权重（0.016%）。
  - 边界：P1 里 teacher 用的"局部微调"是小规模 SFT，本文不把它算作 WSP。
- **配对（s, a_f, a_r）**：对 D_K 的每一步，给 θ_raw 同样的历史，它的 greedy 动作和 teacher 不同的步。s = 该步的上下文，a_f = 学生的动作，a_r = teacher 的动作。315 步里有 90 个这样的步。

## 2. 要回答的三个问题

- **Q1 一个做对了的改动长什么样？** 它需要多大的秩、多少层、哪些模块？如果 SFT 的效果能被一个很小的改动复现，WSP 才有可能写得出来。（A、B）

## 4. 实验

### A 组：LoRA SFT 的"大小—效果"曲线（方案 4）

每次只动一个因素，其余和 A0 相同（α = 2r，dropout 0.05，32 epoch，seed 0）。

| 臂 | 改动 | 训练次数 |
|---|---|---:|
| A0 | 参照：秩 64，全部模块（重训一次，和下面同批） | 1 |
| A1 秩 | 秩 16 / 4 / 1，全部模块；lr 各取 5e-5、2e-4 两档（低秩时原 lr 可能偏小），按 T1、T2 选，两档都报 | 6 |
| A2 位置 | 秩 16：只 MLP（gate/up/down）；只 attention（q/k/v/o）；第 0–13 层；第 14–27 层；第 28–41 层；B1 的 3 个模块 | 6 |
| A3 监督 | 秩 64、全部模块，但只用 90 个配对、只监督动作（B1 的监督方式） | 1 |

**K100 上的 A 组**（小一些）：A0-K100（秩 64，全部模块，64 epoch，lr 1e-4）；秩 16 / 4 / 1（lr 1e-4）；只 MLP、只 attention（秩 16）。共 6 次训练。A4 同样取中间 checkpoint。

### B 组：把"做对了的改动"拆开看（方案 2 的一种读法）

- **B1 谱（已做，11-15 21:37 CST，CPU）**：现有 seed 0 SFT adapter 的 Δ = (α/r)·BA，258 个模块逐个算奇异值。
  - 每个模块内部接近低秩：stable rank 中位数 3.0（四分位 2.1–4.7）；按范数平方算，第 1 个方向占 39%，前 4 个 55%，前 16 个 78%，前 32 个 90%。
  - 但在层上是摊开的：42 层每层占 1.3%–3.2%，没有集中在某几层；凑够 50% 的范数要 50 个模块，90% 要 153 个。
  - 按模块类型：gate_proj 38%、up_proj 34%（MLP 输入侧合计 72%），q_proj 9%，down_proj 8.5%，o_proj 8%，k/v 各 1%。
  - 这只是范数，不等于功能，所以要做 B2。
- **B2 功能截断（不训练）**：把 A0 的 Δ 每个模块截到秩 1 / 4 / 16；只保留范数最大的 23 / 50 / 90 个模块（对应 25% / 50% / 75% 范数）；只保留 MLP 输入侧。截断后的 Δ 仍是一个 LoRA adapter，直接评测。
- **B3 多个学生的共识**：在同一 D_K 上训练的多个学生（A0 加两个新种子，以及 A1 的低秩学生）。
  - 它们的 Δ 两两之间主方向的重合度有多高（同一模块前 k 个奇异子空间的夹角）；
  - 共识改动（各学生 Δ 的平均，以及它的低秩截断）直接装到 θ_raw 上，评测。
  - 问题是：不同学生学到的是不是同一个改动。如果是，而且低秩，"正确的改动"就是一个稳定的、可以去找的目标。
  - 新增训练：2 次（seed 1、2）。K100 上同样做 B2、B3（K100 的 seed 1、2 再训 2 次）。
  - 跨数据量：K100 学生的 Δ 和 K20 学生的 Δ 是不是同一个方向、只是幅度不同（重合度，以及把 K100 的 Δ 缩放后和 K20 的比）。
- **B4 几个不同基座（方案 2 的另一种读法，用户 21:45 CST：两种都做）**：
  - 学生：原始 E4B、原始 Gemma-4-12B-it，以及它们各自的轨迹 SFT 版本（不用 2B；不用中国模型）。
  - 做法：让每个学生在同一批训练题（K20 的 20 题、K100 的 100 题）上从头做，并在 teacher 的历史上逐步对比动作。得到一张"题 × 学生"的成败表和"步 × 学生"的一致表。
  - 综合：把失败分成三类——所有原始学生都错、SFT 后都对的（任务知识，SFT 教会的东西）；只有 E4B 错、12B 对的（E4B 自己的缺陷）；SFT 后仍错的（SFT 也没解决的）。每类给出题数、步数和例子。
  - 用途：不同基座的权重不能直接相减，所以 B4 不产生 Δ；它给 D 组的 teacher 提供"该改什么"的依据，D 里对照"只看 E4B 的失败"和"看这张多学生表"两种输入。

### C 组：不迭代优化的闭式改写（方案 3，我的建议）

- **C1 一步梯度改写**：在 θ_raw 上对 D_K 算一次 SFT loss 的全量梯度 G（每个模块一个矩阵），取秩 r 截断 G_r，Δ = −η·G_r，r ∈ {1, 4, 16}；η 在 T1 上线搜。它是"SFT 的第一步"，也是程序员能读到的最直接的信号。同时报告 G_r 和 A0 最终 Δ 的方向重合度。
- **C2 把上下文里的示范编译进权重**：先测只把 D_K 的示范放进 prompt、不改权重时 θ_raw 能到多少。如果明显高于 40.5，再逐层做最小二乘，把"有示范时的模块输出"编译成一个低秩 ΔW（有闭式解）。
- **C3**（已有，不重跑）：激活均值差去方向，39.0，无效。

## 5. 判定（按点估计，预先写下）

- B2、A1、A2 显示秩 ≤ 4、不超过 25% 的模块就能保住 dev140 ≥ 70：小改动原则上够，重点转到 C、D（不靠优化器能不能找到它）。
- 需要高秩或全部层才行：在这个任务上，"只改少数位置"的 WSP 到不了 SFT。WSP 的故事要改成"写一个全层的低秩改动"（C1、C2 的路线），或者换到 WSP 更占优的场景（K 很小；或接在 SFT 后面修特定失败）。
- C1 的秩 ≤ 4 改写 dev140 ≥ 59（拿到 SFT 增益的一半）：可读信号里有足够的信息，值得让 teacher 去写。
- D 的 teacher 改写高于 C1 和随机对照至少 4 题：teacher 的读取有额外价值。

## 15. C1 按回复的组成部分拆开（我加的；11-16 03:40 CST 登记，先于作业；以上各节不改）

**问题。** §14 的现象是：训练目标降一半，闭环里 Thought 变成占位符。每一步 teacher 回复的形式是 `Thought: <自由文本>\nAction: <一条命令>` 加回合结束符。训练目标是所有监督 token 的平均，其中大部分 token 属于 Thought。要回答两件事：(a) 训练目标的值和它的下降主要来自哪一部分；(b) 只用 Action 部分的梯度做一步改写，闭环里会不会不一样。

**定义**（代码 `tools/wsp_onestep.py`，分支 wsp-eseries a5e1a76）。
- 每个 assistant 回合的监督 token 按联合解码的前缀分成两类：`Action:` 这个子串第一个字符所在的 token 之前的都算 **thought**（含 `Thought:` 前缀和换行），从它开始到回合结束符都算 **action**；没有 `Action:` 的回合整段算 other。
- **thought_first** = `Thought:` 及其后空格之后的第一个监督 token（闭环里变成 `...` 的就是这个位置）。
- `score` 对每一类报告 token 数、每 token 的 NLL、argmax 准确率，以及 action 部分整步全对的比例（action_turn_exact）。
- `gradient --span action|thought`：把另一类 token 的标签屏蔽（置 −100）之后，用同一个 SFT 目标算全量梯度；每条样本内仍按剩下的 token 取平均。

**做什么（K20，LONI A100，新代码树 wsp_a5e1a76，评分单元 sd-k20）。**
1. 原始模型、SFT（现成种子 0）、§10 的全 token 一步改写（秩 64，‖Δ‖ = 0.0625 / 0.125 / 0.25）各自按类的 NLL 和准确率，外加逐 token 明细。
2. **C1-act**：只用 action token 的梯度，秩 64；‖Δ‖ ∈ {0.0625, 0.125, 0.25, 0.5, 1, 2} 上按类报告训练目标。
3. **C1-thought**：只用 thought token 的梯度，同样处理，‖Δ‖ ∈ {0.0625, 0.125, 0.25, 0.5}。用来确认占位符是不是 thought 这部分梯度带来的。
4. 三个梯度（全部 / action / thought）之间、以及它们和 SFT 的 Δ 之间的重合度。
5. 闭环：C1-act 的 ‖Δ‖ ∈ {0.125, 0.25, 0.5, 1, 2} 和 C1-thought 的 {0.125, 0.25} 进 T2-train（§14 的 20 道训练题）。

**规则。** 和 §14 一样：C1-act 取 T2-train 成功率最高的步长（并列取小的），dev140 跑两次；没有任何步长超过原始模型就记为"没有可用步长"，最好的那个跑一次 dev140。C1-thought 只是诊断，不进 dev140，除非它在 T2-train 上超过原始模型。

**预先写下的读法。**
- 如果 thought 类占了训练目标的大头，而且全 token 一步改写的下降几乎都在 thought 类：平均 token loss 主要在量"写 Thought 的文风"，不是"选动作"。
- 如果 C1-act 在闭环里不破坏 Thought 并且超过原始模型：一步闭式改写是可行的，前提是只对决策 token 求梯度。
- 如果 C1-act 也不行：一步梯度这个信号本身不够，不是 token 选择的问题。

### C4：加性方向（我加的）

- 写法：在第 l 层 `mlp.down_proj` 上做加性秩一 W + a·bᵀ，a = α·(δ_l − δ_{l−1})（δ_19 记为 0，这样各层的增量累加后，第 l 层残差平均移动 α·δ_l），b = 该层 down_proj 输入在 K20 全部 token 位置上的均值 m_l 除以 ‖m_l‖²（使 bᵀx 平均为 1，即近似一个常数偏置；同时报告 bᵀx 的变异系数）。α ∈ {0.5, 1, 2, 4}。
