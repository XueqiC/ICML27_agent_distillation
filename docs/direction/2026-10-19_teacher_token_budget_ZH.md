## 几点说明

1. **full cell 占了 60% 左右**，约 50 亿 token。HAD 是例外：它的 15 个 K cell 每个也是固定 3 万次调用，所以 HAD 的 K cell 加起来就有约 23 亿。
2. **数字可能偏高。**
   - 我们的 prompt 是"system 加不断增长的历史"，前缀高度重复。如果 OpenAI 的自动 prompt caching 生效，实际计费的输入会少很多。
   - 但目前采集记录里 cached_tokens 一项都是 0，可能是没有记录这个字段，也可能确实没有命中缓存。需要你在 billing 页面看一下实际扣费，才能知道 R 对应多少钱。
3. **数字也可能偏低。** CoA 和 AgentDistill 的调用次数是按假设估的；HAD 的 prompt 带了 harness 信息，可能比 5.1k token 更长。
4. **建议的执行顺序**：先跑完 K cell，full cell 最后跑。每个方法跑完第一个 cell 后，用实测用量替换掉这张表里的假设，再更新给你。
