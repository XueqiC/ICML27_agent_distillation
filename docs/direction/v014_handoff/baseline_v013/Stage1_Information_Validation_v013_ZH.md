# 第一阶段：环境信息理论与 Agent 蒸馏验证 v0.13

日期：2026-10-09。当前主理论：Environment_Information_Theory_v013_ZH.md。WM 是可选的信息接口实现；本方案不依赖某个 WM 架构、checkpoint 或视觉动力学假设。

状态：已完成 verify_environment_information_v013.py 中列出的有限构造核算；本方案中的重复统计试验、实际神经学生训练和真实 agent 测试均尚未执行。数值核算不是实验结果全集。

## 1. 实验所要裁决的主张

第一阶段要回答：在既定学生执行能力和允许反馈下，哪些环境信息能改变可达到的学生决策，哪些经验关系必须经过训练接口保存，所推导误差是否真正预测学生在真实任务中的表现。

不以“接口看起来像环境”“生成样本更多”“平均预测更准”代替这个问题。实验主轴是信息内容、学习后果与复用能力；查询、token 和计算成本分别记录，不把总预算优化另立为中心贡献。

分三个层次：

- A0：可精确计算的构造与数学实现核对。当前已部分完成。
- A1：实际运行表格/有限类蒸馏，验证信息获取、接口选择、训练和部署的闭环。
- B：一般神经学生及工具任务中的机制与方法验证。此时明确哪些数学假设仍成立、哪些只能作经验检验。

A0/A1 不能通过时先修正问题，不能用更大模型的成功率掩盖错误。B 的负结果须保留并定位，不能持续更换评价集直到显著。

## 2. 固定统计单位与数据角色

K 表示每个任务族起始拥有的完整可信教师示范数，不是任务数量、token 数或全部后续信息。所有新查询、外部知识和预训练信息来源另行登记。

独立统计单位为独立生成的任务实例/完整经验块，以及独立训练的学生重复。一个 episode 中的 token、动作、重试与教师标签可相关。回放已有经验不增加真实独立样本数。

| 数据/对象 | 用途 | 独立性要求 |
|---|---|---|
| 初始信息 I₀、K 条示范 | 全方法共享起点 | 明确教师与学生可见字段 |
| D_pilot | 选特征、候选接口、任务参数范围与训练配置 | 不进入最终证书 |
| D_calibration | 估计真实/候选特征均值并选择有限候选 | 候选集合与特征在读取前冻结 |
| D_fit | 训练实际学生 | 记录完整块关联和来源 |
| D_tail | 必要时估计真实后续学习测试/近似余项 | 不用拟合残差冒充全域证书 |
| D_deploy | 最终真实任务评价 | 不参与候选或超参数选择 |
| 未见配方与未见任务集 | 测接口可复用性 | 预先定义留出轴，避免把重新调参称为直接迁移 |

候选在 D_calibration 上选择本身合法，因为使用覆盖全部预定候选的统一界。若继续生成候选、修改特征或反复看最终评估后调参，就需要新的独立审计或相应自适应统计理论。

实验失败概率建议分配：δ_cal=.02、δ_tail=.01、δ_coverage=.01、δ_deploy=.01，总和 .05。某些实验不需要所有项时，报告实际使用的分配。现有代码中的分支与编译示例分别使用 .05 和 .025，联合保证为 .925；不能混成这一建议的 .95。

## 3. A0：五组精确机制实验

### A0.1 教师完美，但学生所需信息缺失

使用主稿第 2 节的 E_±。初始示范 K∈{1,4,16,64}，Δ∈{.025,.05,.1,.125}。教师看见隐藏状态；学生部署严格保持单一别名上下文。训练时哪些状态字段可见要固定，不能在改善方法时同时给学生更多部署信息。

比较：

1. 被动频数/交叉熵模仿；
2. 任意回放或同一示范的合成重写；
3. 允许分支实验后的方向识别与目标编译；
4. 知道 v 的学生类最优策略，作为有限类上界；
5. 额外开放隐藏状态的学生，只作表示/信息权限变化的单独正控制。

记录教师收益、学生类最优值、实际学生值、被动 regret 下界、查询识别错误和编译误差。方法 3 应在同样部署权限下突破被动信息地板；方法 5 改变了 Π，不能和方法 3 混成同一种改进。

使用二项分布精确计算验证固定查询设计的错误率。跨 Δ 看达到相同识别错误所需样本数是否符合 Δ^{-2} 阶；不要把某一个算法曲线拟合当作所有学习器下界的证明。

反证/故障定位：

- 被动方法稳定区分两个世界：先查泄漏的 v、额外预训练知识或未计入的查询。
- 主动方向识别正确但学生未改善：检查目标编译、实际输出概率和部署权限。
- 教师已不完美：环境实现偏离理论构造。

### A0.2 静态评估等值，不代表蒸馏价值等值

使用第 3.1 节四状态构造。对 p∈{0,.05,…,1} 检查两来源静态学生收益一致；核对同一最优教师收益均为 .6。

从每种来源独立采集 m∈{1,4,16,64,256} 个教师动作，实际拟合频数学生，并统一在 E 中部署。精确期望为 .5375 与 .5125，差 .025，不随 m 变化。有限重复均值应收敛到该差距。

诊断指标：教师动作频率、学生可见上下文、训练目标均值、部署价值。不能只报告静态模型评估误差为零就宣称信息传递可靠。

### A0.3 联合信息的严格层级与曝光量预测

构造第 5 节 P_N、Q_N，N∈{2,3,4,5}；块内教师标签随机排列，但块边界始终保留。每一块 Z 是 N 个相关标签的频数。

部署任务 J(p)=p^N，学习器 p̄_n=n^{-1}Σ Z_i，n∈{1,2,4,8,16,32}。

必须同时测：

- 阶数 1,…,N 的原始矩误差；
- 真实最终收益差和式 (24) 的精确预测；
- log|差值| 对 log n 的斜率，理论为 −(N−1)；
- 独立块数、原始教师标签数与回放次数，分开作横轴。

用精确卷积先得到真值，再作随机重复检验置信区间覆盖真值。高阶差值会很小，若有限重复不足以分辨，应报告检测能力不足，而不是报告理论不成立或“没有影响”。

加入二坐标构造：P={(0,0),(1,1)}，Q={(0,1),(1,0)}，各等概率；全部单坐标边缘完全相同，联合成功率不同。把坐标独立打乱作为信息损坏干预。

正控制：构造两个不同分布但对目标次数范围全部所需矩匹配的来源，验证最终期望值确实相同。可用更高阶 P_{N+1}/Q_{N+1} 服务≤N 次任务；不是只展示失败反例。

### A0.4 训练非线性如何改变所需信息

保持部署只有一步：

- 仿射更新作对照；
- 阈值更新 p=1{Z>.5}，使用主稿第 5.7 节的同均值来源；
- p₁=Z，随后平方更新，R∈{2,3,4,5}。

平方更新中使用 D=2^{R−1} 阶有限差分分布；精确有理数验证全部低于 D 阶矩匹配，但最终收益差非零。这里只证明允许的多项式更新类内次数上界可达到，不把平方更新当作一般 LLM 优化器。

此组实验的目的，是防止将“部署 N 步只需 N 阶信息”误用到任何学习算法。神经更新的效果要在 B 阶段另测。

### A0.5 有限接口证书、残差与覆盖

构造有限消息字母表、学习状态和候选接口，分三个难度：

- 已知精确后续测试，含完全正确接口，检查正控制；
- 没有完全正确接口，已知各候选真实误差，检查最优候选相对界；
- 只传递不完整测试特征或故意遗漏状态，检查 τ/ρ 必须进入证书。

对每个候选量化 D_j、Dhat_j、实际训练价值差、统计上界和上界松紧。先检查固定特征/候选是否确实冻结；然后才检验 95% 覆盖率。

重复审计覆盖率时预先取 1000 次独立重复，并报告二项置信区间。1000 不是普适必要样本量，实际报告应说明其分辨率。若只运行一次，如当前脚本，必须称“单次有限核算”。

必要消融：只匹配均值、匹配均值+协方差、匹配到所需阶、全消息分布匹配；不完整特征但错误设置 τ=0；有出界但错误设置 ρ=0。后两项只能作为故障演示，不能出现在正式保证里。

## 4. A1：实际蒸馏算法闭环

### A1.1 输入与流程

输入：学生上下文表、少量可信示范、允许查询接口、预定任务类及最大次数、有限候选消息提供器、冻结学习器配方。

按以下流程运行：

1. 明确哪些歧义会改变学生最优动作；在可控族中其真值已知，用于检验信息缺失。
2. 取得允许的新反馈，形成经证据修正的学生训练目标；若访问不足，报告不可辨识，不能猜出隐藏变量。
3. 每种候选接口输出完整经验块。基于 D_calibration 的联合矩统一置信界选择接口。
4. 从所选接口独立抽块，用相同仿射更新训练学生。
5. 在真实环境评估实际学生，与真实参考信息训练、初始学生、被动行为克隆及学生类最优值比较。

接口候选可以是完整块回放、重加权块库、结构化反馈编码、不同联合相关性的采样器。使用不含完全正确候选的组，避免方法永远只选择已知 oracle。

### A1.2 需要区分的两个成功标准

**保真成功：** 所选接口学生接近使用真实参考信息训练的学生，且误差落在声称证书内。

**蒸馏成功：** 实际学生相比初始或被动模仿基线有真实改善。这个结论必须另验参考配方本身有效，不能由保真单独推出。

报告目标概率 q、实际学生 p、教师 T 三个对象；目标 q 的好性能不能替代 p 的成绩。若训练效果超过真实参考来源，允许有符号的学习价值差为负，不将其截断后丢失证据。

### A1.3 检查复用，而不是只为一个学习器过拟合

留出初始化 p₀、确定权重序列、独立块数和次数范围内的部署任务，在接口选择完成后直接使用同一接口。定理 4/6 覆盖这些留出轴，应该验证不需要重选接口。

另留出非线性学习器作为边界测试。不能因为同一接口在仿射族迁移成功，就声称已保证任意模型架构、任务或优化器迁移。

## 5. B：真实神经 Agent 的方法验证

本阶段沿用项目已确定的黑箱教师、学生与模型来源约束；不从旧 WM 方案推导新的模型选择。教师可用信息明确限于实际接口输出。理论不假设教师内部参数、隐藏推理、logit 或梯度可得；需要这些访问的基线应放入单独访问组，不能无标注地混比。

### B.1 首选任务结构

先做可恢复、可随机化实例的工具任务，确保真值可检验：

- 多步工具依赖：改变较早动作会影响后续可执行分支，终局成功可自动判定。
- 部分反馈与恢复：学生需要利用失败消息选择恢复动作，教师成功示范不覆盖全部分支。
- 等边缘、异联合的经验组织：在同一真实记录中有控制地改变块关联或跨步骤配对，保持指定边缘统计。

这些是拟建实验条件，不冒称现有公开 benchmark 的特性。随后再在至少一个固定外部环境做验证；具体环境根据实际可用的恢复、观测和评价接口选择，不能为获得结果而更换访问规则。

先固定 student 可见上下文与 harness，避免同时修改记忆权限、重试策略、模型大小与反馈接口造成混杂。

### B.2 方法与对照

| 组 | 使用的信息与学习方法 | 要回答的问题 |
|---|---|---|
| 原始教师轨迹模仿 | K 条初始示范，标准监督目标 | 被动基线 |
| 更多同来源记录/回放 | 相同信息来源，区分新增记录与重复回放 | 数据量能否消除该差异 |
| 交互教师标注 | 相同允许真实查询，教师对学生访问上下文给反馈 | 新信息本身带来多少收益 |
| 代价/后果加权目标 | 使用相同环境反馈估计相对动作后果 | 是否只是常规代价敏感模仿的收益 |
| 梯度或多步参数轨迹匹配 | 只用实际允许取得的学生训练信息 | 学习后果指标是否超过这些直接基线 |
| 本稿接口选择/校准 | 完整块、预定后果测试及独立校准 | 信息结构与证书能否预测实际学生收益 |
| 可选生成接口或 WM | 与上述组相同允许信息和数据来源 | 某种实现是否更方便，非理论成立前提 |

适用时纳入 reward/Q moment matching 的原论文实现或访问兼容版本；若修改了访问和目标，明确称适配基线，不能报告成完整复现。

各方法可使用同样的有用观测与反馈，不人为禁止基线访问本方法拥有的信息。样本数、教师调用、真实交互、后续训练、模型规模和墙钟时间分项报告。补充成本匹配曲线用于排除明显算力混杂，但主结论不等于成本最优化。

### B.3 可测替代量与有效性界线

先测试：

- 单步学生更新均值、协方差及有限方向投影；
- 完整经验块与打乱后的差异；
- 从有限可恢复训练快照作短后续训练后的真实价值；
- 接口误差对最终真实训练价值差的留出预测；
- 未见初始化、更新步数与任务实例的迁移。

有限神经梯度投影不是“全部所需信息”。短尾训练价值不是长尾 V。若没有验证余项与覆盖，称为代理指标，并报告其失效情况；不能沿用主稿的条件证书写成无条件保证。

将信息接口在一组配方上校准，锁定后对另一组配方评估。至少把“换初始化”和“换优化/更新规则”分开报告，后者通常超出仿射保证。

### B.4 评价与统计

主指标为独立训练的实际学生在真实环境的成功率/归一化收益；同时报告真实参考训练收益与二者有符号差。教师行为相似度、训练 loss 和环境预测误差只作诊断。

采用任务实例配对评测。相同训练种子的多个部署 episode 不是独立训练重复；对方法均值采用以训练重复、任务族为聚类单位的适当区间，保留每个种子与任务结果。

昂贵训练重复数通过独立 pilot 的方差与预先定义的最小有意义改善确定，至少报告其检测能力；不把任意固定的少量种子当成普适充分。不能以未显著差异证明两方法等价；等价/非劣需要预先设定容许误差。

## 6. 验收与论文主张

| 验收项 | 通过标准 | 失败后应作什么 |
|---|---|---|
| 数学实现 | 精确构造与恒等式一致，所有量词/访问条件标出 | 修正证明或实现，不扩大主张 |
| 信息层级 | 低阶匹配反例、高阶充分正例同时成立 | 查块定义、更新非线性、环境参数泄漏 |
| 误差率 | 在可分辨范围内吻合常数与指数，原始真值可重算 | 报告检测能力或明确模型不满足条件 |
| 统计证书 | 重复审计覆盖符合所声明失败预算 | 处理自适应选择、遗漏残差和出界 |
| 蒸馏效果 | 实际学生有真实改善，且可区分新增信息与传递效果 | 检查参考配方是否有效与训练可达性 |
| 可复用性 | 不重选接口，在声明覆盖的未见配方上成立 | 缩小声明的学习器/任务类 |
| 新颖性 | 对直接相近文献逐条说明何处已有、何处新增 | 将重述结果降为工具，引入确有必要的核心问题 |

本阶段可以否定某种接口或代理指标，也可以发现理论仅适用于受限配方。这样的结果应决定论文范围。不得预先写“最佳论文级贡献已经完成”。
