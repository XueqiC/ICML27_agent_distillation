# v0 的停止规则：on-policy 误差界与覆盖项

2026-11-02。用途：说明 v0 为什么用"合成留出题上的成功差距"决定停止，为什么修复只需改"致命动作"（殊途同归），以及停止之后剩余的差距属于哪一项。

**结论先行**
- 学生与参考策略的失败率之差 ≤ u · T · ε_b。其中 ε_b 是学生在**自己访问的状态**上采取"致命动作"的单步概率。这是 Ross, Gordon & Bagnell (2011) Theorem 2.2 证明的直接推论，只是把"与专家不同"换成"让专家无法完成"，所以这个界更紧。
- 因此 on-policy 修复只需消除致命动作，不必模仿 teacher 的每一步。离线模仿只控制专家状态上的误差，界是 T² 量级（同文 Theorem 2.1）。
- 在合成分布上差距降到噪声水平之后，dev 上剩余的失败只能来自覆盖项（合成题没有覆盖到的条件，或者同一条件下合成题与 dev 题之间的差异）。这时应扩大生成器，而不是继续循环。
- 这个界可能很松。它的作用是决定该停在哪里、下一步改哪一项，不用来预测数值。

## 1. 设定

- 任务 x 来自分布 P，horizon T（v0 中 T = H = 40 步）。
- 状态 s 包括任务与公开历史。策略 π 在 s 上给出动作分布 π(·|s)。
- 每步代价 C(s, a) ∈ [0, 1]：只在 episode 结束且未成功时为 1，其余为 0。于是 J(π) = 失败概率。
- 参考策略 π*：只使用公开信息的 teacher+harness（闭环评价近似的正是它）。它不一定 100% 成功，J_syn(π*) 可以在留出题上抽样测量（teacher 从起点接管）。
- 为什么不用规划器作 π*：规划器知道隐藏的物体位置，几乎任何动作之后都能重新规划完成任务。于是 Δ 只会在剩余步数不够时才大于 0，所有"致命"都集中在最后几步，诊断价值很低。参考策略必须和学生看到同样的信息。
- d_π^t：执行 π 时第 t 步的状态分布。

**Definition 1（cost-to-go 与动作差距）** 记 Q_t(s, a) 为在第 t 步于 s 执行 a、之后执行 π* 的失败概率。定义 Δ_t(s, a) = Q_t(s, a) − Q_t(s, π*)，其中 Q_t(s, π*) = E_{a'∼π*(·|s)} Q_t(s, a')。

**Definition 2（致命动作）** 若 Δ_t(s, a) > 0，称 a 在 s 上是致命动作：执行它之后，即使由 π* 接手，失败概率也会上升。Δ_t(s, a) ≤ 0 的动作即使与 π* 不同，也不算错误（殊途同归）。记 u = sup Δ_t(s, a) ≤ 1。

**Definition 3（on-policy 致命率）** ε_b(π) = (1/T) Σ_t E_{s∼d_π^t} P_{a∼π(·|s)}[Δ_t(s, a) > 0]。

## 2. 误差界

**Theorem 1** J(π) − J(π*) ≤ u · T · ε_b(π)。

**Proof**
- 由 Ross et al. (2011) Theorem 2.2 证明中的 telescoping 恒等式：J(π) − J(π*) = Σ_t E_{s∼d_π^t}[Q_t(s, π) − Q_t(s, π*)]。
- 对每个 s，Q_t(s, π) − Q_t(s, π*) = E_{a∼π}[Δ_t(s, a)] ≤ E_{a∼π}[Δ_t(s, a) · 1{Δ_t(s, a) > 0}] ≤ u · P_{a∼π}[Δ_t(s, a) > 0]。
- 代入并按 Definition 3 求和即得。∎

**Remark**
- Ross et al. 用的是与专家不同的 0-1 损失。致命动作的指示函数不超过这个损失，所以 ε_b ≤ ε_disagree。按殊途同归计错，界只会更紧。
- 对比：在专家状态分布上训练（离线 teacher 轨迹），Ross et al. Theorem 2.1 给出 J(π) ≤ J(π*) + T²ε，ε 在 d_{π*} 上测量。v0 在学生自己的状态上修复，对应的是 Theorem 1 的线性界。

## 3. 从合成分布到 dev 分布

**Proposition 2（覆盖分解）** 把任务按"条件" c 分组（任务类型 × 改动类型）。设 dev 上条件 c 的权重为 P_dev(c)，合成生成器覆盖的条件集合为 𝒞。则

J_dev(π) = Σ_{c∈𝒞} P_dev(c) [J_syn(π | c) + δ_c(π)] + Σ_{c∉𝒞} P_dev(c) J_dev(π | c)，

其中 δ_c(π) = J_dev(π | c) − J_syn(π | c) 为同一条件下合成题与 dev 题之间的差异。这是恒等式，不需要额外假设。

**Corollary（停止规则的依据）**
- 训练只能降低 J_syn(π | c)。Theorem 1 应用在合成分布上，给出 J_syn(π | c) ≤ J_syn(π* | c) + u T ε_b,syn(π | c)。规划器见证只保证任务可解，不保证 J_syn(π* | c) = 0。
- 当所有 c 上在新合成的留出题中测得的 J_syn(π | c) 都在噪声范围内（预注册修订 1：Clopper–Pearson 95% 上界 < 5%），继续在同一生成器上训练已没有可降的项。dev 上剩余的失败只来自 δ_c 和未覆盖的条件。
- 下一步只能二选一：扩大 𝒞（增加生成器或条件类型），或者缩小 δ_c（让合成题更接近真实任务的分布，比如更远的改动档）。

**哪些项可以测**
- J_syn(π | c)：每轮在合成留出题上测量，用于停止。
- ε_b：可由闭环评价中 teacher 标出的致命步，以及修改后能否成功来估计，用于诊断。
- δ_c 和未覆盖部分：只能在最终 dev140 评测之后做事后分析（把 dev 失败按条件归类），不能用于训练或选择。
