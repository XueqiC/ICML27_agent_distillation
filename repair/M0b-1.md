## Sampled decoding

`eval/run_suite.py --decoding sampled --sampling-seed 0`,
`scripts/eval_adapters.sh` with `DECODING=sampled`, and
`tools/rollout_pool.py run --decoding sampled --sampling-seed 0` select
temperature 0.7, top_p 0.95, n=1. Each turn uses the same canonical JSON/hash
seed rule as SAG. Task identity is bound as accounting metadata before the
runner strips it from model inputs. Greedy, SAG and WKM retain their settings.

## Coverage commands

Supply the actual main-grid K20 view, not a newly selected K20 support set:

```bash
PYTHONPATH=src:. python -m tools.repair_coverage \
  --config configs/base_e4b.yaml --tasks /path/to/main-grid-k20/selection.json \
  --endpoint http://127.0.0.1:8000/v1 --model-name e4b-tsft-k20-e32-lr5e-5 \
  --output reports/runs/repair-coverage-plan --plan-only
```

The plan prints the execution command and every planned episode without
constructing a client or environment, and writes nothing. For later execution,
remove `--plan-only`, supply `--server-provenance`, `--lora-check` and installed
environment data via `--data-root` or `ALFWORLD_DATA_ROOT`. The adapter report
must match the configured base model/revision and serving identity. The config
supplies H (40 in `base_e4b.yaml`); output cap is 1024 and thinking is off.
Serving context limits come from server provenance.

`--extra-sampled N` accepts 0, 1 or 2. Every invocation is a fresh complete
schedule: greedy, sampled seed 0, then optional sampled seeds 1..N. It does not
resume another run or silently collect extras. To use a nonempty frozen U_mech,
pass `--tasks data/manifest/repair_v01_splits.json --task-set U_mech`.
Empty lists, duplicate task groups, D_probe groups, dev and sealed tasks are
rejected before execution. U_mech is reported as P1 separately from P0.

Each attempt preserves the pool's complete artifacts, including failed calls
and preflight failures. Root `rollouts.jsonl` retains the exact pool record
format; `episode_index.jsonl` associates it with attempt/decoding/seed.
`summary.json` reports success per attempt, distinct failures, type counts,
unknown/error outcomes and the preregistered branch label. A branch label is
actionable only when all planned outcomes are known and error-free.

`failures.json` freezes up to 20 distinct failed tasks, one episode per task:
earliest failed attempt, sorted by type then sha256(`[20261028, task_id]`).
All other attempts remain evidence. Known parser/context failures follow the
existing harness semantics. Unknowns and infrastructure errors cannot count
toward the six-task threshold. This milestone does not select repair probes,
request labels or establish a scientific finding.
