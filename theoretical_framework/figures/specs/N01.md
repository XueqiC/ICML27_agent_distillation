# Figure spec — N01 (output `N01_decomposition`)

**Message.** Total regret splits exactly into representation, information and algorithm terms. Garbling the transcript can only raise the information term. The robust ambiguity value is the same whether computed as a min over policy mixtures or as a max over priors.

**Data.** Recompute a small exact instance, defined below. Committed JSON stores only aggregates for C1. Panel (c) uses committed data: `theory/v014_repro/results_v014_rerun.json` → `robust_ambiguity_minimax`. Use `fractions.Fraction` and convert to float only for plotting.

**Instance for panels (a) and (b).**

- Environments $`e_1,e_2,e_3`$ with prior $`(\tfrac12,\tfrac13,\tfrac16)`$.
- Student class $`\Pi=\lbrace \pi_1,\pi_2,\pi_3\rbrace`$ with values:
  - $`e_1`$: $`(0.9,0.5,0.6)`$
  - $`e_2`$: $`(0.4,0.8,0.6)`$
  - $`e_3`$: $`(0.4,0.5,0.7)`$
- $`\Pi_{\rm ref}=\Pi\cup\lbrace \pi^\star\rbrace`$ with $`J_E(\pi^\star)=1`$ for all $`E`$.
- Binary transcript $`D\in\lbrace d_1,d_2\rbrace`$ with $`P(d_1\mid e)=(0.8,0.3,0.5)`$ for $`e=e_1,e_2,e_3`$.
- Write all decimals as exact rationals.

**Panel (a): stacked horizontal bars, one per learner, decomposing $`\mathbb E[J^{\rm ref}-J(\widehat\pi)]`$.**

- Segments, in this order: $`\mathcal R_{\rm rep}`$ (grey), $`\mathcal R_{\rm info}`$ (blue), $`\mathcal R_{\rm alg}`$ (orange).
- Four learners:
  1. Bayes, the posterior-optimal policy per $`D`$;
  2. prior-only, the best fixed policy under the prior, ignoring $`D`$;
  3. uniform random over $`\Pi`$;
  4. Bayes on a garbled $`D'`$, a binary symmetric channel with flip probability $`0.25`$, treated as a learner on $`D`$.
- Annotate each bar with its total.
- $`\mathcal R_{\rm rep}`$ and $`\mathcal R_{\rm info}`$ are identical across bars. Only $`\mathcal R_{\rm alg}`$ differs.
- X axis: "expected regret".

**Panel (b): line plot of $`\mathcal R_{\rm info}(D_\varepsilon)`$ against $`\varepsilon\in[0,\tfrac12]`$.**

- $`D_\varepsilon`$ is $`D`$ passed through a binary symmetric channel with flip probability $`\varepsilon`$. Use 101 grid points.
- Horizontal dashed lines at $`\mathcal R_{\rm info}(D)`$ ($`\varepsilon=0`$) and at the no-data value $`\mathbb EJ^\Pi-\max_\pi\mathbb EJ(\pi)`$, which is attained at $`\varepsilon=\tfrac12`$.
- Caption note: "monotone: a garbling can only raise the information term (Prop. 1.4)".
- Axes: "flip probability ε", "information regret".

**Panel (c): minimax duality on the package instance.**

- Regret matrix $`\begin{pmatrix}0&0.2\\0.2&0\end{pmatrix}`$.
- Solid curve: worst-case regret $`\max\lbrace 0.2(1-\rho),\,0.2\rho\rbrace`$ against the policy-mixture weight $`\rho\in[0,1]`$.
- Dashed curve: the dual objective $`\min\lbrace 0.2\mu,\,0.2(1-\mu)\rbrace`$ against the environment-prior weight $`\mu\in[0,1]`$, on the same axes.
- Mark the common value $`0.1`$ at $`\rho=\mu=\tfrac12`$ with a dot, labelled "primal = dual = 0.1 (JSON: robust_ambiguity_minimax)".
- Axes: "mixture weight", "regret".
