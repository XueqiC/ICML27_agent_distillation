# P1 设置 A 完整报告（rsi，2026-11-06）

**一句话结论**：按 prereg 判定，在现有数据上，教师定位改权重没有胜过简单做法。教师的编辑能修好同类失败状态，但这种局部修复传不到整题；用同样的修复数据直接做 SFT，各项效果指标都更好。

## 1. 设置与条件

- 起点 θ₀ = 轨迹 SFT baseline（K20，seed 0）。修复配对 113 对，按任务实例划分为诊断 55 对、测试 58 对，两边不重叠。
- 代码树 d082a6a；E4 按 prereg §11 用 3138f4a 冻结；rsi 重启后 shard 用 `--resume` 续跑（§12）。全部在 rsi 的 RTX PRO 6000 上评测，只报点估计。
- 条件：
  - **E0**：不改
  - **E1**：教师手术（5 个类别会话 + 整合会话，提交前在全部诊断配对上验证）
  - **E2_0..4**：随机编辑，结构与 E1 相同，5 个种子
  - **E3**：固定规则方向（fail − repair 的均值方向，第 20–41 层 down_proj 去方向，α 在诊断集上选）
  - **E4**：用同样的修复数据做 SFT
  - **E5**：不经教师的自动定位 LoRA（按梯度信噪比选前 25% 张量，lr × steps 网格在诊断集上选）
- 指标：
  - **M1**：58 个测试失败状态，从失败那一步开始 greedy rollout 的成功率
  - **M2**：71 个合成留出题，以及 20 个 K20 原题，整题成功率
  - **M3**：附带伤害，200 个原本做对的决策里 greedy 动作被改变的比例
  - **M4**：dev140，导出为完整模型后用 vLLM 评测

|---|---:|---:|---:|---:|---:|---:|

## 3. 按 prereg §6 判定

| 判据 | 要求 | 结果 | 是否满足 |
|---|---|---|---|
| 1. dev140 上 E1 比 E0、E2 均值、E3、E5 | 各高 ≥3 pp | +1.4 / +1.4 / +2.1 / +4.3 pp | ❌ |
| 2. M1 上 E1 比 E0、E2 均值、E3、E5 | 各高 ≥5 pp | +15.5 / +19.3 / +10.3 / +10.3 pp | ✅ |
| 3. dev140 上 E1 ≥ E4 | ≥ | 57.1% < 58.6% | ❌ |
| 4. 附带伤害 ≤5%，K20 原题不下降 | ≤5% | 8.0%；K20 20/20 | ❌（附带伤害） |

判据 1 不满足，所以落在 prereg 预设的分支：**在现有数据上，教师定位改权重没有优于简单做法**。这和 P0、D-param 的结论一致。

## 4. 怎么理解

- **教师的编辑是真的局部修复**。在同类别的留出失败状态上（M1），它比不改、随机编辑、固定规则、自动 LoRA 都高 10–19 个百分点。可见教师找到的位置和方向不是随机的。
- **局部修复传不到整题**。dev140 只多做对 2 题（+16 / −14 个任务翻转），在随机编辑的波动范围内；合成留出题 49 → 50。
- **同样的数据直接 SFT 更好**。E4 在 M1（50.0%）、dev140（58.6%）和合成题（51/71）上都最好，代价是附带伤害最大（15%）。
- **路径检查**：E0（不改，只是合并导出成完整模型）在 dev140 上是 78，而同一台机器上 θ₀ 走 LoRA 路径是 82，有 18 个任务翻转。合并导出这一步本身就会让大约 13% 的任务结果改变。
- **和数据侧训练的差距**：同一台机器上（LoRA 路径），v0 的 uniform 是 99/140，D-data 是 91/140；P1 的所有条件都 ≤84/140。
