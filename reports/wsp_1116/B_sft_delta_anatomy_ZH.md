# B 组：把现成的 SFT 改动拆开看

状态：草稿（11-16 CST）。hpg 上还有 3 个数没取回（隧道断开），标了"待补"。

## 1. 要回答的问题

A 组说明"重新训练时，改动可以很小"。B 组问的是另一件事：**已经训好的那个 SFT 改动 Δ，本身是不是一个小的、稳定的、可以被找到的对象？** 具体三问：
1. 它的大部分效果是不是集中在少数方向、少数模块里（事后砍掉其余部分还剩多少）？
2. 同一份数据训出来的几个学生，学到的是不是同一个 Δ？
3. 它们共有的那部分，单独拿出来有没有用？

这是用户方案 2 的第一种读法（同一 training set 上的几个学生）。第二种读法（几个不同基座，B4）这一轮没做，见 §6。

## 2. 名词

- **Δ**：一个训好的 LoRA adapter 等价的权重改动，逐模块 Δ_m = (α/r)·B_m·A_m。学生 = 原始模型 + Δ。
- **现成的学生**：10 月主表里的轨迹 SFT adapter，K20 和 K100 各 3 个 seed（秩 64、258 个模块）。‖Δ‖_F：K20 seed 0 为 5.88，K100 seed 0 为 16.07。
- **截断到秩 r**：每个模块的 Δ_m 做奇异值分解，只留最大的 r 个方向。
- **输出方向 / 输入方向**：Δ_m 的左 / 右奇异向量。输出方向是这个模块往后面写什么，输入方向是它在什么输入下写。
- **范数份额**：‖保留部分‖_F² / ‖Δ‖_F²。
- dev140、成功率的定义同 A 组报告。所有派生的 Δ 都不经过任何训练，直接当作 adapter 评测。

## 3. 怎么做的

- **B1 谱（CPU）**：6 个现成 adapter，逐模块算奇异值；seed 两两之间算重合度。
- **B2 事后截断**：取每个 K 的 seed 0，做 5 类操作后直接评 dev140：
  - 每个模块截到秩 1 / 4 / 16；
  - 只保留范数最大的 23 / 50 / 90 个模块（K20 占范数的 25% / 50% / 75%；K100 占 25% / 48% / 74%），其余模块置零；
  - 只保留 MLP 输入侧（gate、up 共 84 个模块；K20 占 72%，K100 占 69%）；
  - 秩 4 且只保留 90 个模块（K20 占 40%，K100 占 37%）；
  - 整体乘 0.5、乘 2。
- **B3 几个学生的共识**：
  - 三个 seed 的 Δ 取平均（再截到秩 64 / 16 / 4）；
  - "共有方向"臂（我加的）：只在写残差流的 84 个模块（各层 down_proj、o_proj）里，取三个 seed 公共的第 1 条（或前 4 条）输出方向，只保留平均 Δ 在这条方向上的分量，其余全部置零；以及反过来，把这条方向从平均 Δ 里去掉。
- 评测：hpg（RTX PRO 6000）为主，部分在 LONI（A100）和 rsi 重复。

## 4. 结果

### 4.1 谱：模块内部低秩，模块之间摊开（K20 seed 0）

- 每个模块内部接近低秩：stable rank 的中位数是 3.0（四分位 2.1–4.7）。按范数平方，每个模块的第 1 个方向占 39%，前 4 个 55%，前 16 个 78%。
- 在层上是摊开的：42 层每层占 1.3%–3.2%。凑够 50% 的范数要 50 个模块，90% 要 153 个。
- 按模块类型：gate_proj 38%、up_proj 34%（MLP 输入侧合计 72%）、q_proj 9%、down_proj 8.5%、o_proj 8%、k / v 各约 1%。

### 4.2 事后截断

完整的 seed 0：K20 59%（82），K100 76%（107）（hpg）。原始模型 40–44 题。

| 对 seed 0 的 Δ 做的操作 | 保留的范数份额（K20 / K100） | K20 | K100 |
|---|---|---|---|
| 不动 | 100% | 59%（82） | 76%（107） |
| 每模块截到秩 16 | 78% / 75% | 56%（78） | 66%（92） |
| 每模块截到秩 4 | 55% / 51% | 46%（64） | 60%（84） |
| 每模块截到秩 1 | 39% / 34% | 46%（64） | 51%（71） |
| 只留范数最大的 90 个模块 | 75% / 74% | 39%（54） | 66%（93） |
| 只留范数最大的 50 个模块 | 50% / 48% | 37%（52）（LONI）、39%（55）（hpg） | 56%（78） |
| 只留范数最大的 23 个模块 | 25% / 25% | 31%（43）（LONI）、30%（42）（hpg） | 45%（63） |
| 只留 MLP 输入侧（gate、up） | 72% / 69% | 37%（52）（LONI）、39%（54）（hpg） | 64%（89） |
| 秩 4 且只留 90 个模块 | 40% / 37% | 待补（hpg） | 45%（63） |
| 整体 × 0.5 | 25% | 44%（61） | 51%（71） |
| 整体 × 2 | 400% | 评不了 | 评不了 |

- **事后砍比从头训小的损失大得多。** K20 上把现成的 Δ 截到秩 1 是 46%（64），而从头训一个秩 1 是 79–85 题（A 组）；截到秩 4 是 46%（64），从头训秩 4 是 87–90 题。
- **K20 上按模块砍几乎全丢。** 保留占 75% 范数的 90 个模块只有 39%（54），保留 23 个模块等于原始模型。而从头训时只给 70–98 个模块（A 组的任意三分之一层）就能到 74–81 题。
- **K100 的 Δ 耐砍得多**：留 90 个模块 66%（93）、只留 MLP 输入侧 64%（89）。原因这一轮没查。一个可能是 K100 的 Δ 范数大（16 对 5.9），砍掉一部分后剩下的仍然够用。
- 范数份额不能预测效果：K20 上"秩 16"和"90 个模块"都留了约 75% 的范数，一个 56%（78），一个 39%（54）。
- "× 2"两个 K 都没有分数：评测前的服务一致性检查不通过（vLLM 和 HF 的 log 概率平均差 0.13 nats，上限 0.05）。翻倍后的改动把 log 概率平均改了 2.45 nats，数值噪声被放大。我没有放宽检查，记为评不了。

### 4.3 同一份数据上的三个学生：同一个函数，不同的矩阵

| | K20 三个 seed 两两之间 | K100 三个 seed 两两之间 | 同一 seed 的 K20 对 K100 |
|---|---|---|---|
| 整个 Δ 的余弦（按范数加权） | 0.070–0.071 | 0.084–0.086 | 0.30–0.31 |
| 每模块第 1 条输出方向的重合度 | 0.56–0.58 | 0.40–0.41 | 0.14–0.15 |
| 每模块第 1 条输入方向的重合度 | 0.03 | 0.06 | 0.59–0.61 |

（重合度 1 = 同一方向，随机水平 < 0.01。）

- 不同 seed 的 Δ 作为矩阵几乎正交（余弦 0.07）。它们共有的是**输出方向**（0.56–0.58），输入方向接近随机。
- 同一 seed、不同数据量时反过来：输入方向高度一致（约 0.6），输出方向不一致。输入方向主要由 LoRA 的随机初始化决定（同一 seed 的 A 矩阵初始值相同），不是从数据里学的。
- 所以"SFT 学到的 Δ"不是一个唯一的对象：输入侧基本是随机投影，学到的内容在输出侧。

| 三个 seed 的共识 | K20 | K100 |
|---|---|---|
| 三个 seed 各自 | 59%（82） / 59%（82） / 61%（86） | 76%（107） / 72%（101） / 84%（117） |
| 三者平均（秩 64；‖·‖_F 是单个的约 1/√3） | 58%（81） | 77%（108） |
| 平均后截到秩 16 | 52%（73）（rsi） | 67%（94） |
| 平均后截到秩 4 | 待补（hpg） | 60%（84） |
| 平均，去掉公共的第 1 条输出方向 | 54%（76） | 77%（108） |
| 只留公共的第 1 条输出方向（84 个模块 × 秩 1） | 34%（47） | 36%（51） |
| 只留公共的前 4 条输出方向 | 34%（48） | 33%（46） |
| 只留公共的第 1 条输出方向，且只在第 24–41 层 | 30%（42） | 31%（43） |

- **三个几乎正交的 Δ 取平均，效果和单个一样**（K20 58%（81），K100 77%（108）），而平均后的范数只有单个的 58%。对比：单个 Δ 乘 0.5 掉到 44%（61） / 51%（71）。这说明三个学生在训练数据出现的输入上给出的是同一个输出，三份各占三分之一加起来还是完整的一份；它们是同一个函数的三种写法。
- **种子间共有的那条输出方向不是效果的载体。** 只留它是 42–51 题（原始 40–44）；把它去掉，K20 掉 5 题、K100 不掉。

## 5. 结论

1. 现成的 SFT 改动在每个模块里是低秩的，但摊在所有层、所有模块上；**事后把它砍小，效果丢得很快**，尤其在 K20 上。A 组"可以很小"说的是可以**训出**一个小的解，不是现有的解里藏着一个小的核。
2. 同一份数据上的几个学生学到的是**同一个函数、不同的矩阵**：矩阵之间几乎正交，平均之后照样有效。
3. 它们在权重空间里共有的部分（每个模块的头一条输出方向）单独拿出来没有用。

对 WSP 的含义：
- 没有一个唯一的"正确 Δ"等着被读出来。从几个学生的权重里取共识方向，这条路在这里走不通（方案 2 的第一种读法的直接做法）。
- 但"解有很多、互相可加"是好消息：程序员不需要命中某一个特定的矩阵，只需要写出任何一个在训练分布上给出正确输出的改动。约束在函数上，不在权重上。这指向按"输出该是什么"来写（例如逐层最小二乘，C2 的路线），而不是按"权重该是什么"来写。
