# 总报告：WSP 在什么条件下能取代 SFT

状态：定稿（11-16 13:50 CST）；11-16 19:57 CST 补入 hpg 上的 3 个 B 组数和重复评测（见 §6），结论不变。分组报告：`A_lora_size_ZH.md`、`B_sft_delta_anatomy_ZH.md`、`C_one_step_edit_ZH.md`、`D_teacher_wsp_ZH.md`。预注册：`docs/direction/2026-11-15_WSP_vs_SFT_small_experiments_prereg_ZH.md`（§0–§17）。

## 1. 结论

在这一轮的设定下（ALFWorld，学生 Gemma-4-E4B，teacher 的 20 条或 100 条轨迹），**试过的两种 WSP 都没有拿到 SFT 增益的任何一部分**，而 SFT 自己可以缩到非常小：

| | 改动的规模 | dev140（K20） |
|---|---|---|
| 原始模型 | | 29%–31%（40–44 题） |
| WSP：teacher 读激活后写的闭式编辑（D1 / D2 两次会话） | 1 层 1–2 个矩阵，秩 1–2 | 30% / 31%（42 / 43.5 题）；同一路线的未改写 29%（40.5 题）；同结构随机方向 29%（平均 40.8 题） |
| WSP：一步梯度改写（C1，最好的一档） | 258 个模块 | 18%（25 题） |
| SFT，秩 1，全部模块 | 218 万参数 | 56%–61%（79–85 题） |
| SFT，秩 64（参照配方） | 1.40 亿参数 | 58%–66%（81–93 题） |

所以问题不是"SFT 需要一个大改动而 WSP 只能写小的"。一个秩 1 的改动就够了。问题是**目前没有一种不经过几十步优化的办法能把这个改动找出来**。

## 2. 框架

整条 pipeline 只有一处不同：

```
teacher 的 K 条轨迹 ──┬─ SFT：优化器在 −Σ log p(y_t | h_t) 上迭代几百步 ──→ Δ
                      └─ WSP：程序员（teacher 或一条规则）读学生，直接写出 ──→ Δ
学生 = 原始模型 + Δ ──→ 闭环评测（dev140）
```

三个问题，四组实验：

| 问题 | 实验 | 对应你列的方案 |
|---|---|---|
| Q1 一个做对了的 Δ 长什么样（多大、在哪、要训多久）？ | A：重新训练，逐个因素缩小。B：把现成的 Δ 拆开 | 方案 4；方案 2（第一种读法） |
| Q2 它能不能不靠优化器、从可读信号直接写出来？ | C：一步梯度改写 | 方案 3（我的建议） |
| Q3 teacher 能不能找到并写出它？ | D：teacher 会话 | 方案 1 |

## 3. 每一组说明了什么

### A 组：改动可以很小，也不挑位置，但不能只放在 3 个模块

- 秩：K20 上秩 16 / 4 / 1 是 89–90 / 87–90 / 79–85 题（参照 81–93）；K100 上 114 / 106–107 / 106–107 题（参照 111–113）。
- 位置（K20，秩 16）：只 MLP、只注意力、任意三分之一的层，都在 74–81 题。只改 3 个模块：56 题，训练 loss 都降不下去。
- 训练量：K20 第 10 次更新 37–38 题（低于原始），第 40 次 75–82 题；K100 训 2 个 epoch 就是 102 题（最终 113）。
- 低秩需要把学习率从 5e-5 提到 2e-4，否则是欠拟合。
- 含义：目标存在，而且小。"小"是指秩低，不是指位置少。

### B 组：现成的 SFT 改动不是一个可以被"读出来"的唯一对象

- 事后砍：把训好的 Δ 截到秩 1 是 64 题（从头训秩 1 是 79–85）；只留范数最大的 90 个模块（75% 的范数）是 54 题（K20）。
- 三个 seed 的 Δ 作为矩阵几乎正交（余弦 0.07），输入方向接近随机，共有的只是输出方向；但三者取平均照样是 81 题。它们是同一个函数的三种写法。
- 只保留种子间共有的那条输出方向：42–51 题，等于没改。
- 含义：没有"正确的权重"可找，只有"正确的函数"。从几个学生的权重里取共识这条路走不通；按输出该是什么来写（最小二乘类的做法）更对路。

### C 组：SFT 的第一步是文风，不是决策

- 一步梯度改写能把 teacher-forcing 的训练 loss 从 1.03 降到 0.48，但训练题的闭环成功率没有一档高于原始模型（最好 45% 对 50%），dev140 最好 25 题。
- 原因：训练 loss 的 97% 落在 Thought 的 token 上；给定 teacher 的 Thought，原始模型 90% 的步已经能把 Action 写对。梯度指向"把 Thought 写得像 teacher"，步子一大 Thought 就塌成字面的 `...`。
- 含义：teacher-forcing 的 loss 不能当作写改动的依据，也不能当验收。

### D 组：teacher 找到了真实的失败模式，但写出的编辑没有效果

- D1（只有前向读取）：teacher 从失败轨迹里认出"多余的 look / inventory"，构造了对应的方向，在第 31 层去掉一半。会话内训练题 9 → 11。
- 同一套权重在评测路径上：训练题 9 对 9，20 题逐题相同；dev140 42 题，未改写 40–41 题，5 个同结构随机方向 35–43 题。
- 会话内的 +2 和换一种推理实现造成的差别一样大；候选的分数随系数在 6–11 之间来回跳。teacher 是在抖动里挑了最高点。
- D2（加梯度归因）：会话内 9 → 10；评测路径上训练题 8 对 9，dev140 两次评测 41 和 46 题，5 个随机方向 37–45 题。
- 含义：两个具体的方法问题。反馈太粗（20 题、一次 rollout）；编辑太小（1 层，token 概率上只有 0.02 nats）。

## 4. 回答"在什么条件下"

按这一轮的证据，WSP 要想在这个任务上取代 SFT，至少要同时满足四条，而这一轮试过的做法各自缺了其中几条：

1. **改动要铺在很多模块上**（A：3 个模块不够，70 个以上可以；秩 1 即可）。D 的 teacher 两次都只改 1 层。
2. **信号要来自决策，而且是学生在自己的轨迹上的决策**（C：teacher-forcing 的 token loss 97% 是文风）。C1 用的正是这个被文风主导的信号。
3. **验收要比"20 题做对几题"细得多**（D：±2 题是噪声）。
4. **不要去找某个特定的权重矩阵**（B：解不唯一，共有的权重成分没有用）。

反过来，SFT 在这里便宜得很难被取代：秩 1、几十步、K20 一次训练 7–8 分钟（2 张 B200）。所以我的判断是，"WSP 取代 SFT"作为一般性的主张，在这个设定下站不住；更可能站得住的是下面两种更窄的说法，这一轮都还没有检验：

- **WSP 用在 SFT 做不了的地方**：例如 K 极小（1–5 条轨迹）时，或 SFT 之后针对剩下的特定失败做修补。K100 的 SFT 停在 79%–81%，剩下的 20% 是什么、能不能被定点改掉，是一个现成的问题。
- **WSP 作为"把语言或示范编译成权重"**（C2 / C2b）：程序员写的是规则或示范，权重由一个闭式的编译步骤（逐层最小二乘）给出，铺在全部模块上。它满足上面的 1 和 4（是否满足 2 取决于示范取自谁的轨迹），是这一轮没来得及做、但被 A、B 的结果支持的方向。

## 6. 没做的、偏差和待补

- **没做**：A3（单步监督）、B4（不同基座的多学生表）、C2、C2b、C4、C5、D 的"指定位置 / 全部模块"变体。原因是 12 小时里 hpg 的 B200 被预留占住、LONI 训练比预估慢 3.7 倍、我按 A → B → C1 → D 的顺序排，后面的没排上。
- **偏差**（都登记在预注册 §9、§11–§17）：评测用了三种 GPU；每个臂的重复评测只做了一部分；D 改用合并权重评测；C1 的步长改用闭环指标选。
- **噪声**：同一 adapter 评两次差 0–6 题；同配方重训差 12 题。每个臂只训一次。10 题以内的差别这一轮分不出来。上面的结论都不依赖这样的差别。
- **已补（11-16 19:57 CST，hpg）**：K20 "秩 4 且 90 个模块" 53 题；三个 seed 平均后秩 4 是 71 题、秩 16 是 80 题（rsi 上 73）；重复评测：K20 参照 93 / 92，K100 参照 113 / 108，10 月的 seed 两次相差 0–3 题。L4 卡上的数偏低（同一 adapter 76 对 82 / 83），不和其他卡混比。细节在 A、B 两份的 §6。
