## 1. 研究目标（以交接文档为准）

**核心问题：给定少量可信经验（K 条经过环境验证的教师轨迹），什么样的学习经验足以让受限学生形成能独立成功的策略？**

交接文档要求我们回答的不是"K 条够不够"，而是三件事：
1. 在**允许自由生成新任务、新教师输出和新真实交互**之后，哪些经验仍然缺失；
2. 这些缺失怎样随学生的能力（可实现的策略）变化；
3. 怎样产生能让学生真正学会的经验。

待检验的两个机制：M1 是经验里有相关知识，但没被吸收或调用；M2 是学生需要更明确的决策信息。顺序是先发现、再提方法，否证也算结果。

**我们执行时实际收窄了什么**（需要你确认是否有意为之）：
- 主表里所有方法，都**只用 K 个种子任务**：Seed-SFT 只在 K 条种子上训练，baseline 也只在 K 个任务上探索（10-04 的决定）。交接文档里"自由扩展"的那一半还没做，被它列为"必须的强基线"的 **Grounded Augmented-SFT（生成新任务、真实执行验证、再训练）也还没跑**。
- 只用了 ALFWorld 一个环境，而且只在 valid_seen 上测（房间布局在训练里见过）。

## 3. 结论（按证据强度分级）

### 3.1 已经比较扎实的结论（多个 K、3 个种子集、配对评测）
1. **剂量是 few-shot 下的第一混杂因素。** 3–6 万监督 token 处有一个与 K 无关的低谷，学生跌到 base 以下；剂量够了以后，Seed-SFT 随 K 单调上升（K=1 59.7 → K=20 107.7 → K=50 114.7 = 教师 → K=100 111）。官方配方是按几千条轨迹调的，在 K≤20 时都落在这个低谷里。
2. **在 ALFWorld valid_seen 上，K≈20–50 条可信轨迹加普通 SFT 就能追平教师。** 这是一个很强的朴素基线。
3. **只在 K 个任务上交互的 baseline 都没有超过 Seed-SFT**：Kang 不稳定，AgentEvol 起点差时越训越差，LEAP 停在 base 附近。剂量对照给出了原因：学生拟合了种子以后（训练集拟合 94–98%），在这 K 个任务上已经几乎不失败了。LEAP 对照拿到 0 条纠错，ETO 对照只找到 3 对。**K 个任务里能提供的学习信号已经用完了，缺的东西在这 K 个任务之外。**
4. **增益来自 base 不会、种子又覆盖到的任务类型（加热、冷却）。** 覆盖是必要条件，但不充分（k2s1 和 k2s2 覆盖的类型相同，结果是 86 对 59）。

### 3.2 初步结论（单个学生、单个种子集，区间很宽）
5. 机制归因：M1a（学不进去）在 K=20 和 K=5 都是 0。K=5 时缺口的 44% 来自种子里根本没有的知识；K=20 时剩下的缺口以 M2（29%）和 M1b（17%）为主，另有 33% 单步干预救不回。
6. K 越小，能救回失败的干预越偏向"直接给动作"（I4），而不是"给建议"（I3）。缺的是可执行的知识，不只是决策信息。

### 3.3 现在还**不能**下的结论
- "自由扩展之后仍有剩余障碍"：根本还没测。
- M1、M2 是 few-shot 蒸馏的普遍瓶颈：只有一个环境、valid_seen、两个学生。
- 能力限制会改变所需信息：还没有受控环境对，也没有第二个学生。

### 3.4 这对目标意味着什么（坦白说）
在 valid_seen 上，K=50 的普通 SFT 已经追平教师，**这个评测集上几乎没有留下剩余障碍可以研究**。目前的结果足以支撑一篇扎实的分析，大意是"few-shot agent 蒸馏里，剂量和 K 内信号枯竭解释了官方方法为什么失败"。但要回答核心问题，有两个前提条件：
(a) 要做扩展实验；
(b) 要有一个扩展之后学生仍然追不上教师的评测环境。
这两件事是下一步的重点。

## 4. 下一步（按优先级）

### N1 跑完官方 baseline 主表（已经在跑，不需要新决定）
- 内容：ETO K20（预计今晚到明早）、IPR K20（4 卡，预计周五到周六）、LEAP K50/K100（明天）。
- 预期：都在 base 到 Seed-SFT 之间，大概率不超过同 K 的 Seed-SFT。如果 ETO 或 IPR 明显超过 Seed-SFT，结论 3 就要修正：说明成功/失败对比确实能从 K 个任务里提取出新信号。
- 对目标的影响：补齐表 1。对核心问题的直接信息量不大，但这是比较对象的基础。

### N2 扩展对照实验（交接文档 §8.2，同时就是必须的强基线 Grounded Augmented-SFT）——**最关键**
- 内容：从 K=5 和 K=10（缺口最大）× 3 个种子集出发，让教师在 ALFWorld train 的新任务上产生轨迹，经过环境验证，再与种子合并做 SFT（统一用约 40 万 token 的剂量）。新增可信轨迹数相同（例如 +15、+45），比较这几种来源：
  - (a) **重采样**：同样的 K 个任务换新轨迹。不带新任务，只是增加曝光。
  - (b) **只扩已覆盖类型**：新任务只取种子里已有的类型。
  - (c) **均匀扩展**：新任务按类型均匀抽样，会覆盖缺失类型。
  - (d) **按诊断定向扩展**：根据机制归因，只补缺失的类型，以及示范缺失步骤的任务。
  - (e) **等量无关对照**：长度相当但与缺口无关的新轨迹，例如重复已经做对的简单类型。
- 预期（括号内是会推翻假设的结果）：
  - (a) 约等于原 Seed-SFT，说明光增加曝光不够（若 (a) 也大涨，说明问题是优化或曝光，不是信息）；
  - (b) 小幅提升；(c) 大幅提升，接近 K=20–50 的水平；
  - **(d) 每条轨迹的收益高于 (c)**：说明机制诊断能预测哪类经验有用，这是论文潜在的核心贡献（若 (d)≈(c)，说明只是覆盖问题，诊断没有附加价值）；
  - (e) 约等于 (a)。
- 对目标的影响：直接回答"什么经验才算够"的第一层；给出交接文档要求的强基线；也检验结论 3"缺的在 K 之外"是否成立。
- 成本：教师调用每格十几到几十条轨迹（现有采集工具可直接用，余额已经充值）；GPU 每格约 1–2 小时（训练加评测）。总共约 30 个格子，可以分批跑。

### N3 找一个扩展以后学生仍落后教师的评测环境——**决定论文高度**
- 原因：valid_seen 已经饱和。要研究剩余障碍和 M1/M2，必须先有剩余障碍。
- 两条路（需要你选，或者两条都走）：
  - **N3a 未见场景的 dev 集**：从 ALFWorld train 里留出一部分场景（房间布局）作为 dev-unseen，训练和教师生成都不碰这些场景。封存的 valid_unseen 仍然不动。优点是便宜，可以直接复用现有的一切。
  - **N3b 第二个环境**：ScienceWorld 或 AppWorld，任务更长，信息获取更重要，交接文档预期这里的 M2 现象更强。ICML 无论如何需要第二个环境；工程量大约 1–2 周。
- 预期：在未见场景或新环境上，K=50 的 SFT 和 N2 里最好的扩展仍落后教师 ≥10 个百分点，剩余失败里 M2/M1b 的比例上升。如果连这里都没有剩余缺口，论文主张就收缩为"few-shot 下充分经验 ≈ 覆盖加剂量"，然后去更难的环境里找。
- 对目标的影响：决定论文能不能讲"扩展之后仍缺什么"，而不只是"剂量和覆盖"。

### N4 在剩余障碍上做机制分析和定向经验（§8.3、§9）
- 内容：在 N2/N3 得到的扩展后学生上，重复 FCE 和 I0–I5 干预，加覆盖检查和知识探针。然后针对诊断出的机制生成定向经验：M2 对应显式检查点或重新观察的示范，M1b 对应在变化的表述下绑定前提和后果。最后撤掉辅助，再测学生能否独立完成。
- 预期：定向经验在同等轨迹数下胜过均匀扩展，而且撤掉辅助后仍然保持。这一步就是方法的雏形。
- 对目标的影响：从"发现"走到"方法"。

- 作用：回应"官方方法只是剂量不足的稻草人"这类质疑。

### N6 理论和受控环境对（§4、§8.4）
