# N 组：K 很小时，SFT 和"示范放进 prompt"各能到多少

状态：定稿（11-18 01:45 CST）。预注册：`docs/direction/2026-11-15_WSP_vs_SFT_small_experiments_prereg_ZH.md` §18（N1、N2、C2），偏差记录 §20 第 2、5 条和 §21 第 2、6 条。

## 1. 要回答的问题

第一轮的结论是"在 K = 20 上，没有一种 WSP 能拿到 SFT 的增益"。一个自然的退路是把问题改窄：**K 小到 1、2、5 条轨迹时，SFT 是不是就不行了？如果是，那里有没有别的办法（不改权重，或者把示范编译进权重）能补上？** 这一组只回答前半句和"不改权重"那一半。

## 2. 名词

- **K**：teacher 轨迹的条数。视图 k1 ⊂ k2 ⊂ k5 ⊂ k10 ⊂ k20 是同一个分层抽样（`stratified_nested_v2`，seed 0）的嵌套前缀。k1 是 1 个 pick_and_place_simple（19 步）；k2 再加 1 个 pick_two_obj_and_place；k5 是除 look_at_obj 外每类 1 个；k20 一共 315 步。
- **SFT**：在这 K 条轨迹上做监督微调。每一步的输入是到这一步为止的对话历史 `h_t`，监督目标是 teacher 的整个回复 `y_t`（Thought 加 Action），loss 是 `−Σ_t log p(y_t | h_t)`。
- **示范放进 prompt（ICL）**：不改权重。消息 = 原来的 system prompt + K 条示范轨迹（按评测时同样的方式渲染）+ 当前题目的对话。不加任何说明文字。
- **dev140**：140 个没用于训练的评测题，只用来报告，不用来做任何选择。
- **噪声尺度**（第一轮测到的）：同一个 adapter 评两次差 0–6 题；同配方重训差约 12 题。

## 3. 怎么做的

**N1：SFT 随 K。**
- 输入：视图 k1、k2、k5、k10（k20 的同配方臂已有）。
- 做法：配方固定为第一轮 K20 上最好的小配方，即秩 16、α 32、dropout 0.05、lr 2e-4、全部 258 个模块、seed 0。epoch 数取 640 / K（K1 是 640，K2 是 320，K5 是 128，K10 是 64，K20 是 32），所以**每次训练都看 640 遍轨迹，优化器更新次数相同**。在 LONI 的 A100 上训练和评测。
- 检查：最后一个 epoch 的平均 loss 高于 0.01 就算没训到位、要加倍重训。四个臂都没有触发（K1、K2 的最后一个 epoch loss 是 0.00000）。
- 输出：每个 K 一个 adapter，dev140 评两次。

**N2：示范放进 prompt。**
- 输入：原始 E4B，和 N1 相同的视图。
- 做法：固定示范臂 icl-k1 / k2 / k5 / k10 / k20，示范就是对应视图的全部轨迹，所有题目相同。同类型臂 icl-type2，每道题用 K20 里和它同任务类型的前 2 条轨迹；任务类型由 harness 从题目指令判断，不用评测侧标签。上下文上限分别开到 32k、65k、131k token。
- 输出：dev140。在 hpg（RTX PRO 6000）上各评一次，最好的固定臂和 icl-type2 再评一次；之后在 LONI（A100）上全部再评一遍，因为 N1 是在 LONI 上评的，要同机器比。
- 没有出错的 episode，没有上下文溢出。

**一个例子**（icl-k1 这一臂里一道题实际收到的消息结构）：

```
system:    <原来的 system prompt>
user:      <示范题的指令和初始观察>              ← k1 那条轨迹的第 1 步
assistant: Thought: ...  Action: go to ...      ← teacher 的原始回复
...（示范轨迹的其余 18 步）
user:      <当前评测题的指令和初始观察>
```

## 4. 结果

dev140 做对的题数（括号里是百分比）。SFT 每格评两次；ICL 的两个数是 hpg / LONI。

| K | 0（原始） | 1 | 2 | 5 | 10 | 20 |
|---|---|---|---|---|---|---|
| SFT（LONI） | 42 / 43（30%） | 42 / 43（30%） | 49 / 49（35%） | 61 / 63（44%） | 73 / 74（53%） | 89 / 90（64%） |
| 示范放进 prompt，hpg | 38、40 | 32 | 34 | 45、40 | 38 | 34 |
| 示范放进 prompt，LONI | 42、43 | 30 | 42 | 40 | 36 | 33 |
| 每题 2 条同类型示范，hpg / LONI | | | | | | 37、41 / 38 |

读法：
- **SFT**：K = 1 等于没学；K = 2 起稳定上升，K 每翻一倍多 11–16 题。K = 5 已经是 61 / 63，高于预注册的 59（"K20 上 SFT 增益的一半"）。
- **示范放进 prompt**：没有任何一个 K 高于"不放"。hpg 上 K = 5 第一次的 45 重评是 40，属于噪声。LONI 上示范越多越低（42 → 36 → 33）。
- 同类型的 2 条示范也没有帮助（37–41）。

## 5. 结论

按预注册的判定：

1. "K ≤ 5 时 SFT 仍然明显高于原始模型" 成立（K = 5 是 61 / 63）。所以**"K 很小时 SFT 不行"这个前提不成立**。SFT 只在 K = 1 时失效，而 K = 1 时别的办法同样无效。
2. 没有哪个 K 上 ICL 高于同 K 的 SFT 至少 10 题。**不存在"不动权重更好"的区间。**
3. 最好的 ICL 臂没有到 59，所以 **C2 的第二步（把示范编译进权重）不做**：prompt 版本本身没有效果，没有可编译的目标。

对新方法的含义：在 K 很小的一端，WSP 没有空位可占。想在小 K 上做文章，对手是"K = 2 的 SFT 已经多 6–7 题"。

## 6. 没做的和局限

- 每个 K 只训了一个 seed。同配方重训的波动约 12 题，所以 K = 1 和 K = 2 之间 6–7 题的差别本身不稳；整条曲线的走向（K = 5 以上明显上升）是稳的。
- epoch 数按"看 640 遍轨迹"固定。K = 1 时这意味着同一条轨迹看 640 遍，loss 到 0，这是过拟合到一条轨迹的极端情况；没有试更少的 epoch。
- ICL 没有加任何说明文字，也没有试"只放示范里的关键步"。规则单（C2b）是另一种不改权重的做法，见 `C2b_rule_sheet_ZH.md`。
- 只有一个学生（E4B）、一个环境（ALFWorld）。
