# 第二轮总报告：WSP 在什么条件下能取代 SFT，以及它输在哪一环

状态：定稿（11-18 01:45 CST）。分组报告：`N_small_k_ZH.md`、`A3_supervision_ZH.md`、`B4_multi_student_ZH.md`、`C2b_rule_sheet_ZH.md`、`C4_additive_ZH.md`、`C5_search_ZH.md`、`D_sessions_ZH.md`、`W_why_ZH.md`。预注册：`docs/direction/2026-11-15_WSP_vs_SFT_small_experiments_prereg_ZH.md` §18–§21。第一轮：`reports/wsp_1116/`。

## 1. 结论

设定：ALFWorld，学生 Gemma-4-E4B，teacher 给 K 条轨迹（K = 1 … 20），评测 dev140。

1. **没有找到 WSP 能取代 SFT 的条件。** K ≥ 2 时 SFT 都领先；K = 1 时 SFT 不行，别的办法也都不行。
2. **WSP 主要输在"方向"这一环，其次是"幅度"。** 不训练能读到的信号只指到有效改动的一小块；把方向直接给 teacher，它才第一次写出有效的编辑，但因为定不出幅度，只拿到约四成。
3. **不经过训练、又确实有效的做法有两个，都很小**：teacher 写的规则单放进 prompt（约 +10 题），激活差写成偏置（+6 题）。SFT 是 +47 题。

所有做法并排（dev140 上比"同一评测路线的不改写版本"多多少题）：

| 做法 | 用没用训练出来的信息 | 增益 | 输在哪一环 |
|---|---|---|---|
| SFT，秩 16，全部步、整个回复 | 是（它就是训练） | **+47** | |
| SFT，秩 1 | 是 | +39.5 | |
| SFT，只用做错的 90 步、整个回复 | 是 | +33.5 | |
| W3：有效方向交给 teacher，teacher 写编辑 | 是（方向来自训好的 adapter），只作诊断 | +17 | 幅度 |
| W2：有效方向，幅度抹平 | 是，只作诊断 | +13.5 | 幅度 |
| C2b：teacher 写规则单，放进 prompt（不改权重） | 否 | +10.5 | 不到编译的门槛 |
| C4：激活差写成偏置 | 否 | +6 | 方向（信号弱） |
| C5：梯度的 6 维空间里按闭环指标搜 | 否 | +4（边缘） | 方向（子空间里没有） |
| D1–D4：teacher 自己找方向的四次会话 | 否 | 0（等于随机） | 方向 |
| N2：示范放进 prompt | 否 | −12 到 0（LONI） | |
| A3：SFT 但只监督 Action | 是 | −10 到 −1 | 监督信号 |

## 2. 框架

```
teacher 的 K 条轨迹
   │
   ├─ SFT：优化器在 −Σ log p(y_t | h_t) 上走几百步 ────────────────→ Δ（方向和幅度都是学出来的）
   │
   ├─ WSP：程序员读学生，直接写 Δ
   │     要同时对四环：位置、方向、幅度、写法
   │     信号来源：一次梯度（C5、W1）、激活均值差（C4）、teacher 的内省工具（D3、D4）
   │
   └─ 不改权重：示范放进 prompt（N2）、teacher 写规则单（C2b）
   │
学生 = 原始模型 + Δ（或加 prompt）──→ 闭环评测（dev140）
```

这一轮的实验分三类：

| 类 | 问什么 | 实验 |
|---|---|---|
| 把问题改窄 | K 很小时有没有 WSP 的空位 | N1、N2 |
| 看 SFT 到底靠什么 | 监督信号要多少；失败分几种 | A3、B4 |
| 换信号、换写法再试 WSP | 规则、偏置、搜索、给位置 | C2b、C4、C5、D3、D4 |
| 定位失败在哪一环 | 信号问题还是改不对 | W1、W2、W3 |

读所有数字都带着三个噪声尺度：同一个 adapter 评两次差 0–6 题；同配方重训差约 12 题；20 个训练题上两种实现（HF 和 vLLM）对同一套权重有 2 题不同。

## 3. 每一组说明了什么

### N：K 很小的一端没有空位（`N_small_k_ZH.md`）

| K | 0 | 1 | 2 | 5 | 10 | 20 |
|---|---|---|---|---|---|---|
| SFT | 42 / 43 | 42 / 43 | 49 / 49 | 61 / 63 | 73 / 74 | 89 / 90 |
| 示范放进 prompt（LONI） | 42 / 43 | 30 | 42 | 40 | 36 | 33 |

SFT 从 K = 2 起就领先，K 每翻一倍多 11–16 题。示范放进 prompt 在任何 K 上都不比不放高。"把示范编译进权重"因此没有做：没有可编译的目标。

### A3：有效的监督必须带 Thought（`A3_supervision_ZH.md`）

| | 监督整个回复 | 只监督 Action |
|---|---|---|
| 全部 315 步 | 89 / 90 | 34 / 31 |
| 做错的 90 步 | 76 / 76 | 46 / 37 |

只监督动作，学不出来，甚至比不训练差。只用三分之一的步、但监督整个回复，保住约 71% 的增益。teacher 手术用的信号正是右下角那一格，这一格交给优化器也只有 37–46 题：**信号本身不够。**

### B4：失败分两种，SFT 都能修（`B4_multi_student_ZH.md`）

100 个训练题里，E4B 原始模型做错的 68 题中，28 题是"大一号的原始模型会"（行为缺陷），40 题是"两个原始模型都不会"（缺任务知识）。20 条轨迹的 SFT 把前一种修好 63%，后一种教会 36%。把这张表给 teacher（D3、D4），没有帮它找到方向。

### C2b：规则单有约 10 题，但到不了编译的门槛（`C2b_rule_sheet_ZH.md`）

规则单 v1：51 / 55（原始 42 / 43）。让 teacher 看反馈改两轮，没有变好（44、47）。加上示范，增益被抵消（41）。没到 59，不做编译。

### C4：激活差写成偏置，+6 题，窗口很窄（`C4_additive_ZH.md`）

系数 0.5 / 1 / 2 / 4：43、49 / 49、17、0（不改 43 / 43）。登记的随机对照把模型改坏了（0 题），没有信息量；借三次会话的 15 个随机对照（39–46）当旁证，49 高于每一个。

### C5：换成闭环目标来搜，也只有边缘的 +4（`C5_search_ZH.md`）

终点 47 / 46（原始 42 / 43）。搜索是**逆着梯度**走的：顺着 Thought 的梯度走一步，训练题从 10 掉到 5–7；逆着走到 13。所以一步梯度输的不只是目标，那个子空间里本来就没有 SFT 那样的增益。

### D3、D4：位置给对了，teacher 的编辑还是等于随机（`D_sessions_ZH.md`）

| 会话 | 条件 | teacher 编辑 | 不改 | 随机对照 |
|---|---|---|---|---|
| D4 | 指定位置 | 45 / 41 | 43 / 43 | 40–43 |
| D3 | 强制铺开 | 45 / 42 | 42 / 44 | 39–43 |
| W3 | 给方向 | 61 / 59 | 43 / 43 | 39–46 |

### W：四环里，方向是主要瓶颈，幅度其次（`W_why_ZH.md`）

- **W1**：梯度的前 64 个方向只接住有效改动的 15%。只留这 15%：48 题；去掉这 15%：63 题；去掉随机的 64 维：87 题。梯度指到的地方必要，但远不充分。
- **W2**：方向全对、各模块幅度抹平：56–58 题（原样 85 / 79）。幅度的分配也是学出来的信息，梯度的大小不能替代它。
- **W3**：把方向给 teacher：61 / 59。它没有调幅度，每类模块用系数 1.0，两类合用就把模型改坏，最后只提交了一类。

| 环 | 是不是瓶颈 |
|---|---|
| 写法 | 不是 |
| 位置 | 不是 |
| 方向 | 是，主要的 |
| 幅度 | 是，其次 |

## 4. 贯穿各组的一个发现：20 个训练题当验收信号不可靠

| 实验 | 训练题上 | dev140 上 |
|---|---|---|
| 规则单 v1 | 进度分低于原始模型（0.785 对 0.811） | +10 题 |
| C4 | 系数 0.5 最好（12 题），系数 1 和不改一样（8 题） | 系数 0.5 没变化，系数 1 多 6 题 |
| W3 | teacher 的编辑和不改都是 10 题 | +17 题 |
| D3、D4 | teacher 在会话内看到 +2 到 +3 题 | 0 |
| C5 随机基 | +2 题 | 改动小到和不改分不开 |

两个方向的错都有：真有效的看不出来，没效果的看起来有。原因是 20 题太少，而两种实现之间本来就有 2 题的差。凡是靠这 20 题做选择、做验收、做搜索目标的做法，都受这个限制。这一条对数据侧的方法同样适用。

## 5. 对新方法的含义

按"先看性能、再看一个新方法必须解决什么"来排：

1. **性能上，SFT 没有对手。** 这一轮所有不靠训练的做法加起来，最好是 +10 题，SFT 是 +47 题。
2. **一个想直接写权重的方法，必须解决"方向和幅度从哪来"。** 一次梯度、激活均值差、teacher 的内省都不够。这不是工程问题，是信号里没有这些信息。
3. **teacher 的价值在"提炼"，不在"定位"。** 它写规则单有用（+10），给学生生成修复数据有用（v0，在轨迹 SFT 之上再多 21–24 题），找权重里该改哪里没用（四次会话等于随机）。
4. **监督要带整个回复。** 只看动作的信号，不管交给优化器还是交给 teacher，都不够。
5. **训练侧的验收信号要换。** 20 题的整题 rollout 分辨率不够，需要更多题或更细的量。

## 6. 下一步（需要你定）

1. **方向。** 我的建议不变：重心放回数据侧（v0 有效），把规则单并进去（例如作为 teacher 生成修复数据的依据）。WSP 这两轮作为论文里的负面结果和诊断：它输在哪、为什么。
2. **R（SFT 之后的定点修补）还没登记。** 按预注册，D3、D4 等于随机时，R 先只做便宜的一半（SFT 学生在合成题上的失败拿去再 SFT 一次）；teacher 会话那一半要不要做，由你定。我倾向不做会话那一半。
3. **C4 要不要补一个不把模型改坏的对照**（各层的方向打乱，或符号取反）。LONI 上约 2 小时。补了才能说"+6 是这个方向特有的"。
4. **W3 要不要再追一步**：提示 teacher 调小系数、用完 24 次预算，看它能从四成走到几成。这仍然是诊断，不是方法。
5. 之前留下的三件：hpg 上 K30 三臂和 G5 消融要不要补；rai 两次死机的日志需要有 sudo 的人看；GitHub 仓库是公开的，要不要改成 private 或只推报告。

## 7. 没做的和局限

- 一个学生（E4B）、一个环境（ALFWorld）、每个配置一个 seed。
- R 没有做。C2 的第二步（编译）按门槛没有做。W1 里激活均值差和 teacher 自选方向的重合度没有算。
- 四个条件没有 dev140 数字，原因都是服务一致性检查：W2 的两臂和 C5 的最高点是改动太大或不一致，C5 随机基的终点是改动太小。检查没有放宽。
- 合并权重路线和 adapter 路线的数字不能直接比：把一个正常大小的 adapter 合并成 bf16，相对误差也有 0.52。每个走合并路线的系列都带了同路线的不改写参照，所以各组内部的结论不受影响。
- 运行中的偏差记在预注册 §20、§21：rai 两次死机导致约 20 小时没有新作业；C4、会话都改在 LONI 上跑；四个坏模型的评测超时后加长时限重投。
