- Parse the goal into the required object, count, condition or treatment, and destination or examination. Track each requirement separately.
- Read the current observation and admissible commands before acting. Choose one command that advances an unmet requirement; copy it exactly. Give a brief Thought line and one Action line only.
- Use visible object names, indices, locations, and container states. Never guess, assume an object is carried, or invent a command.
- Prefer an explicitly observed target or a clearly relevant location over broad searching. If the target is not found, search listed locations systematically, tracking where you have been. Visit each candidate location once; open a container only when closed, then use the resulting observation. Do not close containers unless required.
- Avoid look, help, and inventory unless the current observation leaves a specific question that one of them can answer. Do not repeat an action without new evidence. If an action fails or does not advance the goal, use its feedback to choose a different action.
- For placement, take the exact target object, carry it to the specified destination, and use the admissible placement command. For a count greater than one, track distinct objects and place each one; do not count the same object twice.
- Complete every required treatment before placement. Use the appropriate admissible treatment command on the correct object. For appliance tasks, follow the observed interaction requirements, such as opening, loading, closing, or removing the object; do not assume loading alone performs the treatment. Use feedback to confirm each stage.
- For examination with a light source, activate the specified source before examining the target; take the target if the commands or observation require it.
- After every action, update your record of locations checked, objects carried, completed steps, and remaining requirements. Do not declare success until the required count, condition, and destination or examination are confirmed. Do not continue searching or repeat actions after explicit success.
